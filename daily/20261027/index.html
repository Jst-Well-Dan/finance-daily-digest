结构化笔记｜【2026-10-26】 摩根士丹利最新会议分析：顶级投行深度谈A股基本盘的状况和分析

1. 核心结论

  1. 估值距历史极值仍有约10%-15%下调空间，但不做机械抄底线。 MSCI中国历史底部约8倍前瞻市盈率、现约10倍；沪深300历史底部约10-11倍，现同样需再下调10%-15%才进入舒适区。适用条件：以过去20年估值体系和风险溢价未发生重大改变为前提；边界：仅为历史参照，不是必须跌到才可进场的教条。
  2. 短期相对更聚焦A股而非港股，国家队高调协同入场指向未来1-2个月触底技术性反弹概率上升。 依据是10月9-20日约150亿美元量级买入、30%-40%投向科创50/创业板ETF、10月15日监管协同喊话、10月19日吴清表态稳定是第一要务，叠加自有A股情绪指数已入反弹区间。适用条件：国家队购买可持续且规模扩大；边界：若购买中断或全球AI与流动性冲击加剧，反弹可能缺席或不可持续。
  3. 年内出台堪比924级别大规模刺激的概率小，政策基调仍是托底+存量预算执行。 三季度GDP已回4.5%、累计4.6%达标压力小、年内预算仍有约三成未用、卖地收入同比-28%与缺优质项目制约支出、银行流动性不紧且需保净息差。适用条件：出口、民生反馈、股市无序暴跌三大触发因素未显著恶化；边界：若三者任一大幅恶化，特别进入明年，不排除更早政策转向。
  4. 反转钥匙分化：港股看美联储流动性预期，A股看AI叙事与信用风险解除；新兴市场宜等11月下旬后。 港股需通胀可控+联储承认流动性紧缩且无进一步过度紧缩预期；A股需AI基本面与credit危机解除带来的叙事反转；韩国等高Beta新兴市场受美元强势、联储不确定性、FOMC与中期选举扰动，短期不建议抄底。适用条件：全球AI投资周期与高油价高利率路径未超预期恶化；边界：若美联储连续大幅加息或AI资本开支证伪，上述路径失效。

2. 专家观点与逻辑链

观点 1：本轮A股独美机制弱化，与美股高成长联动大幅提升

  • 观点归属： 策略负责人罗宾总
  • 结论： 本轮A股波动受美股AI/高成长股波动传导，资金进出受全球联动影响，并不奇怪。
  • 前提事实： 历史上A股因国内投资人基本盘粘性高，与海外联动性低；本轮行情集中于人工智能主题和超级资本开支这一全球联动主题；近期美股AI相关高成长股波动巨大。
  • 推导逻辑： 历史低联动前提 + 本轮持仓集中于全球AI主题 → A股与美股高成长相关性上升 → 美股波动传导至A股主题投资与资金流
  • 隐含假设： 国内资金并未足以对冲外资预期与主题定价；AI主题定价权仍在海外链条。
  • 反例 / 证伪条件： 若A股AI链走出独立基本面验证而美股继续大跌仍不跟跌，或成交结构显示国内资金完全主导，则联动论证伪。

观点 2：9月初已提示风险，目标价下调逻辑得到验证

  • 观点归属： 策略负责人罗宾总
  • 结论： 9月3日对全部中国指数下调目标价合理，近期调整方向与预期一致。
  • 前提事实： 9月初提示流动性将紧缩、AI主题处多空对决不确定性高；列示风险聚集因子包括海外投资账户监管收紧、CRS信托账户税收收紧、9月1日起对外籍人士自中国企业分红正式征税。
  • 推导逻辑： 流动性紧缩预期 + AI分歧加大 + 跨境资金税收监管收紧 → 资金流出与估值压力 + 盈利下修 → 下调目标价
  • 隐含假设： 上述监管税收变化会实质影响资金流与风险偏好，而非仅情绪噪音。
  • 反例 / 证伪条件： 若资金流、盈利修正并未恶化而市场仅因外部情绪下跌，或跨境资金实际未受影响，则下调逻辑不成立。

观点 3：历史极值估值锚：MSCI中国8倍，沪深300为10-11倍

  • 观点归属： 策略负责人罗宾总
  • 结论： 现估值调整幅度大但未到历史底部，还需约10%-15%下调至9倍以下才更舒适，但不主张机械等底部。
  • 前提事实： 过去20年MSCI中国在2008、2015、2020年初疫情、2022年底、2024通缩+创新怀疑期跌至8倍前瞻市盈率后均现明显持续反弹，现约10倍；沪深300历史下端为10-11倍，现同样高约10-15%。
  • 推导逻辑： 历史多次成分大变仍守住8倍/10-11倍底部规律 → 当前10倍上方类比 → 得出仍有10%-15%空间
  • 隐含假设： 未来估值体系与风险溢价不发生重大结构改变；历史成分变迁不破坏市盈率可比性。
  • 反例 / 证伪条件： 若指数盈利大幅上修消化估值而价格不跌即企稳反弹，或全球估值中枢系统性上移，则无需再跌10%-15%。

观点 4：国家队 loud and clear 进场，A股1-2个月内触底反弹概率上升

  • 观点归属： 策略负责人罗宾总
  • 结论： 国家队本轮进场更可持续、规模可能更大，A股相对港股更值得聚焦，1-2个月可见明显触底反弹。
  • 前提事实： 历史上高调进场+真金白银+公开喊话后1-2个月多现可持续反弹，如2024年7月底8月至924行情；本次观测到10月9-20日约150亿美元买入（约为上半年5个月卖出量的约十分之一）、30%-40%投向科创50/创业板ETF（2024年仅十几%）、10月15日北京监管鼓励准国家队机构基金回购、建议险资勿对亏损股集中计提清仓并建议加速维稳购买、10月19日吴清称稳定是第一要务、自有周五A股情绪指数已跌至技术性反弹区间。
  • 推导逻辑： 有规模真金白银 + 针对科技重灾区的结构倾斜 + 跨部门协同喊话 → 信号非常明显且可持续 → 历史经验外推1-2个月触底反弹
  • 隐含假设： 跟踪指标能真实代表国家队行为；喊话能有效提振预期且资金能持续接力。
  • 反例 / 证伪条件： 若买入仅为短期脉冲后迅速萎缩，或市场无视信号继续无序下跌，或情绪指数发出假信号，则判断失效。

观点 5：组合转向防御红利，降低Beta，待尘埃落定再turn on risk

  • 观点归属： 策略负责人罗宾总
  • 结论： Focus list持续调向稳定现金流与盈利确定性，直至全球不确定性落地。
  • 前提事实： 上周将宁德时代A股移出、加入港股红利Swire Property；数周前将MiniMax大模型概念移出、加入恒瑞；此前已加入中国银行；操作主线自9月至今一脉相承。
  • 推导逻辑： 全球AI分歧+流动性不确定性高企 → 降低组合Beta → 增配红利与确定性盈利
  • 隐含假设： 红利与医药大行在下跌市中防御有效且不受同等AI与流动性冲击。
  • 反例 / 证伪条件： 若AI链率先大幅反转而红利跑输，或红利同样补跌，则防御切换失效，需重新turn on risk。

观点 6：三季度4.5%是坏消息，出口强难传导内需，仍处K型分化与准通缩

  • 观点归属： 宏观分析师Jenny
  • 结论： 三季度靠外需与基建托底回4.5%，四季度跟踪4.5%-4.6%，但内需仍弱，短期大刺激迫切性下降。
  • 前提事实： 净出口对GDP贡献由上半年0.8个百分点跳至三季度1.8个百分点，出口由AI硬件扩至非科技板块；但带动的无产能过剩AI投资仅占制造业投资1/5、总投资七八%；9月预算加速与财政支持托底基建；9月社零0.4%回升至1.1%主因中秋错位；居民贷款、人均支出、储蓄率显示降非必要消费、多存钱还约3%存量按揭，9月底全国性按揭补贴仅针对新造首套前5年且范围窄；Q3 GDP平减指数显示通胀仅在上游商品与AI硬件，服务业通胀下滑。
  • 推导逻辑： 外需结构走强填补投资下滑 + 预算发力 → GDP回4.5%达标 → 政策托底即可 + 居民主动去杠杆未解与服务通缩 → K型分化与准通缩延续
  • 隐含假设： 出口统计与平减结构能准确刻画内外需传导；居民行为主因是高按揭利率而非收入预期本身。
  • 反例 / 证伪条件： 若服务通胀回升、居民储蓄率下降与贷款回暖、出口带动制造业投资占比显著扩大，则K型与准通缩判断证伪。

观点 7：年内大刺激概率小，触发转向看出口、民生、股市三要素

  • 观点归属： 宏观分析师Jenny
  • 结论： 流传的等同甚至超过924规模的降息降准+新特别国债转向属空穴来风，更多讨论的是明年。
  • 前提事实： 年内预算约三成未用、累计GDP4.6%达标压力小；前9月税收同比6%好于预算3%但支出远低预算，主因卖地收入同比-28%、政府基金收入跌近两成及缺高质量有回报基建项目；银行不缺流动性因缺好项目，降准与全面降息概率小，潘行长提未来择机将政策利率由7天逆回购切至隔夜只是已自6月逐步发生的变相降息；人民币难大升（准通缩基本面+潘行长强调汇率与经常账户无简单线性关系+一篮子已近历史高位，预测USDCNY年底6.65、明年底6.6），退税退坡聚焦过剩与高竞争力及高污染产品且间隔至少一年渐进可控；地方2万亿/年置换债今年收官，若央行新低利率再贷款工具未证实落地叠加卖地续跌，地方保工资民生钱受挤压；A股6月以来下跌但仍在3000点以上，国家队已陆续托底。
  • 推导逻辑： 达标压力小+财政真实约束大+货币传导受限 → 年内无迫切大转向 → 仅当出口意外走弱或地方流动性缺口致民生负反馈或股市无序暴跌伤及新质生产力融资才触发转向
  • 隐含假设： 官方预算与土地出让数据反映真实财政约束；汇率与退税评估框架稳定；股市水平仍被决策层视为可控。
  • 反例 / 证伪条件： 若年内意外宣布全面降息降准、大规模新增国债，或油价高企迫使美联储连续大幅加息致出口骤弱、地方工资拖欠大面积发酵、A股失守关键点位无序暴跌，则小概率判断被证伪。

观点 8：不重演日本失落20年，2028年起有望由准通缩转稳定低通胀

  • 观点归属： 宏观分析师Jenny
  • 结论： 长期不那么悲观，工业5.0+反内卷+出口结构支撑产能利用率2-3年改善，一二线房价明年底基本企稳，2028年起进入稳定低通胀，但回2%-3%健康通胀极难。
  • 前提事实： 人均收入与生产率后发追赶空间大、资产泡沫远小于当年日本、无被动大幅升值；产业链深度广度利于抢占智能化下一代工业革命份额，未来投资聚焦存量工厂智能高效升级而非简单扩产；今年一线房价已基本稳住，大城市中产负财富效应不再恶化。
  • 推导逻辑： 追赶空间+小泡沫+汇率未高估 + 工业5.0升级投资+反内卷去过剩+出口结构支撑 → 产能利用率改善 + 房价企稳缓释去杠杆 → 2028年脱离准通缩
  • 隐含假设： 反内卷与产业升级能持续落地且全球份额不被贸易壁垒逆转；房价企稳能传导至消费意愿。
  • 反例 / 证伪条件： 若产能利用率持续下滑、房价再度大跌、服务通胀长期为负且无向消费再平衡的结构性转型，则日本化担忧重新成立，2%-3%更无望。
