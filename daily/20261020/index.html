结构化笔记｜【谈内需问题】付鹏：内卷不足的螺旋，为什么刺激消费再也刺激不动了？内需不足和中国当前内卷问题的交织分析

1. 核心结论

  • 结论1：内卷本质是有效需求绝对不足，而非单纯供给过剩。 适用条件/边界：仅在居民部门收入分配失衡、年轻人实际收入与就业承压持续的阶段成立；若居民可支配收入增速回升或分配结构扭转，则价格战强度可缓解。
  • 结论2：常规刺激消费政策已失效，因居民部门无杠杆空间。 适用条件/边界：适用于当前高债务、低储蓄率人群为主体的消费主体结构下，与2008-2009年居民有储蓄、可加杠杆时期不可类比；若居民资产负债表修复则结论失效。
  • 结论3：中国大规模基建与财政货币高强度扩张已触及人口税源天花板，总需求高增长难以重现。 适用条件/边界：以25-44岁主力纳税人口占比持续低于约25%-27%、老龄化加深为前提；若生育、人口结构或税收机制发生重大变化，需重估。
  • 结论4：全球需求重心东西切换，价格由供给收缩决定，上游通胀与下游通缩并存。 适用条件/边界：适用于1982-2015全球化周期结束后、贸易分割与上游寡头主动控产的格局下；若上游重回囚徒困境式扩产或海外居民收入增速塌方，则逻辑打破。

2. 专家观点与逻辑链

观点 1：内卷不足螺旋的分配根因

  • 观点归属： 付鹏
  • 结论： 下游拼命打价格战的根因是消费力不够，穿透到底是房子造成的“大部分人债务、少部分人财富”与收入分配失衡。
  • 前提事实： 上游不可控、中游被挤压、下游卷；终端出现76800、73800、58800抱回家式汽车恶性价格战；年轻人转向低价替代消费。
  • 推导逻辑： 房子形成债务分化 → 收入分配失衡 → 有效需求不足 → 企业为抢存量需求被迫降价 → 恶性内卷
  • 隐含假设： 房价与债务负担是分配失衡的主因而非其他制度性因素主导；价格战主要由需求侧解释而非技术进步降本解释。
  • 反例 / 证伪条件： 若在收入分配未改善情况下价格战自行收敛，或龙头通过技术降本实现盈利性降价而非亏损性倾销，则观点被削弱。

观点 2：储蓄增长与储蓄率劈叉下的刺激无效论

  • 观点归属： 付鹏
  • 结论： 刺激消费对没钱者无效，对有钱者无需刺激；当前存钱者与存不下钱者是两批人，真正的消费者是后者。
  • 前提事实： 2018年后银行储蓄异常增长但居民储蓄率下降；低收入者挣3000花3000加借贷、储蓄率为0；付鹏引用周小川2018年关于储蓄率下降过快的提醒；年轻人灵活就业统计与体感就业存在偏差。
  • 推导逻辑： 储蓄总量涨+储蓄率降 → 钱集中在无消费意愿的老同志/高 wealth 群体 → 年轻人无钱可花 → 货币财政刺激无法转化为有效消费
  • 隐含假设： 新增储蓄主要来自投资回报不足而预防性储蓄的老年/高收入群体，而非全体均匀积累；年轻人边际消费倾向显著更高。
  • 反例 / 证伪条件： 若能证明储蓄增长广泛分布于年轻消费主力，或定向补贴/减债后消费倾向大幅回升，则刺激无效论不成立。

观点 3：日本镜鉴——地产泡沫是结果，自然人口淘汰是出清路径

  • 观点归属： 付鹏
  • 结论： 日本1990年地产破裂是分配失衡的结果不是根因；日本未靠强制分配，而是靠二战后红利一代自然离世、第二代付出代价后第三代迎来薪资与岗位改善，中国若不强制分配也大概率需等一代人。
  • 前提事实： 日本二战后至1990年储蓄与储蓄率同步，1992年后劈叉长达11年储蓄增、储蓄率至零、年轻人失业高企；2015年后储蓄增速回落与储蓄率重新吻合、年轻人失业率下行。
  • 推导逻辑： 高速增长后分配固化 → 储蓄率塌方+年轻人失业 → 地产破裂为表象 → 老一代退出 → 劳动供给收缩 → 年轻一代薪资岗位正反馈
  • 隐含假设： 中日人口与分配演化路径可比；日本2015年后改善主因是人口自然周期而非货币、产业或外部需求主导。
  • 反例 / 证伪条件： 若日本改善被证实主要由政策干预、企业治理改革或外部因素驱动，或中国通过分配改革提前扭转年轻人收入，则“等一代人”推断失效。

观点 4：财政货币局限与基建终结论

  • 观点归属： 付鹏
  • 结论： 财政受制于债务、货币受制于回报率，中国不可能重现4万亿式大基建，总需求增速系统性下移，GDP总量数字掩盖分配差异。
  • 前提事实： 地方政府债务风险、公务员降薪裁员；25-44岁人口占比从2021年29%降至约27%，逼近日本停建基建的25%线；美英基建投资约1982年结束，日新干线“不是不会而是不能”。
  • 推导逻辑： 人口老龄化+年轻人占比下滑 → 税源萎缩 → 政府投资无法带动税收即变债务 → 基建停滞为维护保养 → 利率因储蓄过剩+回报不足持续下移但难拉动增长
  • 隐含假设： 内债本质是税，企业靠通胀征税、政府靠税源背书债务；基建有效性唯一判据是能否带来税源；25%为关键阈值。
  • 反例 / 证伪条件： 若出现不依赖人口税源的新型高回报基建，或财政通过加税率、非税收入维持债务可持续，则基建终结判断过强。

观点 5：全球东西切换与上游供给收缩定价

  • 观点归属： 付鹏
  • 结论： 需求东弱西强切换，既无大增长也无大衰退，价格由供给决定；上游寡头主动减产保价、分红回购受益，海外走通胀正反馈，中国承压于上游通胀、下游通缩无法传导。
  • 前提事实： 美国页岩油2014-2015价格战后形成寡头不再资本开支，沙特阿美上市后低油价即减产；油常年85-90、铜8000-9000；海外利率4%-5%而经济仍有韧性，中国利率需降至2%以下，加息将重创房奴。
  • 推导逻辑： 中国居民收入下移=海外居民收入上移 → 海外可承受高利率、中国只能降息 → 上游控产挺价+分红 → 海外薪资就业通胀循环 vs 国内利率下移+利润挤压+出海寻求回报
  • 隐含假设： 利率高低好坏取决于居民收入增速而非绝对水平；上游能长期维持协同减产不陷入囚徒困境；地缘分割持续。
  • 反例 / 证伪条件： 若海外薪资增速塌方导致高利率反噬，或上游寡头联盟破裂重回扩产，或中国成功向海外大规模输出人民币资本并获取高回报，则挤压格局改变。
