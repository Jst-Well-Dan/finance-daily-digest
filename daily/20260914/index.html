2. 专家观点与逻辑链

观点1：AI漫剧制作端无利可图，钱被投流拿走

  • 观点归属： 付鹏，引用一线投资人数据。
  • 结论： 看空AI漫剧内容制作公司，行业今年3月后全面亏损。
  • 前提事实： 一部AI漫剧成本中投流约占80%，token成本去年约6—7%、涨价后约10%；万播收益从30—100元跌至5—10元；约每77部才有一部回本（转写表述，精确口径待核验）。
  • 推导逻辑： AI把单集制作成本打穿 → 同一脚本可同步发给十几二十家公司竞作、市场只推优胜者 → 竞价推高投流 → 利润被流量端拿走 → 制作端全面亏损。
  • 隐含假设： 平台持续采用“同一IP多版本赛马、只扶持优胜者”的分发机制；投流价格不回落。
  • 反例 / 证伪条件： 若某制作方建立起可复用的自有流量池、投流占比显著下降，或万播收益回升至20元以上，则“必亏损”结论不成立。

观点2：AI最优脸看多了会扭曲现实审美

  • 观点归属： 付鹏个人调研感受。
  • 结论： 对AI漫剧的“完美脸”应保持警惕，尤其建议青少年少看。
  • 前提事实： 为规避版权，AI脸只能按人类审美最优方式拼凑五官，男女主脸高度同质化；嘉宾自述刷多后看真人脸“总觉得哪儿不对劲”，且看完记不住具体长相。
  • 推导逻辑： 反复暴露于最优刺激 → 大脑记住“最舒服的比例” → 现实脸相对显得有缺陷 → 观感不适乃至影响现实社交审美。
  • 隐含假设： 观看量达到足够大的累积时长；该效应具有普遍性而非个体差异。
  • 反例 / 证伪条件： 若对照研究显示重度观众与普通观众的脸部吸引力评分无显著差异，或观众能清晰区分虚构与现实审美，则该担忧不成立。

观点3：AI时代的护城河从制作转向流量

  • 观点归属： 付鹏。
  • 结论： 在AI内容领域，制作能力不再是护城河，谁掌握流量谁赢。
  • 前提事实： 以前电影的护城河是名导演、名演员、出品方与资本；现在AI让二三流甚至无资源的导演也能做出精美内容；平台上同等制作水平的剧，有的有赞、有的零关注。
  • 推导逻辑： 模型与算力人人可用 → 制作能力平权、无差异化 → 用户只能看平台推什么 → 投流与分发决定生死。
  • 隐含假设： 模型能力继续快速趋同，不出现独占性强的代际断层；平台分发规则保持中心化推荐。
  • 反例 / 证伪条件： 若出现依托独特数据或独家模型形成的持续质量断层，或去中心化分发让好内容自然胜出，则制作护城河重现。

观点4：农产品用期限结构辨别真假题材

  • 观点归属： 伦敦农产品老交易员（经付鹏转述）。
  • 结论： 判断天气等题材真伪要看期限结构是否转成高Back，而不是看价格涨幅或新闻热度。
  • 前提事实： 农产品平时低波动，价格贴近种植成本；一旦当季出问题，当期限货打出高溢价但远期不受影响，形成近高远低；老交易员策略是每年花约60万美元分散买当年的看涨期权，赌连年风调雨顺不可能持续。
  • 推导逻辑： 供给冲击只影响当季 → 真短缺必在结构上留下高Back → 无结构配合的涨价只是叙事 → 按结构下注、小额期权博小概率。
  • 隐含假设： 历史分布延续，即极端天气以低频离散方式出现；期权费相对潜在赔付足够便宜。
  • 反例 / 证伪条件： 若气候变化使减产常态化、远期同步抬升（结构不再均值回归），或期权隐含波动率已充分定价灾害概率，则该策略失效。

  • 结论： 对日本政策明确转向审慎：肯定安倍经济学摆脱通缩成功，但其低利率加财政扩张组合已到尽头，不应再额外助推。
  • 前提事实： 贝森特称日本"已经战胜了通胀"、安倍再通胀政策"走到了尽头"；日本产出缺口2023年起不再为负、供需缺口已闭合（付鹏补充，待核验）。
  • 推导逻辑： 通缩已除、缺口闭合 → 继续总量刺激只会加到总需求上 → 通胀过热、长债收益率失控、日元与国债一起承压 → 应停掉再通胀组合、让成果自行运转。
  • 隐含假设： 当前通胀与工资上涨是可持续的内生分配改善，而非一次性输入性通胀；产出缺口闭合的测算准确。
  • 反例 / 证伪条件： 若工资涨幅回落到物价之下、内需良性循环断裂，或证实本轮通胀主要来自进口成本而非分配改善，则"已战胜通缩"不成立。

观点2：通缩根源是企业共同体分配制度，企业与员工"共生不分钱"

  • 观点归属： 付鹏。
  • 结论： 对"货币放水就能治通缩"持否定态度：日本通缩的核心是劳动者没有分配权，低通胀最终是思想变成了制度。
  • 前提事实： 战后日本企业实行终身雇佣与年功序列，工资跟工龄与家庭阶段走而非岗位与贡献走；企业遇风险优先保集体、囤现金，谁先提加薪谁就是破坏环境；2005年前后银行与企业资产负债表已修复七七八八，但行为模式未变（付鹏陈述，部分为其长期研究判断，待核验）。
  • 推导逻辑： 工资非市场化定价 → 修复资产负债表后仍不分钱 → 对内压薪压价（内部贬值）替代对外贬值 → 通缩预期刻进两代人认知 → 对内通缩、对外升值成为自我强化的秩序。
  • 隐含假设： 资产负债表修复后仍不恢复分钱，主因是分配制度与认知，而非需求不足或人口结构等其他因素占主导。
  • 反例 / 证伪条件： 若2005年后企业利润与现金增速实际已大量转化为薪资与分红，或跨国比较显示同样雇佣制度的经济体并未长期通缩，则分配单因解释被削弱。

观点3：日本处方是总量转结构，财政必须投向生产率而非需求

  • 观点归属： 贝森特（经付鹏阐释，其中"总量转结构"的提炼含付鹏的整理成分）。
  • 结论： 对日本财政与货币持中性偏紧立场：总量再通胀应停，财政从刺激总需求转向提高产能与全要素生产率，偏向股东友好、放松劳动力市场管制。
  • 前提事实： 春斗加薪已超5%、名义增长与工资迹象出现；继续对外贬值会把进口通胀变成居民账单；G20沟通后贝森特与日本央行、财政部门已形成一定共识（付鹏陈述，待核验）。
  • 推导逻辑： 缺口闭合 → 总量刺激只推通胀不推生产率 → 转向供给端有效投资（电站、芯片半导体）→ 生产率提升缓解通胀、名义增速消化债务 → 日元在效率提升下慢慢升值。
  • 隐含假设： 日本存在可快速见效的供给端投资项目；股东回报与加薪优先于"生存优先"不会引发企业防御性收缩；政府能精准识别有效投资。
  • 反例 / 证伪条件： 若结构性投资迟迟不能落地、生产率无改善而通胀先行，或财政收缩过快导致内需循环断裂，则该处方失效；把"结构调整"误读为全面收紧财政将直接导致衰退（付鹏明确警示）。
