观点 1：美国脆弱在股债正相关，坚强在多元拆弹手段

  • 观点归属： 华创张瑜（大势研判主讲部分）
  • 结论： 美股美债应为负相关的资配基石，转正即脆弱；本届美联储的核心考核是能否让相关系数转负；美国不同于一般国家，可用经济+政治+军事多元手段配套拆弹。
  • 前提事实： 近30年股债相关系数有4次转正或接近转正；2000年互联网泡沫、07-08年次贷危机前转正约一年后爆发大危机；2014-15年taper讨论时接近0；耶伦任内加息但系数由高转负、实现软着陆；当前高位已维持两年多；近期美方主动帮稳日元、紧张美债利率上行、财政部小规模国债回购积极表态。
  • 推导逻辑： 股债负相关时资金只是腾挪，股跌债涨可限流动性风险 → 转正后单一资产下跌易双杀触发量化平仓和资配逻辑崩塌 → 当前高位两年多未解故高度敏感脆弱 → 美国可用非经济手段争取时间配套，故同时鲜明坚强
  • 隐含假设： 股债相关系数可作为金融系统健康度的充分代理指标；历史4次可比，耶伦经验可复制为信任锚定加息与景气联动；非经济手段能有效延缓抛售和利率冲击。
  • 反例 / 证伪条件： 若股债相关系数在未动用非经济手段下自行转负并维持，或转正后长期未发生流动性危机，则脆弱论证伪；若多元施压仍出现美债被动抛售+长端利率失控上行，则坚强论证伪。

观点 2：8月国内量稳价升，地产新政关键看土地市场量价与付款周期

  • 观点归属： 宁波（经济前瞻与地产新政部分）
  • 结论： 8月量的层面相对平稳、未较7月进一步恶化，值得关注的是物价或因大宗暂时回升；地产新政对宏观的影响最终收敛到土地成交量价和财政收入、地产投资。
  • 前提事实： 8月PMI中消费品制造业、基础原材料前瞻指数回升；7月受异常高温台风强降雨扰动；9月有中秋国庆双节备货可能；8月基建相关PMI回升2个多点，7月全国固投累计增速好于前6月；7月CPI/PPI回落幅度超预期，8月海外油铜黄金反弹、国内焦煤期货大涨、生猪回升；地产资金流涉及银行、居民、政府、开发商四部门，从拿地到资金回流由约1年拉长至竣工交付的2-3年。
  • 推导逻辑： 7月天气扰动消退+节前备货+基建轻微加速 → 8月内需PMI前瞻与基建PMI回升 → 量稳判断；大宗普涨未结束 → 8月物价暂时回升；拿地到回款周期拉长 → 即使成交量不恶化，财政收款节奏与开发商资金流仍受损
  • 隐含假设： PMI前瞻指数回升可代表真实需求而非单纯季节备货；大宗涨价能传导至CPI/PPI；土地出让金缴纳周期延长和地价调整会实质发生。
  • 反例 / 证伪条件： 若8月正式PMI、固投、CPI/PPI未印证回升回暖，或后续拿地量价平稳且财政以其他收入足额补充、基建对冲地产投资下滑，则价升担忧与地产悲观链条证伪；若拿地进一步回落且无补充，则偏不利影响成立。

观点 3：924以来预期扭转靠居民存款活化搬家，未来看波动率与地产渠道

  • 观点归属： 骆宇/华创宏观文若宇（存款观察部分）
  • 结论： 2024年9月以来宏观预期扭转的关键是居民存款新增回落、边际流出且主要流向金融市场而非实体；展望未来，金融资产波动放大和地产政策变化可能中断活化，需观察居民存款是否同比转正和波动率是否引发回表赎回。
  • 前提事实： 924以来居民新增存款规模明显回落；居民消费倾向平稳，房地产销售额负增长，企业存款25年以来增量平稳；二级市场交易只是非银存款部门间转移，但成交额活跃；78月股票点位虽稳但波动放大；25年期房销售约5万亿量级，构成居民存款流向企业存款渠道之一。
  • 推导逻辑： 居民拿到工资不存而是花投即风险偏好高 → 新增存款回落+消费购房未升+企业存款平稳 → 钱流向金融市场搬家 → 政策稳住波动才有赚钱效应维持搬家 → 波动放大致持股体验变差+地产新政切断购房渠道 → 可能存款回表金融机构被迫卖资产换流动性
  • 隐含假设： 新增存款回落等同于主动搬家而非收入下滑；成交活跃主要靠居民搬家而非杠杆或其他资金；波动放大必然恶化持有体验并触发回表。
  • 反例 / 证伪条件： 若8-11月居民存款继续净流出、未同比转正，且理财无赎回、成交维持活跃，则担忧证伪；若出现居民存款同比转正、理财赎回、金融机构抛售资产，则中断判断成立。

观点 4：8月全球股债流入双降、美债安全溢价转负、仓位拥挤

  • 观点归属： 新宇（全球投资十大主线与资金流动部分）
  • 结论： 8月全球微观流动性降温呈避险特征，股债流入双降、风险偏好边际回落；美债长端安全溢价消失叠加持有人向敏感型迁移，全球基金经理现金极低、股票超配拥挤，美股是美金融条件宽松主因，结构分化加剧。
  • 前提事实： 8月沃什杰克逊霍尔偏鹰后9月加息25BP概率由35.8%升至65.1%，2年美债至4.34%；全球股票基金单月流入缩至640亿美元，固收流入放缓至622亿美元；3A公司债与美债利差由危机前30-60BP压缩至0附近部分转负，即时国家对冲后国债收益率较美债低18-22BP反转，外国官方持有占比由2010年约70%降至2025年约40%；BofA调查现金占比3.5%为98年以来历史第六低，股票超配56%为21年11月以来最高；美金融条件指数-0.88处90年以来14%分位，76%宽松贡献来自股市；美股行业两两相关均值0.15为02年以来最低，信息技术与必选消费60日相关-0.58；7月费城半导体跌超20%后半导体ETF流入116.2亿美元创纪录，8月反弹中反转流出49.5亿美元；8月日本动用15.4万亿日元干预、日元升破160但未动用FIMA抵押美债；8.27-9.2当周美股弱债强、欧股强债弱、中国内外资同步流出46.5亿美元。
  • 推导逻辑： 鹰派预期+债务担忧 → 长端安全溢价转负持有人更敏感 → 高仓位低现金下边际资金流入放缓 → 避险转向货币市场，长线风险偏好降温
  • 隐含假设： EPFR/问卷与利差口径能真实代表安全溢价与风险偏好；单月单周波动具趋势意义；FIMA未用即等于未抛售美债担忧解除。
  • 反例 / 证伪条件： 若9月后股债流入重回扩张、现金回升、美债利差重新走阔且外国官方占比企稳，则降温与安全属性重定价判断证伪；若波动率继续放大并伴随持续流出货币基金激增，则判断成立。文中中国信贷脉冲领先美国ISM约12个月、美元弱则新兴跑赢等为历史规律整理，非本次因果结论。

结构化笔记｜【最新】大摩内部闭门会议（2026-9-7附文稿）《宏观策略谈》分析当前中国的通缩形势，下一步进一步的走势和趋势到底怎么去看？《文字稿件》发布于解读君推特X

1. 核心结论

  • 当前多领域收紧是通缩下被动保税基的顺周期收缩，而非2021式主动监管重置。 适用条件/边界：中央未扩大赤字主动对冲、地方维持平衡财政心态去找税源补缺口期间成立；若出现跨互联网、教育、地产等多行业统一顶层监管文件则不成立。
  • 宏观框架仍重供给侧自立自强，9-11月至多是存量财政落地+定向增量，难现924式需求端大招。 适用条件/边界：GDP维持4.3%-4.7%合理区间、无系统性就业与金融风险时成立；若增速明显跌破区间下沿或风险失控则转向。
  • 人民币偏弱是后地产时代投资-储蓄缺口扩大的均衡结果，而非靠弱汇率主动制造顺差；单靠升值不能再平衡，反而加剧通缩。 适用条件/边界：内需偏弱、经常账户顺差高企、国内均衡利率下行格局未变时成立；若内需实质修复或全球同步结构改革则需重估。
  • 紧缩政策有底但拐点未至，需防合成谬误与通缩反馈强化。 适用条件/边界：居民预防性储蓄创新高、实质去杠杆，越收税税基越小、越节约收入越少的反馈成立时适用；若社会反馈出现边际恶化或政策明确新老划断+过渡期，则可能触发调整。

2. 专家观点与逻辑链

观点 1：近期收紧性质判断

  • 观点归属： 邢德强（Robin，主持人）
  • 结论： 近期地产、税收、出海三股收紧同步叠加，但属被动顺周期收敛，未上升到2021年监管重置高度。
  • 前提事实： 现房销售+预售资金封闭监管讨论；高新资质复核演变为多地倒查十几年优惠；高净值海外收入全球征税征管加强；企业对外投资矿产技术设备管制趋严。
  • 推导逻辑： 通缩+土地财政下行+名义GDP弱 → 财政承压但赤字不扩 → 被动堵漏洞找税源 → 效果上顺周期收紧
  • 隐含假设： 这些举措初衷合规合理，主要是执行层一刀切、缺过渡期与沟通；中央暂无意愿主动加杠杆对冲。
  • 反例 / 证伪条件： 若出台类似2021年覆盖多行业的统一主动监管顶层设计，或地方执行细则大幅优化并设过渡期，则“被动叠加”判断被修正。

观点 2：地产供给侧改革改变底层逻辑

  • 观点归属： 邢德强转述大摩地产团队
  • 结论： 若现房销售一刀切严格执行且过渡期少，明年新房销售再下滑15%-20%，开工卖地2027-2028年仍承压。
  • 前提事实： 地产投资占GDP已低于2004年、低于日本等老龄经济体；现房制拉长持有周期、降低周转率与ROE；房企拿地开工意愿下降。
  • 推导逻辑： 现房制+资金封闭 → 周转放慢+利润率下降 → 拿地开工减少 → 卖地收入与上下游继续萎缩
  • 隐含假设： 执行偏严、无实质地方优化；居民通缩预期下需求不回升。
  • 反例 / 证伪条件： 若地方给出明确过渡期与优化细则，或销量降幅显著小于15%，则判断失效。

观点 3：后地产新均衡与人民币

  • 观点归属： 蔡志鹏博士
  • 结论： 地产逆转后形成经常账户顺差扩大+均衡利率下降+实际有效汇率偏弱的新均衡；短期人民币随美元走弱可阶段性升值突破7附近，中期仍是有序温和双向管理。
  • 前提事实： 地产及随之的地方基建投资下滑失去大额投资需求，居民企业储蓄倾向未同步下降，剪刀差扩大；2023-2025年央行用中间价抑贬值，当前用中间价引导有序升值。
  • 推导逻辑： 地产投资消失但储蓄不降 → 投资-储蓄缺口扩大 → 经常顺差走高+利率下行+汇率偏弱 → 升值无法解决失衡反而压低进口价与出口利润强化通缩
  • 隐含假设： 国内需求持续偏弱；汇率政策框架未剧变，仍是3-5年维稳思路；美元存在debasement走弱背景。
  • 反例 / 证伪条件： 若内需实质回升而顺差不降，或央行允许快速大幅升值、中间价框架剧变，则结论不成立。

观点 4：政策定力与转向门槛高

  • 观点归属： 蔡志鹏博士（解读人民日报“仲音”连发四文）
  • 结论： 决策层认为4.7%左右符合潜在增速，风险出清需付出增长代价，政策以落实存量+针对性增量为主，容忍略偏低结果。
  • 前提事实： 上半年4.7%、二季度4.3%，缺口温和；表述强调总量积极有为但避免政策依赖症，投资不求维持速度；地方基建受隐债约束、地产受库存人口约束、制造业受产能过剩与低回报约束，地方激励偏控风险。
  • 推导逻辑： 增速基本匹配潜能+缺口不大 → 稳增长紧迫感不强 → 把现有财政转实物量+微调 → 换取地方债地产金融风险出清
  • 隐含假设： 4.5%-5%区间下沿可接受度上升；逆周期投资工具空间逼仄且地方无加杠杆激励。
  • 反例 / 证伪条件： 若增长远离合理区间、就业或金融风险急升，或出台总量需求端大刺激超预期，则“微调为主”被证伪。

观点 5：资本与税收收紧的腾挪与顺周期风险

  • 观点归属： 蔡志鹏博士
  • 结论： 资本流动管理帮央行在不可能三角内腾挪，维持汇率稳+低利率化债组合；税收社保堵漏长期必要，但短期顺周期紧缩不宜轻视，有合成谬误风险，政策终有底。
  • 前提事实： 境外投资、跨境资本、社保缴纳趋严；中美利差走高而人民币反而升值；土地收入下行倒逼堵税收漏洞；政府越节约、越收税反而钱包越瘪、税越少、杠杆率越高。
  • 推导逻辑： 管住资本 → 稳汇率同时压低国内利率促化债 → 堵税补缺口短期加重通缩 → 反馈机制放大收缩 → 倒逼未来调整但未到924拐点
  • 隐含假设： 资本管控持续趋严有效；制度化长期是好事，但宏观反馈不可忽视。
  • 反例 / 证伪条件： 若低利率未能传导至化债与需求，或资本外流压力迫使利率汇率二选一破局，则腾挪逻辑失效。

观点 6：海外两大尾部风险再定价

  • 观点归属： 邢德强转述大摩商品与外汇策略团队
  • 结论： 四季度布伦特均价有重返100美元风险需重视；日元套利平仓不构成系统性风险，无需恐慌。
  • 前提事实： 中东供给受限，美欧战略储备释放红利耗尽；日本通胀上行需部分加息，但日债回报达不到GPIF等大钱目标，全球风险偏好与AI资本开支预期仍是套利核心驱动。
  • 推导逻辑： 供给受限+储备缓冲耗尽 → 油价上行真风险；日加息但实际回报未改善+全球风险偏好未坍塌 → 套利仅换融资币而非系统抛售
  • 隐含假设： 地缘不缓和；全球不陷入深度衰退、AI增长韧性仍在。
  • 反例 / 证伪条件： 若地缘缓和释放供给，或全球衰退致风险偏好大跌，则油价与套利判断分别失效。

观点 7：硬科技链：长鑫与台湾Semicom信号

  • 观点归属： 亚洲硬科技首席 Charlie
  • 结论： 长鑫目标价88元，看好国产需求+现金流支撑持续扩产与HBM突破，乐观国产设备与先进封装链。
  • 前提事实： 长鑫无EUV落后头部约2代，但国产线良率突破80%，上海合肥北京新项目注入；HBM先两片叠再叠6次达12层，主流水平，明年可供3-4个月HBM3E，国产AI GPU若顺利采用则强化；Semicom显示需求极强、瓶颈在供应链，硅光/CXL/2.5D与wire-to-wire受关注。
  • 推导逻辑： 国产设备提升+地方基金支持 → 未来5年每年约1万片扩产可行 → HBM与2.5D/vertical channel突破 → 国产替代+全球存储定点提前至2028年附近
  • 隐含假设： DUV不可替代瓶颈短期不恶化；中美谈判不封堵关键设备；苹果采用国产存储等upside可期。
  • 反例 / 证伪条件： 若DUV获取受限加剧、HBM认证失败、国产AI GPU采用不及预期，或存储周期提前反转，则乐观情形失效。
