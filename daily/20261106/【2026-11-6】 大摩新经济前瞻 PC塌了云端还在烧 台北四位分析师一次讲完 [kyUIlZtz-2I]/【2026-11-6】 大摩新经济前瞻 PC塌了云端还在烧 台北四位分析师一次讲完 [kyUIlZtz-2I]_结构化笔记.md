# 结构化笔记｜【2026-11-6】 大摩新经济前瞻 PC塌了云端还在烧 台北四位分析师一次讲完

## 1. 核心结论

- **云端资本支出面临周期见底风险，时间点在明年上半年。** 适用条件：自去年下半年由推理+Agentic AI接力的上行已持续一年半，且美国云厂本季未再上修开支；边界：若出现新应用、新融资、国家政策接力，则周期可延长。
- **PC去库存烈度超预期，短期回避PC重仓半导体。** 适用条件：Q3整机同比跌约20-25%、Q4关键零组件环比跌三成以上、明年Q1不复苏，且记忆体维持高价；边界：若记忆体降价或换机刺激出现，则跌幅假设失效。
- **电源链短期缺催化、中长期随单柜功率提升成长，Delta竞争优势优于Lite-On，HVDC 2027-2028渗透率低。** 适用条件：Vera Rubin系机柜功率上行兑现、Rubin Ultra方案明年上半年才定案；边界：若HVDC reference design独占，则2028年超50%渗透率可能。
- **未来2-3年ASIC相对占优，MediaTek第二客户+GUC CPU放量是主要Alpha。** 适用条件：TPU V8明年3.5-3.6M颗交付无SRAM/HBM瓶颈、V9按表推进、CPU tape-out/拉货如期；边界：若tape-out延迟、CoWoS booking下修或客户集中押注变化，则逻辑失效。

## 2. 专家观点与逻辑链

### 观点 1：电源与HVDC：短期平淡、长期跟功率走

- **观点归属：** 台北分析师 Derek（power/BizLink段）
- **结论：** Delta Q3毛利率 miss为主观库存跌价约2pp、Q4将回冲+环比营收约+10% QoQ；Lite-On Q3略超预期、明年云+70% YoY带动整体+40-45%；但两者短期催化弱，长期Delta优于Lite-On，HVDC明年仅小批量测试、2028年渗透率基地情形<50%。
- **前提事实：** Delta Q3有库存跌价损失、Lite-On Q3无此项；Q4指引营收与毛利率均环比改善；DCDC module占Delta营收high single digit；hyperscaler明年HVDC主要为测试性小批量。
- **推导逻辑：** `Q3库存跌价为一次性 → Q4回冲+组合改善 → 毛利率环比回升1pp以上；单柜功率代代提升 → DCDC/电源用量提升 → 2027年需求显著增；Rubin时代in-rack方案已够用+Ultra方案未定 → HVDC 2027量小、2028双方案并存则渗透率低`
- **隐含假设：** 库存跌价可在未来几季全额回冲；机柜功率提升不被系统功耗优化对冲；客户愿意维持双方案。
- **反例 / 证伪条件：** Q4毛利率未回升超1pp；Lite-On在cooling/DCDC/HVDC追上Delta；明年上半年确认HVDC为唯一reference design。

### 观点 2：云端资本支出：两年上行规律指向明年上半年见顶

- **观点归属：** 台北分析师 Daniel（云端周期段）
- **结论：** 2008-2023年四大云厂3年一循环、2年上行配2-4季下行；本轮自2023Q2底部至2025H1达60-70% YoY，去年的推理+Agentic AI续命一年半，明年上半年可能再见顶，除非新应用/资金/政策接力。
- **前提事实：** 2023Q2为底部；美国四大云厂本季口头仍乐观但数字上没有上修资本支出；memory涨价下component仍被拉动。
- **推导逻辑：** `历史15年皆2年上行后回落 → 本轮接力起点为去年下半年 → 至今约1.5年 → 明年上半年进入2年窗口尾部 → 无新增量则见顶`
- **隐含假设：** 历史硬件周期规律在AI时代仍适用；top-down时钟优先于supply chain个股alpha；funding/cash flow不确定性不自动解决。
- **反例 / 证伪条件：** 美国云厂再度上修全年capex；主权/新entrant funding大规模落地；出现杀手级应用拉动utilization再上行。

### 观点 3：PC塌了：FOMO备货后的剧烈修正

- **观点归属：** 台北分析师 Daniel + 艾瑞（PC/ODM tracker段）
- **结论：** 前三季Fear of missing procurement造成过度备货，Q4必须correction；通路/零部件Q4环比跌三成以上、明年Q1不复苏，若记忆体高价则明年全年PC同比掉；PC相关已全线downgrade，仅留联想Overweight因ISG server扭亏。
- **前提事实：** Top-5 ODM notebook出货6月起转弱、Q2末至Q3中需求明显slowdown；IDC Q3+Intel/AMD法说指向同比跌近20-25%超原先teens%预期；timing controller、audio codec、touch等Q4环比-30%+；联想ISG operating margin由亏损转约9%。
- **推导逻辑：** `上半年提前拉货 → 库存过高+记忆体涨价压制换机 → Q3出货同比大跌 → Q4通路砍单三成+ → 明年Q1不复苏`
- **隐含假设：** 记忆体价格维持高档压制整机需求；ODM tracker可代表全球需求；库存调整不少于一个季度。
- **反例 / 证伪条件：** 记忆体Q4涨幅趋缓后快速降价刺激需求；Q4通路跌幅远小于30%；明年Q1提前复苏。

### 观点 4：CCL与载板：涨价传导分化，催化在台光电

- **观点归属：** 台北分析师 艾瑞（PCB/CCL/载板段）
- **结论：** 台燿Q3毛利率大超预期因M6以下占比60-70%+E-glass涨价顺价，台光电仅30-35%低阶+高阶占比高而弹性小；往后看催化在台光电因AI平台组装/良率delay在Q4开始真正出货；欣兴28.8%毛利率miss买方30%+为预期差非结构问题，仍为high conviction稀缺资源。
- **前提事实：** 上周台光电/台燿Q3毛利率均超卖方/买方预期、台燿更优；过去1-3个月AI平台有delay；Q4 system已有真正出货；欣兴Q3环比增长符合预期但低于买方毛利率预期。
- **推导逻辑：** `E-glass Q3大涨 → 中低阶占比高者更易pass-through → 台燿短期毛利率更受益；AI delay消除+Q4出货 → 高阶料号放量 → 台光电价值被看到；载板供需仍紧 → 欣兴预期差不改稀缺性`
- **隐含假设：** E-glass涨价可持续传导；AI出货延迟为良率/组装一次性问题；载板无新增大产能冲击。
- **反例 / 证伪条件：** E-glass价格回落或高阶CCL加价跟上；AI平台再度delay；欣兴后续毛利率继续低于30%显示结构问题。

### 观点 5：ASIC逆周期：MediaTek第二客户+GUC CPU放量

- **观点归属：** 台北分析师 Lucas（ASIC段）
- **结论：** 即使cloud capex放缓，ASIC因成本更优未来2-3年仍占优；MediaTek确认第二家非中国AI ASIC客户、2028年贡献超今年TPU，TPU V8今年Q4上调至2.5B、明年16B约3.5-3.6M颗，V9按表推进无delay；GUC靠Google Axion2/Cobalt系+次世代CPU+地平线/Tesla AI5等分散，明年下半年起放量。
- **前提事实：** MediaTek法说确认第二客户、28年量产；台积CoWoS booking约180K对应3.5-3.6M颗V8一致；V9部分已tape-out、复杂2nm compute die预计明年1月/Q1 tape-out、明年底小量产+28年初大量产；GUC次世代CPU已在台积tape-out、预计最快明年Q2认列。
- **推导逻辑：** `云厂降本诉求 → ASIC性价比路线 → MediaTek/GUC design-win兑现 → CoWoS/tape-out进度验证 → 2027-2028营收上修`
- **隐含假设：** SRAM/HBM供给不是瓶颈；第二客户候选限定且28年预算不砍；CPU ASP（约1400-1800美元）与量（各约500K-4M）假设成立。
- **反例 / 证伪条件：** V9 tape-out延迟或明年底不能小量产；CoWoS booking下修；第二客户确认为小量项目或28年贡献低于2.5B。

### 观点 6：上游谨慎：环球晶涨价被pushback、世界先进新加坡厂压毛利率

- **观点归属：** 台北分析师 Lucas（raw wafer/世界先进段）
- **结论：** 环球晶等raw wafer虽利用率90-95%但Tier1客户有库存、可pushback明年涨价，明年blended LTA涨幅仅15-20%低于预期的25-30%、台积电<10%；世界先进明年H1新加坡厂按44-45K全产能折旧但仅开3-5K至10K片，margin稀释high single至10%，差于预期的low-to-mid single，维持谨慎。
- **前提事实：** 环球晶法说称产能利用率极高但承认部分客户不接受涨价；客户有一定库存+本次涨价可预期致提前拉货，与2021-2022年低库存不同；世界先进新加坡厂房基建自明年Q1起全额折旧。
- **推导逻辑：** `可预期涨价+客户有库存 → 提前拉货 → 实际议价力弱于利用率 → LTA涨幅打折；新厂全额折旧+低开工 → 上半年margin大幅稀释`
- **隐含假设：** 客户库存水位判断正确；新加坡厂爬坡慢于折旧节奏；12寸上半年仅1万片以下。
- **反例 / 证伪条件：** 明年LTA最终涨幅达25-30%；新加坡厂开工快于预期或折旧方式调整； wafer现货价再加速上涨。
