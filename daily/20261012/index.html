结构化笔记｜【大摩闭门会】《大摩宏观策略谈 2026-10-12附文稿》「秋季会变盘吗？」AI 数据中心支持率 −20%、明年化债支持骤降约 2 万亿、全球配置美股仍是首选。 美国宏观环境：高利率下的K型消费分化

1. 核心结论

  • 中国Q4政策为守底线微调而非反转，适用边界为项目制约与化债退坡未改： 国庆前后财政+准财政+金融+地产组合仅能托底四季度GDP至4.4%-4.5%、全年接近4.5%区间下限，不足以打破通缩与去杠杆循环。
  • 2027年内需压力将加大，适用条件为土地收入续降且中央化债支持骤降约2万亿： 24-26年每年约2.8万亿置换降至27-28年每年约8000亿，若无央地税制改革或中央加杠杆接力，地方实际支出将被进一步挤压。
  • 美国高利率韧性靠K型分化维持，适用边界为高收入财富效应未逆转： 近20%受访获遗产/财富转移、半数以上投入股市+约40%买房，对冲高利率；中低收入消费与CCC级信用已受损，柴油涨价加剧生活成本压力。
  • 全球配置首选仍是美股，适用条件为美股已调整+盈利增长支撑： 标普500约19倍PE对应约17%盈利增长、罗素3000超半数成分自6月跌超20%，叠加中期选举后12个月历史偏正效应，配置为超配美股、平配日欧、低配新兴市场；MSCI中国约10.2倍PE仅算公允不便宜。

2. 专家观点与逻辑链

观点 1：中国财政顺周期收紧需防合成谬误，微调守底线

  • 观点归属： 主持人邢总（宏观）
  • 结论： 本轮组合拳规模温和、保底线非大逆转，四季度企稳但明年名义GDP仍有下行压力
  • 前提事实： 去年下半年以来实际财政赤字略收紧；按揭贴息仅针对新房、一年约100多亿；3000亿地方债一般限额未使用额度激活；六张网定向融资+政策性银行贴息落地
  • 推导逻辑： 资金跟着项目走+合格项目稀缺 → 资金躺国库难转实物量 → 基建投资疲软延续 → 微调仅稳住Q4增速、难破通缩循环
  • 隐含假设： 人口下降+城镇化放缓下传统基建回报下降；地方受化债与审批周期约束不会激进开工；中央暂不转向资金跟民生社保走
  • 反例 / 证伪条件： 若新批海上风电、AI算力等重大项目快速放量，或财政转向跟社保福利走，则实物量与通缩预期可明显改善

观点 2：明年化债悬崖将挤压地方支出

  • 观点归属： 主持人邢总、经济学家蔡志鹏博士
  • 结论： 2027年中央对地方化债支持减少约2万亿，将削弱清欠与存量债务缓解能力
  • 前提事实： 5年10万亿化债前置，24-26年每年2.8万亿，27-28年降至每年8000亿；828地产新政后预计27-28年土地出让收入进一步显著下降
  • 推导逻辑： 卖地收入萎缩延续 → 化债置换骤降 → 地方清欠能力下降 → 实际财政支出被挤压 → 内需持续去杠杆压力
  • 隐含假设： 地产调整延续至27-28年；无新的央地财政关系改革或中央资产负债表接力
  • 反例 / 证伪条件： 若中央加杠杆接力、推进地方欠款清偿/城投重组/央地改革，则地方收缩可被对冲

观点 3：美国K型消费分化掩盖高利率脆弱性

  • 观点归属： 主持人邢总（引AlphaWise约2000样本调研）
  • 结论： 美国名义GDP约6%、信用利差窄的韧性是极度K型分化撑起，水面下中低收入已被撕裂
  • 前提事实： 近20%受访近年获遗产/财富转移，高收入超10万美元家庭占比更高，其中超一半投股市、近40%买房；半数以上预计未来6个月经济恶化；IG仍扛住、CCC违约概率与利差急扩
  • 推导逻辑： 代际财富传承+AI股市财富效应 → 高收入血厚免疫高利率 → 总量消费韧性 → 中低收入靠工资被高利率+高通胀+柴油暴涨压垮
  • 隐含假设： 股市不大幅回调；遗产转移持续；能源冲击不进一步恶化
  • 反例 / 证伪条件： 若美股大跌致财富效应逆转，或降息/油价回落，则K型裂口收窄、分化叙事失效

观点 4：中期选举地方博弈给AI数据中心资本开支带来阵痛

  • 观点归属： 主持人邢总
  • 结论： 联邦参议院归属非主战场，州/PUC审批才是AI基建现实约束，9月全球AI信用融资降至230亿美元年内新低
  • 前提事实： 约80%审批权在州长、州立法机构、公用事业委员会PUC，部分委员直选；调研AI整体净支持率约14%，但家10公里内建数据中心支持率跌至-20%；上半年30多州提超300项限制法案、部分州撤税收减免
  • 推导逻辑： 耗水耗电+电价+环保担忧 → NIMBY抵触-20% → 政客迎合选票设审批障碍 → 并网许可/电价核准/水配额受阻 → AI资本开支放缓
  • 隐含假设： 选民反对转化为实际立法与审批延迟；电力水资源短期刚性
  • 反例 / 证伪条件： 若州层面维持税收减免与并网加速，或电力供给快速扩容，则AI融资与开支可重回加速

观点 5：港股策略转向稳健，Focus List调出MiniMax调入恒瑞港股

  • 观点归属： 首席策略Laura
  • 结论： 动荡环境下追求相对稳定组合，看好生物医药中长期，信息技术基本面亦非纯情绪交易
  • 前提事实： Focus List唯一大模型敞口MiniMax因短期波动大被调出；全球公认中国领先优势为人形机器人+生物医药，但前者出货低偏niche；二季度盈利突出的为信息技术+Healthcare
  • 推导逻辑： 宏观+利率+选举不确定性高 → 降低波动敞口 → 增银行红利+恒瑞等国际footprint好的医药 → 兼顾稳健与高确定盈利增长
  • 隐含假设： 医药地缘风险更可控、利率压制缓解；三季报验证盈利确定性
  • 反例 / 证伪条件： 若医药集采/出海受阻或MiniMax波动收敛且基本面兑现，则调仓逻辑被证伪

观点 6：外资9月双流出，MSCI中国估值公允不便宜

  • 观点归属： 首席策略Laura
  • 结论： 9月外资净流出18亿美元且主动+被动均流出；亚太除日本超配收窄、新兴市场更低配；MSCI中国10.2倍前瞻PE对应约6%盈利增长，不到8倍极端拐点
  • 前提事实： 全年净流入靠被动、主动未转趋势；7月后台日韩AI调整流出更大、港股防御致被动超配中国，9月该超配已下降；21年后国庆前后多有不确定性，今年港股假期疲软
  • 推导逻辑： 管制+税收+海外财务收入政策扰动 → 全球机构犹豫 → 9月双流出+仓位下调 → 估值未到极端便宜 → 不因跌多而抄底，需看基本面三季报
  • 隐含假设： MSCI中国成分变迁不改变8倍拐点经验；资金面紧张延续
  • 反例 / 证伪条件： 若主动基金转净流入、盈利上修超预期或估值跌至8倍附近，则谨慎判断逆转

观点 7：融资端三步传导决定Q4基建企稳幅度

  • 观点归属： 经济学家蔡志鹏博士
  • 结论： 2500亿专项债+8000亿政策性金融工具加快投放+PSL降息25bp+纳入六张网，有望将Q3约4.3%拉至Q4 4.4%-4.5%，但传导弱于2022年
  • 前提事实： 9月政策性金融工具投放约1000亿涉4400项目、转向AI数字经济，远小于2022年超7000亿；2022年8-9月委托贷款+1800亿/11500亿后中长贷加速、基建9%升至下半年13%；三家政策性银行披露节奏8月下旬9月才加快
  • 推导逻辑： 政策金融工具补资本金 → PSL+贷款配配套融资 → 开工转实物量 → 委托贷款流量为领先线索 → 今年规模小+缺可融资项目 → 基建下滑仅收窄
  • 隐含假设： 需新批项目衔接短长期；PSL降息仅降成本不创项目
  • 反例 / 证伪条件： 若委托贷款与企业中长贷连续放量、海上风电等大项目获批，则基建反弹可超预期

观点 8：中欧混动车配额冲击出口与国内利润

  • 观点归属： 经济学家蔡志鹏博士
  • 结论： 即使避免关税战，数量管控仍迫使车企加速欧洲本土化，短期货量利润波动、国内内卷加剧
  • 前提事实： 混动车占中国车企对欧出口从2024年10%几升至今年前8个月40%-50%；欧洲已是头部车企重要增长源；企业可抢出口+优先高利润车型对冲
  • 推导逻辑： 配额忠实执行 → 对欧出口量受限 → 抢出口与高利润车型仅缓释 → 本土化转移需时 → 国内销量利润率承压，若扩至中间品化学品资本品医药影响更广
  • 隐含假设： 配额被较严格执行；欧洲本土化短期难完全替代出口利润
  • 反例 / 证伪条件： 若配额宽松执行、欧洲需求超预期或本土化盈利快速释放，则冲击显著小于预期
