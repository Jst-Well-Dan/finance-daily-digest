# 结构化笔记｜【2026-11-16最新】顶级投行摩根士丹利最新判断：预计要2028年才会降息

## 1. 核心结论

- **全球利率路径是“加息到顶后长期观望”，降息要到2028年。** 摩根士丹利预计美联储、欧央行、日央行均在2026年12月与2027年3月各加息25bp，随后分别维持至2027年底、2028年6月后、2028年底再开启降息；适用边界是核心通胀黏性不散、柴油等能源成本继续向食品与部分服务价格传导，若2027年核心通胀提前回到目标或增长失速，该路径会被推翻。
- **中国2027年是“调整之年”，不是“通缩之年”或“内需全面萎缩之年”。** 预计GDP增速4.4%（2026年约4.6%），内需贡献由3.5%降至3.1%、净出口贡献由1.3pp升至1.5pp；CPI 0.7%、核心CPI 0.8%、GDP平减指数约0.4%，PPI在2027年二季度后可能重新转负；成立条件是出口维持约12%增长、一二线房价2027年下半年低位企稳、财政仅温和收缩（广义赤字率11%→10.5%）。
- **居民部门去杠杆是内需偏弱的核心约束，消费修复是慢变量。** 过去13–14个月居民贷款余额累计下降近2万亿元，2027年消费实际增速仅3.2%（略高于今年主要因低基数与以旧换新扰动）；若社保征缴趋严、建筑业与部分服务业就业继续走弱，消费中枢抬升会更慢。
- **三个结构性力量支撑2028年后改善，但需要时间发酵。** 全球工业资本开支上行（亚洲年度资本开支2025年约11万亿美元→2030年16万亿美元）、AI与工业5.0放大中国制造优势（全球约28%制造业增加值、3万座以上智能工厂、数据中心用电占比2%→4%）、投资结构边际改善（工业5.0未来10年约12万亿美元增量投资以改造存量为主）；边界是短期AI出口对内需带动弱、地产尚未止跌、AI初期就业替代担忧仍在。
- **2028–2030年三大里程碑及资产含义明确但非全面看多。** 前沿产业收入由1.4万亿→3.2万亿美元、商品出口份额由约15%→16.5%、AI与工业5.0每年抬升潜在增速0.3pp至约4.2%；对应1年期国债利率1.6%→1.4–1.5%、10年期2030年回到1.8–2%、USD/CNY 2027年底6.6、2030年6.1–6.2；股票端仅“提高全球风险资产配置热情”，并未把中国整体上调至超配。

## 2. 专家观点与逻辑链

### 观点 1：能源成本黏在核心通胀，主要央行2028年才降息

- **观点归属：** 摩根士丹利全球宏观团队（邢自强及宏观团队）
- **结论：** 全球通胀2027年缓慢回落、2028年趋势才明确；主要央行2026年12月与2027年3月各加息25bp后进入长时间观望，降息周期2028年才启动。
- **前提事实：** 布伦特原油回落，但因炼化产能受损与运输问题，柴油等成品油与原油价格分化，柴油市场偏紧预计延续到2027年年中；运输与生产成本维持高位，并可能继续向食品和部分服务价格传导。
- **推导逻辑：** `能源成本黏在运输/生产/食品服务价格 → 核心通胀回落慢 → 央行需要更长观察期 → 到达终点利率后不急于降息 → 2028年通胀路径明确才开启降息`
- **隐含假设：** 财政不明显扩张、能源不出现二次冲击、通胀预期不脱锚、央行不以增长为唯一目标。
- **反例 / 证伪条件：** 2027年上半年核心通胀快速回到目标附近，或就业与增长明显恶化，首次降息可能提前至2027年；反之若柴油冲击扩散至工资，加息幅度可能超预期。

### 观点 2：美国“微妙的平衡”给了美联储加息的底气

- **观点归属：** 摩根士丹利（宏观团队转述美国经济判断）
- **结论：** 2027年四季度美国实际GDP同比约2.5%，略高于市场共识；2027年底失业率约4.3%；美联储2026年12月与2027年3月各加息25bp，随后维持至2027年底。
- **前提事实：** AI投资之外，高收入家庭受财富效应支撑、消费维持不错；就业市场“新增岗位不多但劳动力供给也被压降”，失业率只会温和上升。
- **推导逻辑：** `就业供需双缩 → 失业率仅温和上行 → 消费有基础、通胀有黏性 → 美联储有空间继续加息而非降息`
- **隐含假设：** AI资本开支不失速、资产价格不出现大跌导致财富效应逆转、移民与劳动供给政策不发生剧变。
- **反例 / 证伪条件：** 失业率快速升破4.5%–5%、消费信贷违约率跳升、AI投资出现拐点，则“再加息两次”的路径作废。

### 观点 3：欧洲与日本——同样的加息节奏，不同的政策阶段

- **观点归属：** 摩根士丹利宏观团队
- **结论：** 欧央行2026年12月与2027年3月各加息25bp后维持不变，直到2028年6月之后核心通胀进入明确下行通道再降息；日央行同样两次加息后维持到2028年底。欧洲通胀2027年初或达4.5%、全年3.4%，核心黏性明显。
- **前提事实：** 欧洲增长与美国不同但货币政策反应函数类似；日本走出长期通缩，但居民实际购买力偏弱，抑制继续加息空间；日本GDP增速今年约0.8%、明年降至0.5%、2028年温和回升。
- **推导逻辑：** `欧洲核心通胀黏性 + 增长尚可 → 继续收紧并长期维持；日本实际购买力弱 → 加息空间受限、节奏更慢 → 更晚回到中性利率`
- **隐含假设：** 欧洲不出现大规模财政宽松、日本工资—物价正循环延续但不过热、汇率不引发输入型通胀失控。
- **反例 / 证伪条件：** 欧洲增长失速或日本实际消费转弱，加息会暂停甚至转向；若日元大幅贬值推升通胀，日央行节奏可能快于预期。

### 观点 4：中国2027年“调整之年”——增长、通胀、财政与货币的组合

- **观点归属：** 蔡志鹏（摩根士丹利中国经济学家）
- **结论：** 2027年GDP增速4.4%，内需增速3.1%、净出口贡献1.5pp；名义GDP增速由5.8%降至4.8%；CPI 0.7%、核心CPI 0.8%、GDP平减指数约0.4%；广义赤字率11%→10.5%；政策利率维持1.25%；增长目标大概率设在4.5%左右。
- **前提事实：** 出口受AI、全球工业升级、能源安全与国防相关投资支撑，美元计价出口仍可维持约12%且广度拓宽；内需受地产调整、居民去杠杆、就业偏弱拖累；化债支持缩减2万亿元叠加土地收入下降挤压地方现金流，结转结余资金1.5–2万亿元形成缓冲；政策思路延续“托而不举”。
- **推导逻辑：** `外需强 + 内需弱 → 增长放缓但不断崖 → 低通胀延续、PPI二季度后重新转负 → 财政温和收缩、货币定向宽松但不降政策利率`
- **隐含假设：** 出口不遭遇全面贸易摩擦、地产不再大幅失速、财政不转向强刺激、能源与芯片涨价等实物因素继续消退。
- **反例 / 证伪条件：** 出口增速跌破5%、地产销售与投资二次探底、政策转向大规模刺激，则4.4%与低通胀判断需分别下修/上修；若贸易摩擦扩散至广泛双边领域，净出口贡献1.5pp不成立。

### 观点 5：居民去杠杆与消费的漫长修复

- **观点归属：** 蔡志鹏
- **结论：** 2027年居民消费实际增长3.2%，中枢偏低，消费修复是非常漫长的过程。
- **前提事实：** 过去13–14个月经借条调整后的居民贷款余额累计下降近2万亿元，家庭部门去杠杆“如火如荼”；建筑业与部分服务业就业偏弱；社保征缴进一步趋严，可能增加中小企业用工压力。
- **推导逻辑：** `收入与就业预期偏弱 → 家庭主动去杠杆 → 消费谨慎、储蓄倾向高 → 即使基数与政策微调，修复仍是慢变量`
- **隐含假设：** 房价预期不再快速恶化、就业政策有托底、以旧换新等政策扰动逐步消退。
- **反例 / 证伪条件：** 居民贷款余额重新持续正增长、青年失业率明显下降、二手房成交与价格同步回暖，则消费弹性可能显著高于3.2%。

### 观点 6：三个结构性力量与2028–2030年三大里程碑

- **观点归属：** 摩根士丹利宏观策略团队（转写中称 Jenny）
- **结论：** 2027年是调整年而非通缩年；2028年起宏观环境改善；到2030年实现前沿产业市场空间翻倍以上、制造份额扩大、潜在增速维持约4.2%三大里程碑。
- **前提事实：** 亚洲年度资本开支2025年约11万亿美元→2030年16万亿美元，增量近半来自广义工业投资、约两成来自AI/半导体及间接投资；中国占全球工业增加值约30%，工程设备、机械设备与零部件全球份额过半；工业5.0未来10年约12万亿美元新增投资，以存量工厂智能化改造为主；中国数据中心用电仅占全社会用电约2%，2030年升至约4%，美国已超6%；前沿产业收入1.4万亿→3.2万亿美元，九成增量来自AI、工业5.0与生物医药。
- **推导逻辑：** `全球资本开支上行 + AI改造存量产能 → 中国出口与制造份额扩张 → 产能过剩缓和、工业利润率修复 → 居民收入与内需改善 → 2028年起回到低通胀稳定环境`
- **隐含假设：** AI应用真实落地并提升生产率、反内卷与全国统一大市场能约束地方重复建设、地产2027年下半年企稳、海外不出现极端脱钩。
- **反例 / 证伪条件：** 全球资本开支周期下行、AI投资回报被证伪、地产继续下行、贸易摩擦全面升级，则“2028年改善”时点后移；若产能过剩程度未缓和，PPI与利润修复不成立。

### 观点 7：超节点——芯片受限下的“以长补短”

- **观点归属：** Andy（摩根士丹利科技硬件团队）
- **结论：** 超节点是中国AI基础设施的必然选择，市场规模由2025年百亿级增至2030年1万亿元、年均增速超100%；光互联（NPO）、高端PCB/CCL、电源、液冷、储能受益，CPO是大陆企业相对边缘的环节。
- **前提事实：** 单芯片制程受限、性能大幅落后海外GPU；中国长板在网络互联与光通信，具备国际领先的研发能力与产业生态；华为384超节点已成功发布并商用；2026年10月OCP会议形成“互联是下一步提升整体算力关键”的行业共识。
- **推导逻辑：** `单卡性能短板 → 用网络互联与系统级工程补足 → 超节点规模化商用 → 光模块、PCB、电源、液冷需求倍增`
- **隐含假设：** 国产芯片产能与核心零部件供给能跟上、客户愿意为生态付出耐心、美国管制不进一步切断关键设备与材料。
- **反例 / 证伪条件：** 国产先进制程突破使单卡性能追平（超节点必要性下降）、CPO路线被海外主导且大陆被排除、芯片产能瓶颈长期无解，则1万亿市场与100%增速不成立。

### 观点 8：资产含义——利率、汇率与股票配置

- **观点归属：** 摩根士丹利宏观策略团队
- **结论：** 未来12–18个月1年期国债利率由1.6%降至1.4–1.5%；10年期国债利率2030年回到1.8–2%；USD/CNY 2027年底6.6、2030年6.1–6.2；股票机会随产业升级扩散，但中国整体未上调至超配。
- **前提事实：** 信贷需求不足使银行资金不得不配置国债；准通缩环境拖慢人民币升值；工业投资回暖后企业融资需求回升、出口竞争力提升；产业升级拓宽银行、自有资金之外的融资渠道（离岸资金、点心债、可转债）。
- **推导逻辑：** `资产荒 → 短端利率下行；准通缩 → 人民币升值偏慢；产业升级 + 出口竞争力 → 中长期利率与汇率回升`
- **隐含假设：** 央行不主动大幅下调政策利率、资本流动管理框架不变、美国降息路径如其所料。
- **反例 / 证伪条件：** 信贷需求突然回暖、人民币快速升值、美联储降息大幅提前，则短端下行与汇率路径需修正。
