1. 【2026-11-12最新】付鹏最新直播《AI资本支出与中美市场》 为什么有时会突然跌得很急？ | Why leverage can turn a sell-off into a rush

一句话：AI行情核心变量是上游资本支出周期位置而非成长故事，杠杆放大急跌，美股重防守、A股不输即赢。

  1. 本轮 AI 行情的核心变量是上游资本支出的周期位置，并非“成长故事”。 按付鹏框架，Q2（6–7 月）起已进入“买铲子的人钱花得差不多、卖铲子的人订单还在但预期已悄然转变”的阶段；他判断未来 3–5 年 AI 硬件（卖铲子环节）将从成长性定价转为周期性、价值性定价。边界： 该判断针对硬件/算力链，不直接适用于应用端；需以毛利率见顶、订单违约与 Capex 指引下修为验证，若应用端收入加速或毛利率重回升势则前提动摇。
  2. “台风”未过：宏观流动性与利率仍在收紧一侧。 美债短端上行、长端回落形成熊平，通胀与就业数据不弱、联储官员暗示可能再加一次，说明不能把“加息/降息”与“买/不买股票”做点对点映射，中间有完整传导链路。边界： 以美债收益率结构与通胀、就业数据为观察；若短端见顶回落、曲线转陡，则“台风”前提改变。
  3. 当前美股更像结构性、防御性切换，尚未到系统性下跌。 必选消费、红利上涨，半导体与 AI 资本支出链下跌；资金向“不晃的楼”集中推高集中度，英伟达、谷歌、Meta 等核心权重开始晃动，指数稳定性因此变差。边界： 若下跌扩散至全板块、防御板块同步下跌、信用利差走阔，才升级为系统性风险。
  4. “跌得很急”的最微观解释是杠杆。 产业、宏观、市场三层因子都未消退时，最后一层要看交易商 delta/gamma、场外配资与融资盘；负 gamma 环境下，意外事件会触发被动减仓、流动性瞬间消失，形成急跌或踩踏。边界： 若隐含波动率未抬升、dealer gamma 转正、融资余额未被动去化，则急跌缺少微观放大器。
  5. 中美市场方法论不同：美股靠“躲避球”，A 股靠“不输即是赢”。 美股以斜率与波动率为核心，分散后收益趋近指数，超额来自避开回撤（右手端/对冲）；A 股以波动为核心、斜率供给少，系统性下跌时普遍下跌，故更重选股（左手端），当前环境下“不输即是赢、不折腾即是赢”。边界： 若 A 股分红回购与长钱入市提升指数斜率、对冲工具普及，结论需重估。

2. 专家观点与逻辑链

观点 1：本轮 AI 是资本支出周期，“买铲子/卖铲子”关系决定拐点

  • 观点归属： 付鹏（主讲人）
  • 结论： 本轮 AI 由上游资本支出驱动，当前处于“买方现金流消耗到位、效应未现，卖方订单仍在但预期已转”的窗口期，硬件环节将失去成长性估值。
  • 前提事实： 他称自 7 月左右持续讲该逻辑；可比历史为 1998–2000 年互联网光纤 Capex 与 2002 年“要想富先修路”的钢铁、水泥、沥青、基建周期；Q2 起他反复强调自由现金流（free cash flow）转弱。
  • 推导逻辑： 资本支出前期扩张（订单与估值齐升） → 买方现金花得差不多、应用效应未现 → 卖方订单尚在但预期转向 → 卖铲子环节估值由成长切向周期
  • 隐含假设： AI 应用端收入兑现慢于硬件 Capex 投放；本轮与历史 Capex 周期在资金结构上可比。
  • 反例 / 证伪条件： 应用端收入加速、Capex 指引继续上修、毛利率重新上行；或本轮主要由自有现金流支撑、不依赖外部融资，则利率与融资敏感性显著下降。

观点 2：毛利率是周期拐点的领先指标，远期订单不等于锁定收入

  • 观点归属： 付鹏
  • 结论： 毛利率见顶早于利润、早于销售数据见顶，是成长转成熟/衰退的节点；远期订单存在违约与不执行风险，市场却常把它当作已锁定收入。
  • 前提事实： 他以思科 1999–2000 年为例，称其后出现大量订单违约与不执行；并称中国新能源车产业链某一环节约半年前毛利率见顶，股价随后下跌 30%–40%；信用违约掉期（CDS）的存在本身说明远期承诺有违约风险。
  • 推导逻辑： 毛利率见顶 → 产业红利转为内卷抢份额 → 利润与销售随后走弱 → 估值下杀
  • 隐含假设： 毛利率数据未被会计口径扭曲；价格战首先体现在毛利率而非订单簿。
  • 反例 / 证伪条件： 毛利率短暂回落后创新高（成本下行或提价成功）；订单以预付、长期合同锁定且违约率极低。

观点 3：宏观“台风”指利率与流动性，当前仍在

  • 观点归属： 付鹏
  • 结论： “台风”是宏观层变量——流动性紧不紧、利率高不高；当前短端利率上行甚至创新高、长端回落，呈债券熊平，台风未过。
  • 前提事实： 通胀与就业数据表现不错；美联储官员表态可能再加一次；短端收益率创新高、长端小幅回落。
  • 推导逻辑： 通胀/就业不弱 → 短端利率上行、曲线熊平 → 流动性偏紧 → 高估值资产挤泡沫；同时 1% 与 7% 发债的成本差异改变市场敏感度
  • 隐含假设： 利率通过贴现率与再融资成本传导至估值；流动性宽松易生泡沫、收紧易挤泡沫。
  • 反例 / 证伪条件： 短端见顶回落、曲线转陡；或企业现金流充裕、不依赖再融资，则利率上行的杀伤有限。他同时反对“联储不加息所以买股票”式的点对点推论。

观点 4：市场层是结构性防御切换，集中度上升使指数变脆

  • 观点归属： 付鹏
  • 结论： 美股当前不是所有板块齐跌，而是防御性切换：必选消费、红利上涨，半导体与 AI 上游资本支出链下跌；资金集中到“不晃的楼”，核心权重开始晃后，指数稳定性变差。
  • 前提事实： 分化已持续数月；英伟达、谷歌、Meta 等“七姐妹”核心权重波动加大；他年初受访时称“指数可能只跌 3%–7%，但个股可能跌 60%–70%”。
  • 推导逻辑： 产业因子走弱 → 资金撤离 AI 链、涌入防御与红利 → 集中度上升 → 核心权重一晃，指数波动放大
  • 隐含假设： 防御板块上涨足以对冲 AI 链下跌；风险尚未扩散到整体经济。
  • 反例 / 证伪条件： 下跌扩散至全板块、防御与红利同步下跌、信用利差走阔 → 升级为系统性风险；或核心权重业绩再超预期、波动率回落 → 结构性判断弱化。

观点 5：突然跌得急，最微观的一层是交易商杠杆

  • 观点归属： 付鹏
  • 结论： 到了最微观的传导层，已不需再分析产业、公司、订单与利率，而应分析杠杆；负 delta、负 gamma 的环境下，意外事件容易引发恐慌与极端踩踏。
  • 前提事实： 他称当前在跟踪交易商的“负 delta、负 gamma”；类比 2015 年 A 股场外配资、伞形信托、零保证金股指期货等场外杠杆。
  • 推导逻辑： 负面意外 → 做市商与杠杆盘被动同向减仓（负 gamma） → 流动性瞬间消失 → 急跌/踩踏
  • 隐含假设： 期权做市商对冲行为同向；杠杆盘集中度足够高、平仓触发点相近。
  • 反例 / 证伪条件： 隐含波动率未抬升、dealer gamma 转正、融资余额未被动去化 → 急跌缺乏微观放大器。他给出的检查顺序是：台风因子、产业链周期因子、市场因子、交易商因子是否都已结束；未结束则应先评估极端风险，而非追问“是不是跌完了”。

观点 6：美股方法论——“会卖的是躲避球”，关键在右手端

  • 观点归属： 付鹏
  • 结论： 美股以斜率与波动率为核心，宽基已替投资者筛出优质公司；体量大的资金分散后收益趋近指数，真正的超额来自避开回撤（右手端/对冲），而非选股（左手端）。
  • 前提事实： 管理 20–30 亿美元以上必然分散，长期回报与跟标普 500 的人接近；社交媒体上高杠杆散户回撤 20% 即出局；巴菲特左手不轻易调仓，右手会在阶段内增厚现金、做波动率对冲。
  • 推导逻辑： 分散化 → 收益≈指数 → 差异化只剩回撤控制 → 躲避球决定相对排名
  • 隐含假设： 指数长期向上、成分股优胜劣汰机制有效；衍生品与对冲工具可获取。
  • 反例 / 证伪条件： 市场长期横盘或系统性下跌（指数不再提供斜率），躲避与选股逻辑都需重估；小资金集中持仓仍可能取得超额。

观点 7：A 股方法论——波动为核心，“不输即是赢”

  • 观点归属： 付鹏
  • 结论： A 股以波动为核心、斜率供给少，系统性下跌时普遍下跌，因此投资者更在意“买什么”（左手端），躲避的意义有限；当前环境下“不输即是赢、不折腾即是赢”。
  • 前提事实： 他认为 A 股指数难以提供稳定斜率；下跌多为系统性；游资会在主线空窗期利用小板块与话题（如 AI 漫剧）制造热度，甚至通过传媒公司群、短视频投流配合。
  • 推导逻辑： 指数斜率低 → 收益需靠选股 → 系统性下跌时选股失效 → 控制不亏优先于追求收益
  • 隐含假设： A 股系统性风险频率高于美股；个人难以通过衍生品有效对冲。
  • 反例 / 证伪条件： 分红回购与长钱入市提升指数斜率、对冲工具普及，则“躲避无用”的前提改变；若市场转为系统性上涨，过度防守会牺牲收益。

观点 8：市场功能决定财富效应——投资市与融资市

  • 观点归属： 付鹏
  • 结论： 若市场主要功能是融资（IPO、大股东减持、手续费、券商与交易所抽成），净额为负则只剩参与者之间的零和博弈，不产生居民财富效应；若以投资为主（分红、回购），才有正向财富效应并传导至消费。
  • 前提事实： 外卖小哥称“股市下跌接不到单”，随后被人用平台数据增长反驳；美国有 401K 计划、给年轻人发股票账户等安排。
  • 推导逻辑： 融资抽血 > 分红回购 → 净负和 → 多数参与者是被分配方 → 下跌时消费受冲击
  • 隐含假设： 股市财富效应主要作用于边际消费倾向高的人群；市场分配结构决定体感。
  • 反例 / 证伪条件： 分红回购净额转正、长期指数年化回报改善；或外卖单量变化主要由平台竞争、季节等个体因素解释（他本人也提示“不要太较真”）。

观点 9：创始人 IP 是估值的双向加速器（不对具体个案下判断）

  • 观点归属： 付鹏
  • 结论： 企业家/创始人 IP 化已成为营销与市值管理手段，正向时抬估值、聚粉丝、促购买，反向时同样产生反噬、加速股价下跌；但他明确拒绝讨论具体人物与事件真相。
  • 前提事实： 过去十余年企业家陆续做播客、发社交媒体；他称近一两年已有多家知名公司“中招”；IP 运营已从公关营销部门延伸到市值管理部门。
  • 推导逻辑： IP 塑造 → 粉丝与情绪溢价 → 公共事件冲击 → 情绪折价 → 加速下跌
  • 隐含假设： 市场情绪对估值存在可观察的溢价/折价；IP 与股价有相关性。
  • 反例 / 证伪条件： 事件后基本面与资金面未变、股价迅速修复；或统计上 IP 事件与股价无显著相关。该条不构成对任何个人的事实认定。

观点 10：人口周期决定教育行业衰退与“医区房”逻辑

  • 观点归属： 付鹏
  • 结论： 由 2015 年新生儿数量大幅下降可倒推学龄人口依次见顶，幼儿园、小学已出现关停并转，幼教/教培不是好行业；学区房逻辑将让位于“医区房”，医疗资源可达性更重要。
  • 前提事实： 发改委相关表述称幼儿园、小学、初中学龄人口已达高峰；多地民办园校陆续撤并（也含制度与监管因素）；他以带家人就诊为例，称急救“半小时内最佳、一小时凑合，再久参考价值有限”。
  • 推导逻辑： 出生人口下降 → 学龄人口依次见顶 → 教育资源过剩、学历贬值 → 学区房溢价下降；老龄化 + 急救时效 → 医疗资源稀缺性上升
  • 隐含假设： 人口趋势短期不可逆；医疗资源分布难以快速均衡。
  • 反例 / 证伪条件： 出生率显著反弹；分级诊疗、远程急救与交通改善大幅降低地理依赖。

观点 11：AI 漫剧/短剧不会长期成瘾，生命周期约半年到一年

  • 观点归属： 付鹏（含其个人使用体验）
  • 结论： 短剧与 AI 漫剧的同质化供给会迅速抬高刺激阈值，70%–80% 用户在约半年到一年内出现审美疲劳；此后精品剧、长剧可能反杀。
  • 前提事实： 他自述使用“红果”已接近脱敏；同一 IP 被多个工作室同时制作，题材集中于穿越、金手指。
  • 推导逻辑： 低门槛供给爆发 → 多巴胺刺激边际递减 → 审美疲劳 → 流量与相关估值回落
  • 隐含假设： 内容同质化速度快于需求增长；用户阈值只升不降。
  • 反例 / 证伪条件： 持续出现差异化精品、付费率与留存抬升；平台算法改善匹配效率、延长生命周期。

观点 12：7×24 交易时代，散户应转向配置而非盯盘

  • 观点归属： 付鹏
  • 结论： 主要市场延长交易时段后，个人盯盘的性价比进一步下降；散户应拉长周期、转向配置与被动化，主动交易比例下降是必然结果。
  • 前提事实： 美股拟推行 7×24 交易；韩国等市场也在变化；他举例有朋友因全天候看盘而失去生活。
  • 推导逻辑： 交易时段拉长 → 信息与精力门槛上升 → 个人短线劣势扩大 → 被动配置占比提升
  • 隐含假设： 交易时长增加不改善个人的信息与执行优势。
  • 反例 / 证伪条件： 工具化、算法化显著降低个人参与门槛；或长时段为短线策略提供更多机会。
