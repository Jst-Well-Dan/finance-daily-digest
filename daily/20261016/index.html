结构化笔记｜大摩内部闭门会（2026-10-16最新附文稿）AI下一个缺货王曝光！大摩：台积电2纳米明年翻倍，ABF载板缺到2028，腾讯AI单季烧掉150亿

1. 核心结论

  • 台积电2纳米激进扩张确认AI需求远超供给： 考虑融资成本、电力、ABF缺货后仍判断客户需求远大于供应，明年底2纳米产能more than double；适用条件为AI代工需求不出现断崖式下修且美国德州、台湾新厂环评与设备交付如期，仅适用于2026-2028年供给紧张窗口。
  • ABF载板27-28年缺口扩大、涨价由材料转供给驱动： 计入全部已宣布扩产后27年供给缺口约9%、28年约14%（较前估6%/9%扩大），27年like-for-like涨幅25%以上；适用条件为两年至两年半建厂周期+设备排队不变，且ASIC/中国AI芯片与server CPU尺寸假设成立，不适用于扩产大幅提前或需求证伪情形。
  • 腾讯进入AI投入期，Q3为利润负增长起点： Q3收入+8.9%放缓、剔除AI后经营利润可+10%，但新AI产品单季亏损约150亿元致报表OP约-3%，H2两季均为负增长、2027年模型仅flat；适用条件为游戏维持增长以托住top line且AI capex/opex节奏不进一步加速，若回报visibility提前则结论上修。
  • 京东便宜但为价值陷阱、三星存储更看供给而非当季数字： 京东Q4零售仅中个位数增长、履约研发高企+新业务全年亏损拖累，明年核心利润最多稳住；三星应对长存竞争靠技术投入抢份额、HBM不签LTA赌涨价；以上仅适用于消费偏弱+竞争投入不收缩环境，若外卖/海外投入收敛则需重估。

2. 专家观点与逻辑链

观点 1：台积电法说会传递超强扩张信号

  • 观点归属： 大摩大中华科技团队 Charlie（台积电法说会点评）
  • 结论： AI半导体需求远大于供应，台积电决定继续激进扩张，上调明后年资本开支与2028年EUV交付预期，维持买入评级。
  • 前提事实： 已考虑代工外变数（financing cost、电力供应、ABF缺货）；2纳米今年底约10万片/月，大摩原估明年底16万片，台积电指引more than double即约20万片；2028年EUV交付量比2027年多20-30%；当季毛利率66.4%为指引上缘。
  • 推导逻辑： 需求远超供给确认 → 美国德州看地+台湾新3纳米fab+2纳米翻倍 → 上调topline与CapEx模型，margin短期稀释但无基本面问题 → 维持目标价与买入
  • 隐含假设： 客户愿意承担海外2纳米dilution与适度涨价；美国客户需求持续强劲；Intel外包与先进封装合作不冲击台积电定价权。
  • 反例 / 证伪条件： 若明年海外厂dilution超预期致毛利率持续低于指引区间，或Intel/MediaTek先进制程回流失败致需求下修，则激进扩张逻辑证伪。

观点 2：ABF载板新增投资不改变看多，缺口反而扩大

  • 观点归属： 大摩 Irene（ABF substrate update报告）
  • 结论： YTD约140亿美元资本支出宣布不改变上行周期判断，27年缺9%、28年缺14%，偏好欣兴 over 南电。
  • 前提事实： 三星电机越南厂2028年9月才量产；南电嘉义新厂2029年下半年才放量，为集团史上最大ABF投资；今年新宣布扩产要2-2.5年后才开出；需求端上修ASIC及中国AI芯片、更新server CPU/网通芯片form factor。
  • 推导逻辑： 设备排队+土建找地耗时 → 新产能来不及解27-28年缺口 → 缺口从6%/9%扩大至9%/14% → 涨价从今年转嫁T-glass/CCL转为明年载板自身吃紧 → 产能增速成为分化因子 → 偏好欣兴
  • 隐含假设： 所有厂商均在大陆以外扩产致建厂更慢；每芯片尺寸与层数假设稳定向上；报价能见度虽低但吃紧必然传导。
  • 反例 / 证伪条件： 若设备交期大幅缩短、新厂提前放量，或AI ASIC需求下修/尺寸缩小致面积需求下降，则缺口与25%+涨价假设失效。

观点 3：三星存储看供给ramp与股东回报，不签HBM长约

  • 观点归属： 大摩 Cassy转述伦敦与三星管理层交流
  • 结论： 当季业绩数字本身不重要，关键是供给ramp速度、应对长存竞争与股东回报mix，HBM不签LTA、foundry目标做老二。
  • 前提事实： 管理层承认长存为不容忽视对手且已具备自主设计能力；应对为坚定投入技术+增供给抢份额；股东回报在现金分红/普通股回购注销/优先股回购注销间平衡，明年1月给mix；HBM认为未来涨价空间大故不签LTA，通用LTA为5年滚动续签。
  • 推导逻辑： 长存扩产+自研能力上升 → 三星以技术与份额优先而非控价 → HBM涨价预期下拒绝锁价 → 以滚动长约观察需求 → 资金流向computing networking
  • 隐含假设： 存储周期信仰仍在，技术领先可抵消中国供给冲击；HBM价格上行持续；foundry第二名可见度高不需大幅降价抢单。
  • 反例 / 证伪条件： 若长存良率与产能超预期提前进入主流HBM且成本具竞争力，或HBM价格反转下跌，则不签LTA与增供给策略受损。

观点 4：京东Q4零售转弱+新业务持续烧钱，维持Underweight

  • 观点归属： 大摩 Cassy（京东三季度preview）
  • 结论： Q3收入利润指引in line但无意义，Q4零售收入仅中个位数、OP margin承压，全年non-GAAP净利约300亿元，估值便宜是价值陷阱。
  • 前提事实： 去年Q4 3C家电基数不低，日百与3P从双位数下调至高个位数；毛利扩张放缓+研发履约费用高企；Q3新业务亏损95-96亿元，其中外卖环比减亏至略低于60亿元，Q4外卖亏损指引收窄至50亿元以下，但Joybuy跨境投入扩大；无退出外卖打算、海外投入坚定。
  • 推导逻辑： 核心零售增速下修+费用刚性 → Q4及明年OP margin承压 → 外卖减亏被跨境投入抵消 → 新业务亏损可见度低 → 低估值无法兑现 → 维持underweight
  • 隐含假设： 整体消费需求持续偏弱；外卖效率优化无法弥补单量与补贴压力；市场此前预期为高个位数增长。
  • 反例 / 证伪条件： 若Q4零售重回高个位数、或外卖亏损收窄超预期且海外投入放缓致新业务亏损明显低于预期，则价值陷阱判断证伪。

观点 5：腾讯Q3利润负增长，2027年由能否增长转向跌多少

  • 观点归属： 大摩互联网团队 Rebecca（腾讯preview）
  • 结论： Q3收入+8.9%、报表OP约-3%，新AI单季亏约150亿元，下半年持续承压，2027年暂估flat，维持Overweight、目标价550港元，催化为混元4与10月29日生态大会。
  • 前提事实： 游戏+7.8%（本土+13%、国际因高基数低个位数下滑）、广告+18%、金融科技与企业服务+8.7%；剔除AI后OP可+10%；2026全年non-IFRS OP仍可正增长；2027年模型约2200多亿元，buy side担忧下滑幅度；年化Q2 capex推算2027年约2400亿元。
  • 推导逻辑： 收入放缓+AI capex折旧与opex加速 → 150亿亏损抵消核心盈利 → Q3/Q4各-3% → 全年勉强正增长 → 2027年取决于游戏新游pipeline与AI投入节奏 → 回报期visibility低但core无忧 → 维持买入等微信AI Agent落地
  • 隐含假设： 游戏能维持增长托底top line；混元4能力与开发者采用达预期；市场已price-in下半年负增长，分歧只在幅度与时长。
  • 反例 / 证伪条件： 若Q3实际OP下滑远超3%、或2027年top line失速+AI投入再加码致flat无法守住，或微信AI Agent无实质进展，则买入逻辑与550港元目标需下修。

观点 6：长存无EUV路径短期难撼主流市场，属长期overhang

  • 观点归属： 大摩 Charlie（回应CXMT无EUV为何市场反应强烈）
  • 结论： DUV多重曝光与4F squared架构均存在良率/cycle time未知数，HBM主流商业化1-2年内至多有限替代，2-3年后才谈成本竞争，当前更多是情绪面卖出借口。
  • 前提事实： 广州工博会称DUV实现约7纳米节点；行业专家称做得到但cycle time与良率未知；4F squared能否完全避开EUV不确定，最快量产节奏不明；HBM通过新法先叠后通孔可达6.4Gbps，未到7.2Gbps。
  • 推导逻辑： 无EUV只能靠DUV多重曝光或改架构 → 良率与设备卡点未知 → 主流HBM竞争力不足 → 市场此前低估其HBM能力，现修正预期 → 短期情绪冲击、长期才有基本面冲击
  • 隐含假设： 设备瓶颈位置与良率爬坡需2-3年验证；国产替代先从HBM小批量切入；成本竞争是最终裁决因子。
  • 反例 / 证伪条件： 若CXMT以DUV实现高良率低成本量产并通过主流客户验证，或国产HBM速率达7.2Gbps以上规模出货，则长期overhang提前变现为短期冲击。
