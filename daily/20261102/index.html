2. 专家观点与逻辑链

观点 1：美国中期选举与高利率挤压

  • 观点归属： 邢志强（Robert，大摩宏观策略主持）
  • 结论： 基准为分裂国会；白宫受困国内立法后更频繁动用关税/出口管制；高利率已挤出高杠杆低评级企业，美联储只会从容校准加息而非激进加息；黄金对冲的是美债信用而非美股大跌。
  • 前提事实： 市场定价民主党小胜概率90%以上、大胜约2/3；美国多州放缓/暂停AI数据中心审批；美国投资级企业债收益率上行至6%附近、政府年赤字超2万亿美元；美国处雇人不增也不大裁员的平衡状态、工资增速放缓。
  • 推导逻辑： 关税地缘归行政权→分裂国会束缚国内立法→对外工具使用频率上升；AI资本开支翻倍+巨额发债抢资金+油价高企→弱资质融资缺口显现→高利率伤害先在水下裂缝体现
  • 隐含假设： 就业不过热使温和加息足够；地方电费民怨会转化为数据中心政策风险。
  • 反例 / 证伪条件： 若民主党大胜横扫或共和党守住两院，则分裂国会假设失效；若就业重新过热或通胀再上行，则从容加息假设失效；若美股暴跌时黄金不跟跌而大涨，则黄金判断失效。

观点 2：AI泡沫三层次框架

  • 观点归属： 蔡志鹏（大摩亚洲经济学家）
  • 结论： AI是真实深刻的技术革命，但可能伴随局部投资过度与资产价格调整；硬件看超级周期但周期未消失，头部hyperscaler基础情形仍有约30% ROIC，全社会回报需时间验证。
  • 前提事实： 历史5次技术浪潮均是初期大资本开支、基建先于生产率兑现、伴随泡沫与调整；互联网时期光纤/数据中心过度投资后成为数字经济基础；2025年以来广义AI带动投资贡献美国GDP年化约0.6个百分点；AI投资占GDP约3.5%已超历史峰值。
  • 推导逻辑： 历史规律：基建先行→生产率后兑现→初期必有泡沫调整→AI当前处基建期+生产率初现→长期看多但短期需忍受调整分化
  • 隐含假设： AI扩散速度约为互联网2倍且不引发大规模失业；GPU租赁价格、利用率、折旧假设稳定；能找到与Agent AI同量级的可持续付费需求。
  • 反例 / 证伪条件： 若高暴露行业生产率改善证伪、算力价格大跌或利用率骤降致ROIC远低于30%、或长期无新付费场景，则泡沫化程度需上调。

观点 3：中国K型分化与治标治本

  • 观点归属： 邢志强 + 蔡志鹏
  • 结论： 上行一撇窄，出口强但资本密集对就业工资外溢弱；上游价格改善不是全面再通胀；治本需反内卷落实+财政从跟着项目走转向跟着人走，否则仅靠资金托市只能治标。
  • 前提事实： AI硬件、新能源出口好，服装家具等消费品出口价格仍弱；服务业平减指数同比从二季度1.2降至三季度0.7；10月政府债与政策性银行发行加快、8000亿新型政策性融资工具投放、9月基建降幅收窄但10月建筑业PMI仍低于50；央行政策利率由7天1.4%换锚隔夜1.25%，期限溢价约6-9bp属温和宽松。
  • 推导逻辑： 供给端政策+地方重复建设→巨额折旧+价格战→只赚吆喝不赚钱→需控补贴+投存量改造+投于人→2829年渐进走出低物价循环
  • 隐含假设： 中央财政有空间扩大按揭贴息至存量房贷、充实灵活就业社保；资金能转化为开工与就业收入改善。
  • 反例 / 证伪条件： 若出口拓宽至劳动密集型并带动工资消费、或PPI/服务业价格全面回暖，则需求弱假设失效；若资金长期沉淀无实物量，则托而不举延续。

观点 4：亚洲能扛单一风险、怕三重共振

  • 观点归属： Derek（大摩亚洲经济学家）
  • 结论： AI放缓、高利率、油价上涨单独看对亚洲增长影响温和；三者同现且持续才会带来明显下行压力。
  • 前提事实： AI+能源+半导体仅占2025-2030亚洲资本开支增量约20%，另有能源、防务、工业升级、供应链安全支撑；亚洲出口同比约25%、经常顺差约4.2%GDP创2008年来新高、企业债/GDP低于疫情前；中印日韩泰炼能可满足本国相当需求、政府限油价传导。
  • 推导逻辑： 资本开支来源多元→AI放缓不等于周期结束；强出口+高顺差+健康资产负债表→可抵消高利率；贸易条件改善+炼能+限价→可吸收油价→三者同破阈值才失守
  • 隐含假设： 科技出口价格上涨可持续对冲原油进口成本；政府限价 capacity 在120美元/3-6个月内有效。
  • 反例 / 证伪条件： 若油价持续高于120美元3-6个月被迫放开国内燃油价、央行被迫超预期更快加息、2027年AI资本开支低于2026年，三条件齐现即触发下行。

观点 5：国家队子弹测算与选股框架

  • 观点归属： Laura（大摩中国市场策略）
  • 结论： 国家队10月首周后高调入场，1-2个月内有望见绝对底部反弹，12月中前为观察窗；按股息率向借贷成本收敛测算沪深300还有约10%上扬空间；聚焦28只高股息超配沪深300成分股；估值已近历史大底。
  • 前提事实： 证监会+央行座谈会研讨稳定市场；924模式3000亿回购+5000亿增持再贷款已于2025年5月合并，利率更优惠、上限约2%、期限延至3年；至10月中旬1113个申请合计约2300多亿，8000亿剩约5500亿（约70%）未用；沪深300现股息率2.2%、PE 11.6倍，历史大底10-11倍。
  • 推导逻辑： 高调信号+充足低成本额度→参与者愿将股息率压至资金成本→2.2%向2%收敛→指数上行约10%；历史高调干预后1-2个月见底→12月中前磨底反弹
  • 隐含假设： 无上限式承诺的沟通效力仍在；A股调整主因之一是与美股AI交易共振，美股波动能在年底被消化；股息可持续。
  • 反例 / 证伪条件： 若会后无新增流动性支持、无924式坚定措辞，或美股AI资本开支预期持续下修、中期选举后波动不收敛，则反弹时点与空间证伪；若沪深300跌破10倍PE，则转为更好买入点而非逻辑破坏，需重估盈利。

观点 6：医药外包与AI制药验证链

  • 观点归属： Lawrence（大摩医药行业分析师）

1. 核心结论

  1. 中期选举基准情形是民主党小赢形成分裂国会，对中美关税、地缘博弈、科技出口管制影响有限；适用条件/边界：仅在小赢/分裂国会下成立，若出现大赢（参众两院横扫，市场预期约2/3）则对AI监管、财政收缩、财政悬崖含义不同，且分裂后白宫受限反而可能更频繁动用行政权对外工具。
  2. AI周期担忧核心已从需求转向融资挤出+地方抵制：全球AI资本开支约5000亿（2025年）→近9000亿（今年）→或1.5万亿美元（明年），云巨头单家潜在发债超2000亿美元与美2万多亿财政赤字抢资金，叠加美债~5%、投级债~6%、高油价及德州/俄亥俄/宾州等放缓数据中心审批；适用条件/边界：适用于高利率+从容加息延续期，选举后1-3个月地方政策明朗化前为高风险观察窗。
  3. 美联储主席Kevin沃尔将采取从容、不紧不慢加息以收回去年不该降部分（如明年3月再加一次后停手），不会超预期大幅加息；适用条件/边界：前提是美国就业紧平衡（不增雇也不大裁员）、工资增速放缓、无就业过热，若高油价致通胀预期失控或就业骤变则证伪。
  4. A股稳定依赖国家队+8000亿工具余量与美股企稳共振：互换/再贷款8000亿已申请约2330亿（1113个申请，截至10月中旬），仍剩约5500亿（约70%），现沪深300股息率2.2%对借贷成本≤2%隐含约10%上行空间，历史规律为高调信号后1-2个月（12月中前）触底，但需924式“无上限”承诺力度及美股AI止跌；适用条件/边界：仅适用于高股息+沪深300+大摩超配筛选（28只），现11.6倍PE距10-11倍历史大底仅5-10%空间，波动仍高，不宜死磕AI单赛道。

2. 专家观点与逻辑链

观点 1：中期选举分裂国会与行政权主导对外政策

  • 观点归属： 邢志强（宏观策略主持）
  • 结论： 小赢致分裂国会为基准情形，关税与地缘博弈不受国会影响，分裂后白宫反而可能更多动用对外工具。
  • 前提事实： 市场预期民主党小赢概率90%以上，大赢概率近2/3；关税、地缘、科技管制属白宫行政权；北卡第三选区、佛州第七选区为先行指标，美东选举日晚7:30后可跟踪。
  • 推导逻辑： 国会变天管立法财政→关税管制属行政权不受限→国内立法受阻→白宫转向对外挥舞关税/管制大棒
  • 隐含假设： 行政权边界不变，国会不通过新法实质约束白宫对外权限。
  • 反例 / 证伪条件： 出现大赢致财政/监管大变，或法院/国会实质限制行政关税权，则结论失效。

观点 2：AI融资挤出与地方电费反弹

  • 观点归属： 邢志强（宏观策略主持）
  • 结论： AI风险在水下裂缝：大厂称算得过账，但弱资质与边缘AI融资成本已被挤压，叠加地方对数据中心审批放缓。
  • 前提事实： AI资本开支翻倍式上升至明年或1.5万亿≈美国防预算；云巨头发债抢资金致投级债收益率上行至6%；多州居民对电费涨价不满，德州、俄亥俄、宾州等阻力加大。
  • 推导逻辑： AI资本开支飙升+财政赤字发债→抢夺流动性致利率上行→高杠杆低评级先被挤出+地方限电审批→AI硬件板块风险
  • 隐含假设： 发债规模如期落地，电力约束不快速缓解，利率维持高位。
  • 反例 / 证伪条件： 若发债远低于2000亿/家、利率快速回落，或地方审批未收紧，则挤出证伪。

观点 3：美联储从容加息与就业紧平衡

  • 观点归属： 邢志强（宏观策略主持）
  • 结论： 美联储不会激进加息，仅做政策校准，规模不超预期。
  • 前提事实： 高频数据显示美国不再增雇也不大裁员；工资增速放缓，无大规模过热；中东未决、高油价压制下仍需兼顾融资挤出。
  • 推导逻辑： 就业紧平衡+工资放缓→无大幅加息紧迫性→仅收回去年过度降息→加息节奏从容
  • 隐含假设： 通胀预期不因油价失控，就业不出现非线性恶化。
  • 反例 / 证伪条件： 若就业重新过热或通胀预期跳升致连续超预期加息，则结论失效。

观点 4：黄金只对冲财政信用，不对冲股市下跌

  • 观点归属： 邢志强引述跨资产团队
  • 结论： 看空美股盈利不应买黄金对冲，看空美债信用才应配置黄金分散。
  • 前提事实： 过去20年美股暴跌时黄金跟跌；近5年美债遭抛售、担忧赤字与美元信用时黄金抗跌。

  • 隐含假设： 历史相关性延续，财政赤字担忧仍是黄金定价主因子。
  • 反例 / 证伪条件： 若出现美股暴跌而黄金独立大涨的避险模式，则结论证伪。

  • 隐含假设： 剩余额度能实质落地，沟通措辞接近924力度，美股AI不持续大跌拖累。
  • 反例 / 证伪条件： 若无新增/无上限承诺、美股AI继续震荡大跌，或资金申请不用、sell on rally，则反弹推迟或失效。

  • 隐含假设： 反内卷能落实到招商补贴、欠款规范，财政体制能转向。
