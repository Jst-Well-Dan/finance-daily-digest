  • 结论1：大厂AI投入是囚徒困境下的被迫跟进，而非ROI驱动。 适用条件/边界：仅适用于已靠上一轮互联网垄断积累现金流的头部大厂（微软、谷歌、Meta、阿里、腾讯等）；不适用于无垄断现金流的跟风者。
  • 结论2：2026年Q2全球金主自由现金流转负是上下半场切换的临界信号。 适用条件/边界：仅作为存量家底烧干、被迫转向外部融资的框架信号；外围宏观因素（油价、利率）为次要扰动，不改变该框架。
  • 结论3：当前已从“存量烧干”进入“流量受损”阶段，新旧现金流断档。 适用条件/边界：前提是旧业务现金流被AI自我颠覆蚕食、且下游杀手级应用收入仍不能覆盖算力折旧与推理成本；若下游出现规模化变现则结论失效。
  • 结论4：后市核心是杀估值而非即时杀基本面，寡头熬冬天、跟风者面临出清。 适用条件/边界：适用于重仓上游硬件及高杠杆追高的投资者；无杠杆、低仓位者不受此约束；具体杀手级应用出现时点因转写稿前后矛盾已从结论剔除，不做时点判断。

2. 专家观点与逻辑链

观点 1：囚徒困境与自我颠覆

  • 观点归属： 付鹏
  • 结论： 大厂明知回报不确定仍必须重注买铲子，并将过去十几年垄断家底填入无底洞，同时面临自我颠覆。
  • 前提事实： 若不入局AI，可能被新入口降维打击、用户迁移、旧生态坍塌；若入局，过去三年半capex核心由大厂推动，并伴随互保、借钱买铲子的杠杆循环。
  • 推导逻辑： 不进则确定被淘汰 → 进则有可能不被淘汰 → 大家被迫都进并烧掉存量现金流 → 新AI入口反噬旧业务
  • 隐含假设： AI会重塑交互入口；大厂旧护城河无法靠不投资维持；自我颠覆不可避免。
  • 反例 / 证伪条件： 若大厂不投入AI仍能维持用户与生态不迁移，或AI投入能与旧业务兼容不产生蚕食，则困境不成立。

观点 2：自由现金流归零是中场临界点

  • 观点归属： 付鹏
  • 结论： 2026年Q2金主自由现金流综合性归零标志窗口期开启，此后花投资人/债权人的钱，市场要求见兔子才撒鹰。
  • 前提事实： 作者在2026年7月提出Q2为临界点，谷歌自由现金流转负，后续阿里等全球金主亦转负；年初提出12-18个月为上下半场切换窗口。
  • 推导逻辑： 存量自由现金流烧干 → 继续买铲子需股权/债权融资 → 无风险利率高企下需看到挖出金子 → 看不到则融资信心与耐心被消耗
  • 隐含假设： 自由现金流可视为过去十几年攒下的存量；无下游变现时外部融资成本敏感且苛刻。
  • 反例 / 证伪条件： 若金主仍能靠自身存量持续投入无需融资，或市场在无变现下仍愿低成本无限供给资金，则临界点意义证伪。

观点 3：流量出问题与上下游同命、杀估值先行

  • 观点归属： 付鹏
  • 结论： 最新财报显示金主挣钱能力（流量）出问题，上游卖铲子与买铲子是一根绳上蚂蚱，市场先杀估值，领先财务报表约7-8个月。
  • 前提事实： 终端应用层C端订阅/B端API收入目前不能覆盖算力折旧与推理成本；上游已计入高增长与高毛利预期；毛利率见顶领先销量与利润。
  • 推导逻辑： 旧挣钱方式受损且新现金流未出 → 金主持续买铲子预期下修 → 市场前瞻性重估上游未来盈利与估值 → 出现杀估值而非即时杀基本面
  • 隐含假设： 上游高毛利本质是加速烧干下游的消金窟机制（索罗斯式反身性）；资本市场对上游反映的是预期而非当下订单。
  • 反例 / 证伪条件： 若下游收入快速覆盖成本、或金主能靠融资维持capex强度不变且上游毛利率不回落，则杀估值逻辑证伪。

观点 4：出清路径与下半场前提

  • 观点归属： 付鹏
  • 结论： 血条厚的寡头靠融资能力熬估值冬天拼耐力，跟风买铲子者将现金流枯竭、破产或债务重组；只有经历出清、算力成本降成普惠基建后，才有AI下半场全要素扩散。
  • 前提事实： 微软、谷歌、Meta等仍有债务/股权融资能力与寡头垄断底盘；类比2000年互联网泡沫后廉价网络催生Web2.0、流媒体、云计算；类比凯恩斯沃什J曲线逻辑。
  • 推导逻辑： 激进投资者买单出清 → 上游成本下降普及成公共事业 → 杀手级应用带动有车跑 → 再投资再跑进入下半场
  • 隐含假设： 历史会重复：活到最后的是踩着第一批重注者尸骨的后来者；AI终有杀手级应用但时点随机不可算。
  • 反例 / 证伪条件： 若跟风者造血能力超预期无需出清，或算力成本不下降仍能跑通下游商业模式，则出清必要性证伪。
