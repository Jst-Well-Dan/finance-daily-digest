1. 华创张瑜旬度会（2026-8-23最新）这一次，市场拐点到了吗？

  1. 盈利领先指标已至6年高位，2027Q2后拐点风险上升、未来3个季度仍安全。 企业存款同比增速-居民存款同比增速差已修复至过去6年次高位、仅次于2020Q4-2021Q1疫后复苏峰值，该指标领先万得全A净利润增速及PPI约3-4个季度。若在此位置拐头，对应2027年Q2起PPI/利润同比转弱风险；在此之前（至2027Q1）盈利仍可维持上行。边界：该判断依赖“存款体系领先贷款”框架成立，且二季度居民加速缩表+财政对社融拉动走弱的格局延续。
  2. 估值驱动同步见顶，拔估值进入观察期。 新增M2中新增居民存款占比与万得全A市净率高度负相关，该占比2026年7月已降至2018年以来最低位，指向居民存款活化向非银搬家、交易放量驱动的估值提升已达阶段性极值。无极端情绪或极度宽松融资支持下，继续向下突破需比肩2015年6月牛市杠杆峰值、概率低。边界：仅适用于同步指标判断当下估值，不预判盈利。
  3. 政策有小拐点、无大拐点。 存量政策加快落地+未用完额度释放+适度增量兜底可期，但类似2024年9月26日级别的强刺激大拐点概率低。依据：①出口/社零/制造业三者加权增速（政府最难干预的原生需求）仍在3.5%左右，未转负则难触发强逆周期；②出口高顺差且高利润率、中美处于缓和窗口、2017-2027十年化债约束下地方广义债帽受限。边界：若原生需求转负或外部冲击超预期，则“无大刺激”假设失效。
  4. 股债性价比快速回归中立，下半年拔估值降速、回归基本面。 以股债下行波动率之差衡量的单位风险收益差，分位数从85%以上快速回落至50-60%中枢：股票下行波动率从2018年以来最低回升至50%分位数附近，债券下行波动率则降至18年以来次低。2025年6月以来权益显著优于债券的再平衡暂告段落。结论：下半年市场将从过去一年的纯拔估值转向更依赖盈利兑现，整体呈现股债中性、操作难度加大的“下行期”特征。边界：判断基于波动率分母端变化，若波动率再度收敛则性价比重回偏股。
  5. 不构成大熊市条件，但需均衡防守。 2023-2024年熊市特征是“经济好的部分（限额以下低端消费、民生财政、非机电出口）不进上市公司利润”导致数据与盈利背离；当前经济最强项为高新机电出口且在上市公司利润中显性度高，盈利与经济背离小，故不具备大熊市基础。下半年策略含义为仓位与结构再平衡、重视基本面与防守。边界：若出口显性度下降或内需结构再度割裂，则该防火墙减弱。

结构化笔记｜华创张瑜旬度会（2026-8-23最新）这一次，市场拐点到了吗？

1. 核心结论

  1. 盈利领先指标已至6年高位，2027Q2后拐点风险上升、未来3个季度仍安全。 企业存款同比增速-居民存款同比增速差已修复至过去6年次高位、仅次于2020Q4-2021Q1疫后复苏峰值，该指标领先万得全A净利润增速及PPI约3-4个季度。若在此位置拐头，对应2027年Q2起PPI/利润同比转弱风险；在此之前（至2027Q1）盈利仍可维持上行。边界：该判断依赖“存款体系领先贷款”框架成立，且二季度居民加速缩表+财政对社融拉动走弱的格局延续。
  2. 估值驱动同步见顶，拔估值进入观察期。 新增M2中新增居民存款占比与万得全A市净率高度负相关，该占比2026年7月已降至2018年以来最低位，指向居民存款活化向非银搬家、交易放量驱动的估值提升已达阶段性极值。无极端情绪或极度宽松融资支持下，继续向下突破需比肩2015年6月牛市杠杆峰值、概率低。边界：仅适用于同步指标判断当下估值，不预判盈利。
  3. 政策有小拐点、无大拐点。 存量政策加快落地+未用完额度释放+适度增量兜底可期，但类似2024年9月26日级别的强刺激大拐点概率低。依据：①出口/社零/制造业三者加权增速（政府最难干预的原生需求）仍在3.5%左右，未转负则难触发强逆周期；②出口高顺差且高利润率、中美处于缓和窗口、2017-2027十年化债约束下地方广义债帽受限。边界：若原生需求转负或外部冲击超预期，则“无大刺激”假设失效。
  4. 股债性价比快速回归中立，下半年拔估值降速、回归基本面。 以股债下行波动率之差衡量的单位风险收益差，分位数从85%以上快速回落至50-60%中枢：股票下行波动率从2018年以来最低回升至50%分位数附近，债券下行波动率则降至18年以来次低。2025年6月以来权益显著优于债券的再平衡暂告段落。结论：下半年市场将从过去一年的纯拔估值转向更依赖盈利兑现，整体呈现股债中性、操作难度加大的“下行期”特征。边界：判断基于波动率分母端变化，若波动率再度收敛则性价比重回偏股。
  5. 不构成大熊市条件，但需均衡防守。 2023-2024年熊市特征是“经济好的部分（限额以下低端消费、民生财政、非机电出口）不进上市公司利润”导致数据与盈利背离；当前经济最强项为高新机电出口且在上市公司利润中显性度高，盈利与经济背离小，故不具备大熊市基础。下半年策略含义为仓位与结构再平衡、重视基本面与防守。边界：若出口显性度下降或内需结构再度割裂，则该防火墙减弱。

2. 专家观点与逻辑链

观点 1：盈利拐点不在当下、但领先指标已逼近6年极值

  • 观点归属： 张瑜（华创宏观）
  • 结论： 未来3个季度（至2027Q1）上市公司盈利/PPI仍向上，2027Q2后不确定性显著上升，下半年盈利重要性超过估值。
  • 前提事实： 企业-居民存款增速差领先万得全A净利润增速及PPI 3-4季度；该差值已处6年次高位，仅次于2020Q4-2021Q1；2024秋以来持续上行2年；2026Q2居民贷款对社融拉动转负、政府债拉动亦回落。
  • 推导逻辑： 居民存款活化→资金回流企业→企业存款增速相对居民走强→经济循环改善→3-4季度后传导至PPI/利润 ；当前位置接近历史极值→继续上行需比肩2017年地产+出口双共振+棚改+供给侧改革的强度→佐证不足→拐点临近。
  • 隐含假设： 存款体系比贷款更领先反映经济循环；历史领先关系稳定；2026Q2的居民缩表与财政走弱非短期扰动。
  • 反例 / 证伪条件： ①该剪刀差在未来1-2月继续创6年新高并逼近/超越2017年峰值；②居民经营贷/按揭/消费贷年化增速重回正增长且社融企业端信用显著扩张；③PPI在2027Q2未转负且万得全A净利润增速继续上行。
  • 原文位置： 转写开头至“这是第一点”段

观点 2：估值拔升进入顶部区间、为同步指标的当下拐点

  • 观点归属： 张瑜
  • 结论： 居民存款活化驱动的拔估值阶段性到顶，下半年估值提升明显降速甚至承压，市场逻辑从拔估值切换至盈利兑现。
  • 前提事实： 新增M2中新增居民存款占比与万得全A市净率高度负相关；该占比2026年7月降至2018年以来最低；2022-2023年该占比上行（交易低估值/红利），2024秋至今持续下行（交易风险偏好）。
  • 推导逻辑： 居民存款占比下行→居民不攒钱→资金活化至非银→非银存款高增→万得全A成交放量→市净率上行 ；当前占比已至18年最低→进一步活化需重演2015年6月加杠杆疯狂→无此条件→估值顶部。
  • 隐含假设： 该负相关关系在货币结构变化中保持稳定；市场增量资金主要来自居民活化而非外资/杠杆；无极端宽松融资或情绪突变。
  • 反例 / 证伪条件： ①该占比在8-9月继续创2018年以来新低并接近2015年6月极值；②非银存款与万得全A成交额/融资余额同步新高推动市净率突破前期高点；③出现降息降准超预期或杠杆资金大幅流入。
  • 原文位置： “第二点，我们来谈估值...到了阶段性的观察点”段

观点 3：政策小拐点而非大拐点

  • 观点归属： 张瑜
  • 结论： 政策将保持适度兜底、加快存量落地与剩余额度使用，叠加部分增量对冲，但不会出现2024年9月26日级别的强刺激转向，更多是“托而不举”、使调整更温和。
  • 前提事实： 定量：出口/社零/制造业三者加权增速仍在3.5%左右，疫后仅在转负时才触发强逆周期；定性：出口高顺差且利润率高、中美缓和期且临近访美、处于2017-2027十年化债期地方广义债帽受限。
  • 推导逻辑： 原生需求未转负+出口赚钱+外部缓和+化债约束→触发大刺激的必要性与空间均不足→政策以温和对冲为主。
  • 隐含假设： 决策层以原生需求是否转负作为强刺激阈值；化债约束短期刚性；中美缓和延续。
  • 反例 / 证伪条件： ①三者加权增速转负或PMI连续低于荣枯线；②出口增速/利润率快速回落；③出台类似2024年9月24-26日一揽子金融/财政强刺激或超预期特别国债/降准降息。
  • 原文位置： “第三点啊我们谈政策...有小拐点，没有大拐点”段

观点 4：股债性价比回归中立、两端好做中间难做

  • 观点归属： 张瑜
  • 结论： 股债大类资产天平从2025年6月以来偏股快速回归中立，二者性价比均不突出，下半年股债均面临操作困境，需再平衡与均衡配置。
  • 前提事实： 2025年6月前上证综指下行波动率处18年最低、债券波动率处50%分位数偏上，股债波动率差向上；2025年6月达中立后持续偏股；近1-2月股票下行波动率回升至50%分位数、债券降至次低，差值分位数回落至50-60%。
  • 推导逻辑： 前期政府分摊下行波动率（对等关税后国家队稳市）→股票分母端改善→股债差上行→偏股占优 → 近期股票波动率放大+债券波动率回落→股债差快速回落→回归中立 → 经济周期处复苏2年后的顶部附近+中立位对应“下行期”→盈利有粘性但量转弱且无大政策→两端（过热/衰退）好做、中间难做。
  • 隐含假设： 用下行波动率差衡量股债性价比有效；波动率变化主要由政策分摊与市场波动驱动而非基本面突变。
  • 反例 / 证伪条件： ①股票下行波动率重回18年最低且债券波动率回升，股债差重回80%以上分位数；②出现明确宽松或盈利超预期使股债再度显著分化。
  • 原文位置： “第四点就是对股债的判断...天平回归中立位”段

观点 5：经济供需结构分化，中游制造相对最优

  • 观点归属： 银波（华创宏观）
  • 结论： 总量偏弱但供给端冲击可缓解、需求端缩圈，结构上中游制造供需矛盾最小、最值得期待，无总量强政策时应聚焦结构。
  • 前提事实： 供给三冲击：原油进口减弱（4月起影响炼化）、煤炭安检/新规（6月起，工业占比约5%、7月-10% vs 正常+5%）、天气（7-8月统计局强调）；需求：地产/制造业/基建/商品+服务消费/财政支出增速均低于名义GDP，仅出口略高于GDP；70城房价从年初十余城企稳收敛至7月4-5城（上海等一线）。
  • 推导逻辑： 供给端冲击→生产法核算读数偏弱→若冲击缓解则读数向上 + 需求端全面低于名义GDP→仅出口偏强→结构缩圈 → 上下游对比→中游制造供需矛盾最优。
  • 隐含假设： 三大供给冲击为短期扰动可修复；名义GDP作为需求强弱锚有效；上下游划分框架稳定。
  • 反例 / 证伪条件： ①煤炭产量8月后未修复或原油进口继续下滑；②内需指标重回高于名义GDP；③中游制造开工/库存/价格指标转弱而上游或下游改善。
  • 原文位置： 银波段“76月份和7月份的数据...中油制造啊...最好的”段

观点 6：金融预期转弱，7月存款搬家放缓+M2派生走弱双重压力

  • 观点归属： 陆宇/芦哲（华创宏观）
  • 结论： 7月企业与非银流动性边际承压，源于居民存款搬家放缓叠加M2派生走弱，若延续则对企业-居民剪刀差及市场流动性不利。
  • 前提事实： 上半年：个人住房贷款净增量至单季最低、非住房消费贷连续3季负增长，居民存款同比少增幅度大于贷款回落，非银存款高增；7月：贷款仍弱但居民存款同比差额年内首次转正，企业与非银存款同比差额年内首次转负；M2派生中政府债发行偏慢且银行购债比例5月后下降。
  • 推导逻辑： 居民提前还贷+存款搬家放缓→居民存款留存→企业/非银分流减少 + 政府债发行慢+银行购债占比降→货币派生少→M2同比回落 → 企业与非银流动性承压→剪刀差上行放缓。
  • 隐含假设： 存款在企业=实体循环、在非银=金融交易、在居民=预期转弱的部门映射成立；银行购债才派生货币、非银购债仅为转移。
  • 反例 / 证伪条件： ①8月居民存款同比差额重回负值且企业/非银存款同比转正；②政府债发行放量且银行购债占比回升带动M2增速回升；③剪刀差在7月短暂回落后重拾上行。
  • 原文位置： 陆宇段“7月份的数据...连续20多个月震荡向上之后呢，7月份又。”截断处
