# 解读君视频摘要

## 1. 【超经典】付鹏讲解金融史：关于美国苏联对抗和金融的关系

1. **当前与70年代末-80年代初高度可比，不宜简单类比00年互联网泡沫**：核心相似在于全要素生产率大停滞（美国1965-1980）叠加大国对抗、逆全球化/右翼化与新技术孵化并存；当前2016年后同样呈现生产关系错配+世界秩序重构+AI/算力新生产力浮现，适用条件为该框架仅作时代对比，不直接推导价格时点。
2. **具备“国家战略安全+新生产力需求”双重属性的金属是当前焦点**：既有战争/供应链安全预期，又有科技进步带来的需求提振，双重驱动下价格易出现异常；该结论适用于小品种、供应链集中且兼具军工与AI/能源属性的金属，需区分于普通工业金属。
3. **科技大停滞期是制度重构期，全要素生产率重构决定资产定价切换**：付鹏在《见证逆潮》及华尔街见闻阿尔法峰会框架中强调，60-80年代工业红利结束→生产关系错配→冷战思潮+信息技术/半导体/互联网孵化（乔布斯、比尔盖茨于81-82年浮现）→当下半导体/互联网升级至AI数据算力纯数字时代，逻辑链仅在“生产力进步+生产关系重构”双特征同时成立时有效。
4. **区域与供需特征决定双重金属的定价弹性**：视频后半段（截断前）提示该领域标的普遍“小、供应链集中”，叠加疫情后区域特征强化，导致价格弹性放大；但因转写截断，具体品种与供应链数据未展开，结论应视为待补证据的研究方向而非品种推荐。

## 2. 大摩周期论剑闭门会（2026-9-2最新）具体行业的投资策略解析

1. **银行业进入“可持续增长+防风险”主线，降杠杆背景下盈利反而加速**：二季度总资产增速从9%多回落至7%多、贷款增速放缓，但净息差略有反弹、净利息收入回双位数增长，手续费因资本市场活跃维持高增；结论适用条件为政策持续纠偏过去过度宽松（取消信用卡/地产白名单/普惠展期等）且未再大幅放水。
2. **“以量补价”阶段结束，银行对规模扩张的执着明显退潮**：管理层讨论显示对“量”的执着取舍，扩张更理性；该判断仅在当前监管定调不变、且息差企稳前提下成立，若再出现稳增长加码则可能逆转。
3. **大行PPOP与净利润增速改善，拨备计提仍积极**：成本收入控制较好，PPOP双位数增长，国有大行净利润增速从一季度1.2%加快至5-6%，同时仍积极提拨备；结论依赖中报数据的持续性，需跟踪资产质量是否同步稳定。
4. **行业策略机会在于“量稳价稳+财富管理”而非总量扩张**：总收入保持不错增长的结构来自息差企稳+交易/理财/基金/保险销售高增，反映资本市场活跃度的传导；若债市与基建投资持续放缓、市场回落，则手续费与交易收入的高增不可持续。

## 3. 洪灏最新分析：科技板块冲高震荡！接下来的周期和市场判断

1. **韩国半导体本轮属杠杆驱动的抛物线泡沫，40天腰斩属典型泡沫破裂形态**：以SK海力士/三星为核心的板块在约9000点见顶后快速回落至5000点，类比2015年A股创业板5000点泡沫；适用条件为杠杆集中、板块权重畸高（三星占韩股超50%）时，指数翻2-3倍后必遇天花板。
2. **有效市场假说的三大前提在现实中均不成立，泡沫是必然产物**：信息并非完全透明（内幕消息普遍）、参与者并非完全理性且以拇指法则决策、交易并非无摩擦（冲击成本随规模递增）；因此在杠杆约束下，价格必然自我强化至极端。
3. **趋势交易与随机交易的合力是泡沫放大器，而逆势交易在泡沫破裂前会被持续惩罚**：大部分对冲基金以momentum因子为主，全部拥挤时趋势自我加强；叠加无模型的随机散户“涨就买、跌就卖”，导致成交量集中于顶部。边界：仅在波动率被压制、预期回报高于融资成本（文中举例8% vs 1.8%）的环境中，该机制加速杠杆累积。
4. **泡沫未终结技术革命，崩盘后的废墟上会产生新机会，但择时决定成败**：AI对GPU、存储、机器人的真实需求仍在，泡沫破灭不改变产业成型；但以美股互联网泡沫（80%跌幅、20年回新高）为鉴，买在山顶与山脚差异巨大，当前应进入“盘整消化、降低杠杆”阶段而非抄底。
