# 结构化笔记｜【最新出炉】大摩内部闭门会（2026-10-5附文稿）《大摩宏观策略谈：看股市和房地产市场的新风云》大摩首席邢自强和Laura Wang等的精彩分析《文字稿件》发布于解读君推特X

## 1. 核心结论

- **结论1：国庆前托底组合方向正确但力度温和，仅能托住全年GDP 4.5%-5.0%下限，无法扭转居民去杠杆与通缩螺旋。** 适用条件/边界：仅在四季度预算加速释放、且不再出现通缩加速恶化的基准情形下成立；若去杠杆恶化，需看地方化债加码等进一步加码。
- **结论2：本轮美联储加息对香港为短而浅冲击，不重演2022-23年股楼双杀。** 适用条件/边界：仅在美联储累计加息75bp（2026年12月+2027年3月各25bp后结束）、香港HIBOR仅升至3.5%左右、P最优惠利率基本不动的基准假设下成立；若油价高企致加息远超预期则失效。
- **结论3：港股短期宜谨慎、楼市复苏延续但股楼割裂持续，选股比方向更重要。** 适用条件/边界：适用于未来1-2季度加息不确定性未除、内地宏观偏弱环境下；楼价韧性依赖人才持续流入+新增供应不足，开发商股价则随房价增速放缓承压。
- **结论4：按增加值口径全球未真正与中国脱钩，中国全球出口份额有望从15%升至2030年16.5%，但出口强势难传导至内需与就业。** 适用条件/边界：适用于关税+转口重构持续、且各国未真正重建本土制造能力的3-5年维度；若欧美实质性重建产能或全面加征关税则份额假设需下修。

## 2. 专家观点与逻辑链

### 观点 1：托底政策是首次破局但只迈一小步

- **观点归属：** 邢自强（Robin）+ Jenny（资深中国经济学家）
- **结论：** 按揭贴息+PSL扩围只是现有思路延伸，托底而非转向，不足以打破去杠杆陷阱。
- **前提事实：** 10月1日起全国首次购房按揭贴息1年合资格首套5年贴1pct、中央出9成，年支出仅150-200亿，合规房仅占去年成交16%；PSL降息25bp至1.5%并扩至六张网、加码科创小微再贷款。
- **推导逻辑：** `中央财政首次补按揭+准财政微调 → 覆盖面窄、期限错配、地方债高企未解 → 仅减缓居民去杠杆、稳住基建预算释放`
- **隐含假设：** 居民提前还贷主因是信心弱而非利率小幅偏高；基建瓶颈在地方债与回报递减而非单纯融资成本。
- **反例 / 证伪条件：** 若合规口径放宽至二套/存量、或中央财政贴息规模数倍放大后，成交与居民杠杆率企稳回升，则“力度不足”判断被证伪。

### 观点 2：港股短期无催化剂、成为全球AI行情的资金来源

- **观点归属：** Laura Wang（中国策略）
- **结论：** 9月初已下调港股/离岸目标，今年大概率平稳过渡，不宜期待924式重现，宜守新质生产力+红利银行。
- **前提事实：** 全球加息预期升温致流动性偏紧；中美元首会晤仅象征性延续；十一长假港股跌破24000创一年新低，而美股因非农弱化加息预期反弹创新高；国庆消费不过不失。
- **推导逻辑：** `外围紧缩+国内宏观弱+无政策强转向 → 港股微观故事不足以吸引增量资金 → 大盘流动性好股票被作funding short去买日韩台AI资产`
- **隐含假设：** 美股盈利强能对冲估值收缩；全球投资者对华交易肌肉记忆仍偏负面，十一前后习惯性减仓。
- **反例 / 证伪条件：** 若出现超预期强刺激转向、或现房改期房等地产拖累逆转致销售拿地回暖，且港股跑赢日韩台，则谨慎判断被证伪。

### 观点 3：本轮加息对港传导远小于上一轮

- **观点归属：** Jenny（宏观）+ 策略/银行/地产联合报告
- **结论：** HIBOR仅从3%温和升50bp至3.5%，P利率至多升12.5bp且延至明年3月，按揭利率难超3.5%，冲击仅1-2季度。
- **前提事实：** 上轮加息525bp、HIBOR跟升近500bp、按揭2%飙至4%+；本轮基准仅75bp；港币存贷比69%为2009年最低（2022年初85%），总结余虽近历史新低但仅占基础货币3%以下，国际收支已由负转正三季度。
- **推导逻辑：** `加息幅度小+存款充裕+存贷比低 → 银行无拆借与加P压力 → 按揭与借贷利率上行有限`
- **隐含假设：** 总结余仅影响HIBOR敏感度不决定绝对水平；美国通胀无过热，核心PCE与非农支持明年3月结束加息。
- **反例 / 证伪条件：** 若总结余持续紧缩引发HIBOR飙升超100bp、或银行被迫上调P超25bp，则传导可控判断失效。

### 观点 4：香港基本面强于2022年，支撑GDP与楼市韧性

- **观点归属：** Jenny（宏观）
- **结论：** 明年一季度GDP回落至1.6%低点后，下半年迅速反弹至4.5%左右高于趋势水平。
- **前提事实：** 上半年实际GDP 5.1%远高于疫情前2.8%；总人口已回疫情前，过去三年年均13万人才获批为疫情前两倍；转口受益AI/能源转型/军工设备跨境流动；楼价自2024低点反弹近20%。
- **推导逻辑：** `人口回流+人才租房购房消费+自由港转口结构性改善 → 缓冲利率上行 → 暂缓的需求在加息预期明朗后释放`
- **隐含假设：** 对冲基金花红免税等继续吸引高收入金融人才；北京资本外流监管不实质切断流入香港资金；不再出现全面Sell China式撤离。
- **反例 / 证伪条件：** 若人才流入骤降、或内地顺周期紧缩+境外投资管控大幅加严、或油价致美联储持续紧缩，则GDP与楼市韧性假设失效。

### 观点 5：楼价看涨但开发商股看淡，偏好收租股

- **观点归属：** Anson / 李君玉（香港房地产分析员）
- **结论：** 住宅复苏不被打断，今年+12%、明年+5%，但开发商股未来3个月跑输，首选太古地产等收租股+恒基。
- **前提事实：** 按揭利率上限3.5%与租金回报3.5%基本持平；新增土地储备降至9.6万套，私人住宅去年一手成交2万套，今年1.7万套、明年1.5万套供不应求；中环空置仅7.8%低于全港12.5%，中环租金自23年涨6%；现房改期房预期拉长库存去化。
- **推导逻辑：** `利率封顶+人才租赁需求+供应收缩 → 房价增速放缓但仍正 → 房价-股价高相关下股价动能衰减+融资成本升 → 收租股租赁改善+回购更优`
- **隐含假设：** 人才新增需求虽不立即买房但持续转化；写字楼Flight-to-quality与扩招持续；农地变现与高毛利项目如期入账。
- **反例 / 证伪条件：** 若四季度成交不降至月5000套而维持6000-7000套、或新盘提价快销，则开发商谨慎观点被证伪；悲观情形加息超预期+境外监管加严，明年房价转跌5%。

### 观点 6：增加值口径下中美未脱钩、只是绕道

- **观点归属：** Jonathan（亚洲经济学家）
- **结论：** 美国对华依赖未降，中国全球出口份额继续提升，但资本密集型出口+产能过剩难拉动内需就业，K型分化弥合需社保与消费再平衡。
- **前提事实：** 直接口径中国占美进口从高位降至8%，但增加值口径稳定，25%含华增加值经第三国进入美国（一半经墨西哥、越南、台湾）；13个制造业仅电子光学、化工、鞋革三行业份额下降；欧亚对华增加值依赖上升，覆盖高低端全行业。
- **推导逻辑：** `关税致直接进口降 → 经第三国间接进入占比升 → 实质依赖不变 → 份额提升但就业传导弱`
- **隐含假设：** 追踪增加值能真实还原供应链；重建本土制造需长时间与高成本，短期无法完成。
- **反例 / 证伪条件：** 若未来美欧本土制造份额实质回升、或13行业中多数行业对华增加值份额持续下降，则“未脱钩”判断被证伪。
