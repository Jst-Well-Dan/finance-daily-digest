2. 专家观点与逻辑链

观点 1：银行降速提质，ROE企稳

  • 观点归属： 金融行业首席徐然
  • 结论： 银行是稳定正回报板块，明年不需要维持Q3高增速，全年6-7%利润增长即可让ROE企稳，选股偏向农行、建行及宁波银行，工行、中行亦稳健。
  • 前提事实： Q3大行收入同比约9%，整体覆盖银行拨备前利润同比+14%、大行+10-16%；多家大行单季净利双位数增长，平均约8.6%较中期的5.5%加速；手续费受保险高基数拖累同比负增长，但投资收益好；实际税率普遍上行、信贷成本略升；零售信贷年内首次明显负增长，60%多杠杆降至50%多。
  • 推导逻辑： 当前ROE已偏低+监管与银行转向减量提质控风险 → 收入与拨备前利润加速足以覆盖税率与信用成本上行 → Q3利润加速；明年无LPR降10bp冲击+部分高息存款到期 → 息差可稳住 → 只需6-7%增长即可企稳ROE
  • 隐含假设： 投资收益高增中有可持续部分；三四万亿/年不良消化能力足以覆盖零售风险暴露；地方债清零与严控投资质量下信贷减速不引发大幅信用塌方；地产周期企稳、28年制造业等投资恢复。
  • 反例 / 证伪条件： 若Q4及明年收入转弱、投资收益回落而信贷成本继续攀升致利润增速掉至低个位数以下；或零售普惠/经营贷不良计提超预期、息差再下行，则ROE企稳不成立。

观点 2：保险最差一季已过，偏好财险和友邦

  • 观点归属： 保险行业分析师赵耀（瑞克）
  • 结论： 三季报单季多亏损、前三季净利同比-20%至-50%符合preview并已反映在10月下跌中，基本面担忧短期缓解；板块内相对更看好财险和友邦AIA，寿险仅为托底下的反弹。
  • 前提事实： 剔除短期投资波动的营运利润普遍正增长；年化ROE约12-20%；Q3股跌但净资产前9个月+3-4%至+20%多、偿付能力环比持平或小个位数增长；全年DPS预计稳健增长；Q3单季VNB同比-30%至-50%，前9个月回落至小幅区间，8月最差、9-10月逐月改善；财险三家头部COR均同比改善，平安达近年及同业较好水平；AIA Q3单季VNB-5%弱于预期的-3至-4%，但9月单月VNB同比+25%，公司指引Q4强劲。
  • 推导逻辑： 净利大跌=去年高基数+短期投资波动 → 剔除后营运利润、净资产、偿付能力、DPS均稳健 → 悲观已定价；寿险销售受去年炒停售与银保65号文压制但9-10月改善+开门红国寿正增长、新华银保快于个险指引 → 需求无大忧；财险报行合一延续+监管有力 → COR未来两年改善确定性强 → 波动市况下选财险和AIA
  • 隐含假设： 年化ROE与DPS口径能穿透短期波动代表真实回报；9-10月改善趋势可延续至开门红；财险监管不放松；AIA管理层对Q4及2027年指引可信，全年VNB约+8%目标让位于长期可持续增长可被市场接受。
  • 反例 / 证伪条件： 若开门红实际销售弱于指引、VNB继续大负增长；或股市再跌致净资产与偿付能力明显受损、DPS下调；或财险COR改善停滞、AIA Q4未兑现强劲增长，则推荐失效。

观点 3：油运周期未结束，一致预期将持续上调

  • 观点归属： 交运行业首席范天磊
  • 结论： 油运超高资本回报来自不战不和状态，2027年盈利好于2026年，市场对2027年盈利/回报下滑的一致预期将不断上调，股价与估值有支撑。
  • 前提事实： 以中远海能港股为例，大摩隐含VLCC年均期租约20万美元/天，市场仅约15万美元/天，而当期期租报价已25-30万美元/天；期租对现货大幅折价致船东惜租、期租成交清淡；战争中出现大量船损。
  • 推导逻辑： 不战不和=油能出海湾+运力大量损耗 → 价值链利润向船东倾斜 → 超高回报可持续；若缓和，现货下跌预期下期现价差收窄反而刺激期租成交量与期租价上行 → 2027年一致预期上调 → 未来12个月盈利上调支撑股价
  • 隐含假设： 外资卖方对2027年谨慎的一致预期代表边际定价；期租价是未来一年盈利的合理锚；船损修复与新增运力不能快速填补缺口；伊朗油回归是需求拉动而非运力冲击。
  • 反例 / 证伪条件： 若2027年一致预期不升反降、期租价回落至15万美元/天以下并持续成交；或船损快速修复、新船大量交付致有效运力迅速恢复，则上行周期结束。

观点 4：停战落地反而是油运最佳入场时点

  • 观点归属： 交运行业首席范天磊
  • 结论： 短期股价由地缘情绪与跟随现货运价交易主导而非基本面，大方向做多，等待美伊和谈/某种停战协议落地时的悲观释放为较好进场时点。
  • 前提事实： 绝大多数参与者简单交易地缘方向与近期运价，认为涨因战争、停战即利空，仅极少数精确理解基本面；基本面看似稳住甚至稳中有升，但情绪仍主导波动。
  • 推导逻辑： 停战协议落地 → 看空者兑现做空/降仓 → 风险释放；但合规运力需2个月以上等待确认真正安全才进高风险区 → 有效运力扰动不立即消失 + 各方疑协议可持续性+全球低库存 → 积极运油抢船 → 运量需求侧拉动 → 基本面强劲表现
  • 隐含假设： 协议初期的不信任与观望期真实存在；低库存补库意愿强；需求侧抢运超过运力释放速度。
  • 反例 / 证伪条件： 若停战后主流合规运力立即大规模进入高风险区、运价与盈利迅速回落；或停战后无抢运补库、运量不升反降，则入场时点判断错误。

观点 5：完全和平后运价与回报仍大幅高于战前

  • 观点归属： 交运行业首席范天磊
  • 结论： 即便达成可持续和平，运价与资本回报也不会回到战前不赚钱状态，未来3-4个季度仍上行。
  • 前提事实： 战争致大量船损形成有效运力折损；战后存在补库需求；部分亚洲国家或分散中东以外油源致航距拉长；伊朗油若在和平框架下回合规渠道。
  • 推导逻辑： 船损需时间修/造补 → 有效运力仍紧 + 战后补油库存+油源切换致运距拉长致需求增速高于战前 + 伊朗油回归为需求拉动而影子船队难高效回归合规 → 盈利中枢大幅高于战前
  • 隐含假设： 船损规模大且修复慢；补库与供应分散真实发生；影子船队合规化存在制度与效率摩擦。
  • 反例 / 证伪条件： 若船损被证伪或快速修复、新船集中交付；或无补库、油源未切换、中东份额不降；或影子船队高效合规回归致运力大增，则高位中枢不成立。

观点 6：航空油价回落利好中优选国泰和春秋，京沪高铁维持超配

结构化笔记｜【付鹏谈香港】 东西方两头抽水 北水顾不上南下

1. 核心结论

  • 结论1：香港走弱主因是定位而非估值，中间人身份已消失。 全球长线资金不再将其视为东西之间的缓冲/中转地，而是要求选边的资产，配置时需额外计入国际政治折价；适用条件/边界：仅在逆全球化与选边配置逻辑延续期间成立，若地缘缓和或离岸中介功能重建则失效。
  • 结论2：本轮AI基建浪潮下港股权重结构性缺席，反被虹吸抽水。 以AH国企+老互联网为权重核心，不在美及日韩台等AI核心资产链条内，且需大额capex支出，自由现金流转弱；适用条件/边界：以当前权重结构未变、AI资本开支高峰延续为前提，若权重重构或互联网capex转化为回报则需重估。
  • 结论3：香港流动性呈东西两头抽水：外资长线撤离叠加北水顾不上南下。 前者体现为大权重成交占比过去两年快速下降，后者因内地自身结构性行情锁定资金；适用条件/边界：以南向净买入持续萎缩、外资配置型资金未回流为观察窗口，单月脉冲式回流不改变结论。
  • 结论4：大权重转冷+小票游资狂欢的组合不可持续，警惕流动性断裂。 市场总量曾热但大权重成交趋冷，属配置型资金撤而散户游资炒作，前期IPO乱象及监管调查即为注脚；适用条件/边界：适用于判断市场健康度，不直接等同于指数点位预测，若大权重成交占比企稳回升则证伪。

2. 专家观点与逻辑链

观点 1：中间人定位终结，从缓冲带变为选边资产

  • 观点归属： 付鹏（视频主讲）
  • 结论： 香港过去赚的是“不用选边”的钱，现在两边都在逼其选边，估值便宜无法对冲定位折价。
  • 前提事实： 2016年以来逆全球化浪潮延续；全球资金配置已不能只看资产好坏与低估；自中概股起长线资金被迫考虑国际政治因素；香港此前承担中转/缓解功能。
  • 推导逻辑： 逆全球化深化 → 全球配置加入政治选边约束 → 香港不再被划为中间地带而被划入需选边一侧 → 配置港股要求额外风险补偿
  • 隐含假设： 地缘约束是长线资金硬约束而非短期情绪；香港无法靠制度套利重建中立身份。
  • 反例 / 证伪条件： 全球长线资金重返港股大规模增配；或香港重新获得离岸中介豁免地位；转写“1819年”系“2018-2019年”之误，已剔除不影响推导。

观点 2：AI虹吸与权重错配，老互联网沦为capex支出方

  • 观点归属： 付鹏为主；阿里、腾讯capex与自由现金流具体数字为解读君后期整理补充，非付鹏原话口径。
  • 结论： 港股权重资产不是本轮AI受益者，反而要花掉互联网垄断期积累的自由现金流，全球资金被虹吸至美、日韩台积电等核心资产。
  • 前提事实： 本轮AI基础设施投资由美国拉动上中下游；港股权重为AH国企+当年转至香港的中概大互联网；付鹏称阿里自由现金流转负、护城河积累的现金流已花光；解读君补充称阿里单季资本开支676亿、自由现金流净流出447亿，腾讯由净流入430亿转净流出138亿。
  • 推导逻辑： AI capex集中于美及周边核心链 → 港股权重无AI核心标的且需对外投入 → 相对吸引力下降 → 全球资金虹吸远离香港
  • 隐含假设： 当前capex不能快速转化为增量利润与估值重估；AH国企无法提供替代性AI敞口；欧洲类比成立但银行能源权重差异不改变结论。
  • 反例 / 证伪条件： 老互联网capex验证为有效AI收入/利润；港股出现权重级AI核心资产；美AI投资退潮使虹吸减弱；转写“宏吸机/弘吸/红吸”统一按虹吸理解，“AR”按AI理解。

观点 3：两头抽水下的流动性萎缩，北水缺位是当下主约束

  • 观点归属： 付鹏为主；南向资金规模数据为解读君整理补充。
  • 结论： 香港成交转弱是结果：外资配置型资金撤+北水被内地行情锁定顾不上南下，小票炒作熄火后整体流动性易出问题，远期或趋向“深圳市香港区”。
  • 前提事实： 香港权重股成交额占市场比重过去两年快速下降；截至5-6月前一年市场总量热但大权重趋冷；散户游资炒作前两年IPO乱象并引致廉政公署与金融监管调查；内地6-7月前亦为结构性行情锁定注意力；解读君补充南向2025年全年净买入约13000亿港元、2026年9月底累计仅4282亿、10月下旬连续8个交易日净卖出。
  • 推导逻辑： 外资长线撤离 → 大权重成交占比下行 → 市场热度靠游资小票维持 → 内地资金自顾不暇致北水缺位 → 小票熄火后总量流动性收缩
  • 隐含假设： 大权重成交占比可代理配置型资金去留；散户不炒大权重；南向数据口径可比且持续性强。
  • 反例 / 证伪条件： 大权重成交占比企稳回升；南向持续大幅净流入回归；小票成交可独立支撑市场流动性；转写“站在光里、光在那里”等内地产业链口误表述已剔除，不作为依据。
