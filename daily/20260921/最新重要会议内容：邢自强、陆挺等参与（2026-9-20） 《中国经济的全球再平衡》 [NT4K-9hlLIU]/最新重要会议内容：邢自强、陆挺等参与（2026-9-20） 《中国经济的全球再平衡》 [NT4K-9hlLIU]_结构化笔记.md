# 结构化笔记｜最新重要会议内容：邢自强、陆挺等参与（2026-9-20）《中国经济的全球再平衡》

## 1. 核心结论

- 当前全球失衡程度被政治化叙事高估：按逆顺差绝对值之和/GDP约3.7%，远低于2007年近6%和高点约5.4%；中国经常项目顺差约3.7%，远低于2007年约8.8%，适用条件是回到经常项目口径而非只看货物顺差1.19万亿美元。
- 本轮失衡主因是疫情需求结构切换、去全球化与供应链重构、AI资本品需求上行、美国财政军事扩张四因素叠加，具有阶段性和偶然性，尚不构成直接触发全球动荡的充分条件；若美债美元资产出现超级动荡，结论失效。
- 中国对欧美顺差扩大更多来自自身制造业升级与进口替代加规模效应，而非名义汇率低估：过去5年名义有效汇率基本横盘，贬的是实际有效汇率，背后是中外通胀差与国内通缩；人民币大幅升值无法解决失衡，适用边界是国内通缩未扭转前。
- 外需过去5年为中国提供了关键缓冲，若无出口高速增长则GDP难以达标；但该缓冲正被贸易保护反弹侵蚀，窗口正在收窄，倒逼条件是必须用缓冲期解决内需、化债和社保问题。
- 走出需求不足的关键不是先解决所有深层结构问题，而是先打破居民不敢花、企业不敢投的负向自我放大循环，需要中央加赤字加国债并把钱花到化债、社保和低收入群体上；若资金仍投向低效基建或加剧内卷产能，则效果不成立。

## 2. 专家观点与逻辑链

### 观点 1：不要跟随美国政治家炒作全球失衡

- **观点归属：** 刘元春教授。
- **结论：** 对全球失衡持谨慎否定态度，不认为当前失衡已到不可持续、必然引发危机的程度。
- **前提事实：** 全球失衡指标2025年约3.7%，2007年近6%；中国经常项目顺差约3.7%，2007年约8.8%；近期话题由美国《外交事务》等政治化讨论引爆，而非经济学专业共识，待核验具体文献口径。
- **推导逻辑：** 失衡绝对水平不高 → 成因多为疫情与政治与科技革命等阶段性因素 → 不可持续性论证不成立 → 跟风炒作不明智。
- **隐含假设：** 历史口径可比；阶段性因素会消退；美国问题不等于全球问题。
- **反例 / 证伪条件：** 若美债收益率持续上行叠加美元信用动摇并外溢为全球流动性危机，则“不构成动荡直接原因”被证伪。

### 观点 2：承认部分失衡，病根在内需与房地产后遗症

- **观点归属：** 陆挺（野村证券首席，速记作陆婷/陆博士）。
- **结论：** 对失衡持谨慎承认态度，强调中国自身短期因素不可忽视，方向是化债加精准财政社保。
- **前提事实：** 中欧顺差扩大，对德由逆差转为月均约40亿美元顺差；房地产企业应付账款约25万亿，其中近8万亿或为坏账；名义有效汇率近5年横盘，实际有效汇率下行；视频陈述数据，待核验。
- **推导逻辑：** 房地产下行冲击财政财富信用 → 国内通缩利率全球最低 → 制造业成本优势拉大加进口收缩 → 顺差扩大 → 需化债加给低收入与灵活就业补社保。
- **隐含假设：** 化债资金能真正清理企业间三角债而非挪用；社保补贴能转化为消费。
- **反例 / 证伪条件：** 若化债后内需与物价仍持续通缩，或顺差继续扩大而进口不回升，则“花钱方式重于花钱规模”需修正。

### 观点 3：未来5到10年失衡可能加剧而非改善

- **观点归属：** 邢自强（摩根士丹利首席经济学家，速记作邢志强/邢首席）。
- **结论：** 对全球再平衡持谨慎偏空态度，预测失衡加剧，方向是打破宏观路径依赖、提前夯实社保。
- **前提事实：** 美国名义GDP年增约5%但赤字率高达约6%；中国名义GDP增速约4%出头，广义财政赤字率过去一年收缩约2.5个百分点；美国企业未来一年AI资本开支或达1.3万亿美元；视频陈述，待核验。
- **推导逻辑：** 地缘政治加科技革命加宏观路径依赖 → 美国该收缩未收缩、中国该扩张未扩张 → AI加剧K型分化 → 中国制造业占比或从28%继续上行 → 失衡加剧。
- **隐含假设：** AI投资维持高强度；地缘冲突与关税战不缓和；中美财政行为延续既有路径。
- **反例 / 证伪条件：** 若美国实质收缩赤字、或中国中央赤字大幅扩张且社保持续落地并带动物价回升，则加剧判断被削弱。

### 观点 4：转型远未结束，外需缓冲不可持续

- **观点归属：** 汪涛（瑞银投资银行）。
- **结论：** 对中国转型与外需前景持中性偏谨慎态度，方向是防内卷加债务重组加保企业可持续投资。
- **前提事实：** 房地产对GDP贡献由拖累延续，消费占GDP比重低迷，出口重新成为引擎；中国对新兴市场顺差占比20多年持续上升；转述研究与体感，待核验。
- **推导逻辑：** 投资依赖房地产地方驱动模式退潮 → 科技高端制造尚未补足规模 → 企业利润薄加内卷不敢投 → 需有序竞争加过剩产能出清 → 否则转型阵痛延长。
- **隐含假设：** 贸易保护反弹会实质压缩外需空间；国内竞争规则能真正反内卷。
- **反例 / 证伪条件：** 若消费零售与制造业投资同步回升且出口份额稳定在18%至20%而无大面积反制，则“缓冲不可持续”过于悲观。
