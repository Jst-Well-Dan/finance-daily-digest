# 结构化笔记｜【美联储加息】付鹏对于2026年美国通胀和美联储加息路径的整体判断和分析

## 1. 核心结论

- **美国通胀回落的主力是商品端，服务与薪资螺旋尚未打破，回落节奏慢于市场预期。** 适用条件：商品远期贴水与油价回落延续、就业市场与薪资增速保持韧性；若薪资明显放缓或就业走弱，该判断失效。
- **美联储处于两难，最可能的选择是在5%—5.25%一带的限制性利率上停留观察，既不大幅加息也不降息。** 适用条件：通胀未达目标但利率倒挂已对部分部门造成冲击；若通胀再加速或金融风险外溢，路径会被打破。
- **硅谷银行与瑞信事件是个案而非2008年式的系统性危机，对国内金融机构与经济的直接影响小。** 适用条件：风险局限于单一客户群或单一产业链绑定过紧的银行、且恐慌能被及时阻断；若出现跨机构传染，该结论不成立。
- **美元高利率通过港币联系汇率与HIBOR抬升压制港股估值，并通过估值渠道约束A股上行空间，后续上涨更依赖企业盈利而非估值扩张。** 适用条件：美联储年内不转向降息、美元利率维持高位；若美元利率回落或国内盈利实质性恢复，约束减弱。

## 2. 专家观点与逻辑链

### 观点 1：美国通胀的结构性分化与加息路径

- **观点归属：** 付鹏。
- **结论：** 对美联储大幅降息、大幅加息、因银行压力而降息三种预期都持否定态度，主张维持限制性利率观察等其自然回落。
- **前提事实：** 商品端远期贴水收敛、油价回落至80美元左右，商品性通胀大幅消退；但就业市场仍好、薪资增速未明显放缓（视频陈述，数据细节待核验）。
- **推导逻辑：** 商品通胀消退 → 整体通胀回落的最大贡献来自商品端 → 就业薪资螺旋未打破使服务通胀有韧性 → 通胀放缓慢于预期 → 美联储既不能转向宽松、又不敢过度加息 → 维持5%—5.25%观察。
- **隐含假设：** 薪资是服务通胀的核心滞后变量；当前利率倒挂深度已意味着经济承压，再加息边际风险大于收益。
- **反例 / 证伪条件：** 薪资增速快速下行且失业率上行，或通胀重新加速并迫使美联储重新大幅行动。

### 观点 2：银行业流动性风险不是系统性危机

- **观点归属：** 付鹏。
- **结论：** 硅谷银行、瑞信问题看空情绪过度，应个案处置（破产或被大银行接管），不会演变为2008年式崩溃。
- **前提事实：** 2008年底层资产是居民加杠杆购房叠加金融衍生品扩散；本轮是单一客户群银行在负债端与资产端风控上出问题；美国银行数量过去20年由2万多家降至5000多家，中小银行破产本是常态（视频引用的数量为嘉宾口述，待核验）。
- **推导逻辑：** 底层资产未系统性变废纸 → 风险集中于客户结构单一的银行 → 加息与曲线倒挂触发连锁但范围可界定 → 阻断恐慌加个案处置即可 → 不冲击整体金融体系。
- **隐含假设：** 监管能及时保护储户并稳定情绪；大银行有意愿与能力承接问题资产；恐慌不跨银行传染。
- **反例 / 证伪条件：** 出现跨银行挤兑、货币市场基金或衍生品链条断裂，或问题银行资产被证实存在系统性减值。

### 观点 3：美联储加息接近尾声，但高利率继续约束港股与A股估值

- **观点归属：** 赵老师（转写中或称“赵谦老师”“赵青老师”，人名以转写为准，待核验）。
- **结论：** 对加息整体处在偏后阶段、利率终点若隐若现；但只要美元利率维持高位，港股与A股的估值扩张空间就受约束，后续要靠盈利。
- **前提事实：** 美国CPI与PCE自去年6月后增速回落但慢于预期；港币触及7.85弱方保证后金管局回收流动性推高HIBOR；港股自低点反弹约50%后估值已修复一轮；2017年陆港通扩大后A股与HIBOR联动增强（均为视频陈述，待核验）。
- **推导逻辑：** 通胀是回落快慢问题而非再加速 → 加息近尾声 → 但利率不快速回落 → 港币利差压力使HIBOR维持高位 → 贴现率压制估值 → 港股、A股再涨需盈利支撑。
- **隐含假设：** 联系汇率机制下港美利差仍是HIBOR主导变量；估值是利率影响股市的主要渠道而非盈利渠道。
- **反例 / 证伪条件：** 美元利率快速回落带动HIBOR下行，或企业盈利超预期接棒驱动指数上行。

### 观点 4：国内经济自然修复但有通缩与债务约束，国债利率上行空间有限

- **观点归属：** 付鹏谈国内部分；赵老师谈A股底部与盈利修复。
- **结论：** 国内经济随防疫结束进入自然恢复，但居民收入预期受损、外需受供应链重塑扰动；国内利率难回疫情前3.3%—3.4%，上限约3.0%—3.1%。
- **前提事实：** 居民部门收入与收入预期受冲击；全球供应链在过去一年半发生逆转，部分份额未必回流；居民与政府部门杠杆偏高，政策以精准滴灌为主；沪深300股债利差指标显示本轮修复不足三分之一（均为视频陈述，待核验）。
- **推导逻辑：** 需求恢复但消费能力不足以消化庞大产能 → 内卷与产成品通缩压力 → 大规模货币宽松受债务约束 → 利率维持偏低区间 → A股后续空间靠盈利兑现而非估值。
- **隐含假设：** 供应链转移具有黏性，不会因价格因素快速回流；居民消费信心缺口需要一至两年消化。
- **反例 / 证伪条件：** 出口份额超预期回流、居民消费与信贷持续强复苏，或政策转向大规模刺激推高利率。
