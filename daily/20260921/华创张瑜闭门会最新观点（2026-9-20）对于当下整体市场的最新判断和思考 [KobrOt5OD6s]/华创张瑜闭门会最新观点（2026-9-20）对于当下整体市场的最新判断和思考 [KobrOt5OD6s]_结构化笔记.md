# 结构化笔记｜华创张瑜闭门会最新观点（2026-9-20）对于当下整体市场的最新判断和思考

## 1. 核心结论

- **顺畅拔估值已告一段落，进入“务实的下半场”**：适用未来2—3个季度；盈利比估值更具确定性，需重视盈利回归基本面，单靠流动性推升估值的行情难以延续。
- **居民存款活化是核心观察变量，两条链路均进入波动加大期**：一条经企业—居民存款剪刀差领先PPI约三四个季度指向远期利润前景；一条经新增M2中居民存款占比负相关权益市净率指向增量资金与估值，连续两个月回落/回升需观察。
- **股债性价比回到50%中立均衡位，存在配置困境**：过去两年股票支配性价比大幅优于债券的判断结束；当前股票问题是胜率不够、债券问题是赔率不够。
- **政策预期应以存量落地为主**：若三季度GDP高于4.3%、全年4.5%以上大概率实现，且新动能供给与需求仍偏强，则难期待远超当下的扩内需政策，至多为稳预期、稳房价预期的存量加快与个别微调。
- **美联储9月加息后路径模糊、定价易逆转**：12比0通过但两人预计年内不再动、金融条件“限制性”标准模糊、总量稳结构分化与通胀确认难度上升，短期需等更多线索，波动将加大。

## 2. 专家观点与逻辑链

### 观点 1：居民存款活化的双链路决定盈利与估值

- **观点归属：** 华创宏观张瑜。
- **结论：** 对经济循环与资本市场增量资金的两条链路均转谨慎观察；市场处于务实的下半场。
- **前提事实：** 企业存款同比减居民存款同比的差值已到6年高位并连续两个月回落；新增M2中居民存款占比已处过去6—10年相对低位但连续两个月回升；转写数字“2027年二季度”“明年19”等疑似转写错误，已剔除具体时点引用。
- **推导逻辑：** 居民存款活化 → 经济循环改善幅度与物价利润前瞻 → 远期利润预期；同时活化 → 资本市场待配资金与估值 → 拔估值行情。
- **隐含假设：** 剪刀差与PPI的领先关系稳定；新增M2结构与市净率的负相关可延续；财政与地产政策能否作用于这两条链路是有效评判标准。
- **反例 / 证伪条件：** 若剪刀差重新走阔且新增M2中居民存款占比重回下行，则远期利润与估值扩张逻辑恢复。

### 观点 2：三视角拆解8月经济——核算无忧、需求偏弱、新动能偏强

- **观点归属：** 华创宏观分析师（尹波）。
- **结论：** 总量目标视角偏乐观，需求视角偏弱，新动能视角偏强；整体政策预期以降为主。
- **前提事实：** 工业增加值从4.5%回升至5.2%，主因煤炭、原油加工等供给约束缓解；70城中仅上海、深圳及偶发性扬州二手房上涨；19个一级行业中约八成投资增速为负；补贴、必选等四分法下商品与服务消费均边际走弱；装备制造约12.1%、机床出口约20%多。
- **推导逻辑：** 核算用工增与服务业生产指数 → 三季度GDP判断 → 全年目标可达性 → 政策必要性；需求端房价投资消费走弱 → 仅需稳预期式微调；新动能供需两旺 → 无需额外加码支持新动能。
- **隐含假设：** 月度工增与服务业生产指数可代表GDP核算；房价上涨城市数、投资正增长行业数可刻画内需；新动能高增长可持续。
- **反例 / 证伪条件：** 若三季度GDP明显低于4.3%或新动能增速快速回落，则总量与结构判断均需修正，政策预期上修。

### 观点 3：M2回落与存款行为变化来自财政、股市波动与企业融资

- **观点归属：** 华创宏观文若宇。
- **结论：** 对M2与预期指标偏谨慎；两个预期指标出现拐点式观察信号。
- **前提事实：** 8月至5月M2同比回落约1.1个百分点，为24年6月以来最大；6—8月政府债净融资同比少近9000亿且银行增持比例下降；股票下行波动率放大后下浮比率回到0附近；企业短贷中长贷同比负增，仅票据支撑。
- **推导逻辑：** 政府发债偏慢＋银行买债偏少 → M2派生收缩；股市波动放大 → 居民赚钱效应下降 → 存款搬家减弱致居民存款边际多增；企业融资偏弱＋仅出口支撑结汇 → 企业存款难持续抬升。
- **隐含假设：** 银行间利率抬升持续约束银行扩表；股票下浮比率领先居民金融投资约半年关系成立；明年置换债缺席则政府债对M2拉动更弱。
- **反例 / 证伪条件：** 若四季度政府债放量且银行配合买债、股市波动率回落，或企业信贷与出口结汇走强，则M2与剪刀差重回改善。

### 观点 4：美联储9月加息落地但后续路径有六大疑问

- **观点归属：** 华创宏观孙姓分析师。
- **结论：** 对后续持续加息持谨慎态度；市场定价可能面临较大调整。
- **前提事实：** 9月加息12比0通过，但点阵图显示两人预计年内不再动；鲍威尔称难将金融条件描述为限制性、加息为“撤除部分宽松”；美国总量稳但结构分化，失业率从4.3%降至4.1%而劳动参与率下降约0.8个百分点；历史参考仅1997年单次25bp与1999—2000年累计170bp。
- **推导逻辑：** 表态偏鸽＋标准模糊 → 市场难确认速度幅度 → 定价波动；总量稳结构分化 → 低收入群体未改善则加息效果存疑；就业供给收缩下的平衡 → 能否承受持续紧缩需验证。
- **隐含假设：** 金融条件作为内生变量易被市场预期裹挟；通胀方向叠加速度的确认框架不变；供给收缩不是持续通胀传导渠道。
- **反例 / 证伪条件：** 若通胀回落速度明确、低收入实际收入增速追上中端群体、就业在紧缩下仍平衡，则持续加息逻辑增强。

### 观点 5：本轮高油价对中游制造盈利冲击减弱

- **观点归属：** 华创宏观夏雪。
- **结论：** 对中游制造盈利可少些忧虑，对油价焦虑可降温；份额与盈利韧性偏乐观。
- **前提事实：** 截至2026年上半年中游制造毛利率净利率低位回升；2026年二季度原油均价约653元每桶时改善宽度为41.6%，高于2017—2018年油价约515元时低至33.6%；油价与毛利率滚动相关系数转正，三年窗口约0.35；油价传导有时滞，待核验。
- **推导逻辑：** 高油价供给冲击 → 弱制造出清 → 制造强国份额集中 → 中国重油制造份额上行 → 上市公司盈利能力与改善宽度韧性增强。
- **隐含假设：** 2000年以来油价涨超30%年份份额上行的历史规律延续；毛利率改善宽度可比；时滞效应不会在下半年集中显现。
- **反例 / 证伪条件：** 若下半年毛利率净利率随油价滞后回落、改善宽度明显收窄或相关系数重新转负，则韧性结论不成立。
