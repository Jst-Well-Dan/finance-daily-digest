# 结构化笔记｜大摩周期论剑闭门会（2026-9-16最新）具体行业投资策略

## 1. 核心结论

- **反内卷加去杠杆进入执行加码期，银行息差与盈利先受益，但内需短期仍受压：** 中小账款60天硬约束、国企先行、工业品价格核算与公平竞争审查配套落地。今年工业投资增速已低于需求增速、近90%产业投资放缓；银行息差筑底小幅反弹，今年利润增速预计4%-5%、明年6%-7%。适用条件是政策执行不走样、出口维持韧性；若执行放松或出口失速，盈利修复节奏后移。
- **现房销售冲击的是周转与稳态规模而非当期利润率，2027-2028年新房销售下行偏刚性：** 项目现金周转周期从预售下约2年拉长到3-4年，同笔资金可支撑的拿地开工规模收缩。2026年预计新房销售面积-12%、新开工-22%、开发投资-20%；2027-2028年销售面积复合降幅约24%，融资改善也难以形成当期可售货值。边界是北上细则、地价与融资条件尚未落地，最终斜率取决于三者。
- **京东物流与航空被下调背后是同一逻辑：今年的高基数不可持续，明年预期偏高：** 京东物流由超配降至平配，今年靠外卖即时配送、燃油附加与国际化拉动，明年外卖减亏不追量、油价基数已高、国际化尚不盈利。航空三季度利润率大幅收缩相对确定，四季度需国内票价同比涨10%以上对冲高油价，否则全年盈利仍有下调风险。仅当油价明显回落时结论反转。
- **AI上游原材料与油运链是明确看多的方向，大宗内部出现分化：** 11类原材料中玻纤电子布与覆铜板最紧且持续最久，红河科技对标日东纺、四类高端电子布均已获客户认证，叠加纱与设备瓶颈，2027年缺口或比今年更大。炼油与油轮被判断进入可维持较久的高盈利期，集运仅美线旺季偏强。电解铝27年新增或低于预期、废铜供给放松证伪前不计入、锂当下订单尚可但预期一致悲观、煤炭维持偏强。适用条件是AI资本开支不熄火、地缘与低库存格局延续。

## 2. 专家观点与逻辑链

### 观点 1：反内卷叠加去杠杆，金融可持续性改善

- **观点归属：** 金融行业首席分析师 Reter（视频表述）。
- **结论：** 看多银行板块盈利修复与金融体系长期稳定，短期内需承压但为一两年后的更稳基础；上调港交所目标价。
- **前提事实：** 中小企业支付期限收紧至60天、国企严格执行并明确处罚；工业产品价格核算细化；2024年为公平竞争审查真正执行元年、今年查处力度更大；家庭今年为第一年真去杠杆、房贷窗口指导取消；地方平台与专项债项目回报要求持续收紧（待核验：均为嘉宾口述政策进展）。
- **推导逻辑：** 供给约束到位 + 杠杆需求回归 → 无序扩张与转嫁成本受抑 → 贷款非理性竞争弱化 → 息差筑底反弹 + 不良消化后信贷成本下降 → 银行利润增速超过收入、ROE或反弹；交易量维持高位 → 港交所受益。
- **隐含假设：** 执行力度不反复；出口维持较好为调整提供窗口；存款利率仍有下行空间。
- **反例 / 证伪条件：** 若地方执行放松、平台融资重回扩张，或出口明显走弱导致稳增长压力骤升，则息差反弹与利润预测落空。

### 观点 2：现房销售拉长周转，行业稳态规模下移

- **观点归属：** 地产组首席 Teven（视频表述）。
- **结论：** 对2026年指标全面下调，对2027-2028年销售偏谨慎、中性偏空，投资端保留政策弹性；宽松情景更可能成为最终基准情形。
- **前提事实：** 预售下拿地到开盘约6-9个月、现金周转约2年，现房下需承担土地与大部分建安成本、周转拉长至3-4年；已获施工许可的存量项目仍可按预售执行；中央仅给出框架，土地付款、项目融资与地方执行细则未定（待核验：周转年限为嘉宾估算）。
- **推导逻辑：** 周转变慢 → 同资金支撑项目减少 → 土地补充减少 → 新开工下降 → 在建面积收缩 → 销售与投资规模下移；地价下调10%-20%、分期付款与融资支持只能部分对冲。
- **隐含假设：** 开发商对未知细则的理性反应是先停买地、谨慎推盘；宽松情景中地价、杠杆与房价均出现友好变化。
- **反例 / 证伪条件：** 若北上土地付款条件大幅放宽且项目融资明显加码、竣工加速释放监管资金并带动补库，则投资降幅收窄至宽松情景甚至更好；若地价调整远小于10%，则投资比情景三更差。

### 观点 3：京东物流下调评级，航空盈利承压、油轮优于集运

- **观点归属：** 交运组首席倩磊（视频表述）。
- **结论：** 京东物流从超配下调至平配、不下调至低配；航空下调三大航与春秋盈利与目标价；继续看好油轮相对集运。
- **前提事实：** 京东物流今年收入利润较好，来自外卖即时配送、燃油附加与国际化三块；2026年PE约7倍、回购执行偏弱；三季度票价偏弱、油价高企；炼油多赚约10-12美元/桶、油轮多赚约3-5美元；美线运价强至10月下旬、欧线低迷、红海复航预期压制情绪（待核验：盈利数字为嘉宾测算口径）。
- **推导逻辑：** 高基数因素明年减弱 + 国际化增收不增利 → 一致预期偏高 → 下调评级但低估值托底；票价涨幅不足 → 油价侵蚀利润 → 下调航空；地缘扰动 + 低库存 + 炼能不确定 → 油运高盈利维持。
- **隐含假设：** 京东外卖转向减亏、油价不继续大涨、航司运力收缩效果有限。
- **反例 / 证伪条件：** 若油价快速下跌，则京东物流成本压力缓解、航空盈利上修，评级逻辑部分证伪；若红海大面积复航，则集运与油轮运价逻辑同时走弱。

### 观点 4：AI链原材料紧缺延续，大宗调研指向结构性机会

- **观点归属：** 基础材料组首席 Rachel（视频表述）。
- **结论：** 看多玻纤电子布、覆铜板等AI上游原材料与红河科技，看多电解铝与煤炭，对铜、锂偏中性观察；美联储9月加息落地后金铜大跌可能性不大、调整可买入。
- **前提事实：** 46只股票、11个行业的一站式梳理中挑出8只重点推荐；红河科技四类高端电子布均获客户认证、产能扩张快于日东纺；纱设备交付要到明年下半年、电子纱明年无行业新增产能；印尼电力瓶颈致27年电解铝新增推迟；废铜反向开票仅口头指导、无红头文件；锂企业下月订单环比增5%-8%但市场预期超10%（待核验：认证与产能节奏为嘉宾调研口径）。
- **推导逻辑：** AI需求扩张 + 上游扩产慢 → 紧缺持续 → 价格维持上涨 → 龙头份额与盈利扩张；电力与政策瓶颈 → 新增供给低于此前预期 → 紧平衡支撑价格；加息预期已充分定价 → 利空出尽。
- **隐含假设：** AI资本开支延续；废铜政策不实质放松；锂需求悲观预期不自我实现为砍单潮。
- **反例 / 证伪条件：** 若AI需求降温或新增产能超预期投放，或废铜政策出现文字性全面放松致供给增加约70万吨，或金铜在加息后持续大跌，则看多逻辑被证伪。
