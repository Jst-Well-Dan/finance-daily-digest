    边界是2028年相关州约1/5项目推迟至2029年，效率与融资分化加剧。
  • 结论2：中选后布局中国空间打开，应转向更平衡组合而非全面押注AI链。 适用条件：全球AI交易争议未消、美股波动未稳，且中国科技仍面临名单与限制风险时；
    边界是主线聚焦国产替代卡脖子标的，而非全面放弃科技。
  • 结论3：不要对中美关系缓和抱幻想，科技限制不缓和甚至小幅升级。 适用条件：民主党控制国会后贸易政策可预见性提高但方向不松动成立时；
    边界是非战略敏感消费、家电、机械出口确定性提高，不代表美国本土市场准入改善。
  • 结论4：美股短期宽幅震荡但2027年向上格局不变，中国红利仍需作为压舱石。 适用条件：基本面强劲+标普500约18倍估值合理+中选后6-12个月历史规律有效时；
    边界是短期标普500可能试探7000-7300点区间，全球未马上趋稳。

2. 专家观点与逻辑链

观点 1：美国AI开支总量不变、2028年断档推迟

  • 观点归属： 邢自强 Robin + Gary（转述美国20+团队联合评估）
  • 结论： 2027-2028年美国云厂商capex预测维持不变，但2028年约20%本土数据中心建设量挪到2029年，2028-2029年合计不变。
  • 前提事实： 民主党横扫并拿下德州、俄亥俄等数据中心大州州长及参众两院控制权；美国数据中心短板是电力供应与地方审批而非芯片；2027年在建项目已拿批文。
  • 推导逻辑： 民主党胜选州加严审批+电价水价税收返还前置条件 → 2028年约5GW项目拿批文放缓 → 2028年建设量下调、2029年上调，总盘子不变
  • 隐含假设： 监管是延迟而非禁止；电力缺口可部分靠海外与效率弥补；云厂商资本开支意愿不受估值回调动摇。
  • 反例 / 证伪条件： 若2027年在建项目也被复审停工，或2028年实际开工未见推迟、云厂商下调capex指引，则总量不变判断被证伪。

观点 2：算力短缺倒逼海外溢出、模型小型化与融资分化

  • 观点归属： 邢自强 Robin + Gary
  • 结论： 美国本土缺电缺批文将倒逼部分建设转向东南亚/欧洲/中东，提高对token/每瓦算力效率要求，只有头部hyperscaler能消化，新兴借贷型云商面临严苛审查。
  • 前提事实： 美国本土测算有38GW缺口，2028年推迟后扩大至44GW左右；亚洲2026-2030年约30GW可供应，其中约一半可承接外溢；中国长期受芯片制约已走小型化路线。
  • 推导逻辑： 本土审批变慢+缺电扩大 → 头部厂商靠存量电力资产与自有资金维持 → 边缘厂商融资裂缝扩大 + 需求外溢亚洲 + 蒸馏/定制芯片提效
  • 隐含假设： 东南亚电力与审批能承接；模型蒸馏与效率提升能部分替代 brute-force 算力；融资市场按2005年式分化演绎。
  • 反例 / 证伪条件： 若东南亚同样收紧数据中心审批，或头部厂商也大幅削减capex，或边缘厂商融资成本未上升，则分化与外溢逻辑不成立。

观点 3：不要押注中美缓和，投资转向国产替代与广谱平衡

  • 观点归属： 王滢 Laura
  • 结论： 不因民主党控国会而预期中美缓和，科技限制甚至小幅升级；不放弃科技主线但聚焦国产替代卡脖子龙头，同时打开消费电子、家电、机械、绿能、红利银行等多板块空间。
  • 前提事实： 上半年A股与美股高频共振，主线是国产替代+绑定全球AI供应链；过去十年地缘风险溢价上升最快阶段在民主党主政白宫4年；特朗普第二任期中美进入休战可预见状态。
  • 推导逻辑： 民主党国会鹰派不弱+国家安全议题不让步 → 国产替代急迫性加强 → AI出口链确定性下降、内需自主链相对占优 + 非敏感出口可预见性略升
  • 隐含假设： 地缘判断可线性外推历史；国产替代龙头盈利可独立于宏观疲弱；全球资金因美股AI拥挤而愿意再配中国非AI资产。
  • 反例 / 证伪条件： 若国会层面实质放松出口管制/实体清单，或国产替代龙头份额与盈利不及预期，或全球风险偏好回升后资金仍只买美国AI，则该转向失效。

观点 4：美联储12月+明年3月加息后中性，油价短期紧、长期缓

  • 观点归属： 经济学家 Jenny（转述美国团队与全球原油分析师）
  • 结论： 基准仍是12月与明年3月各25bp后回中性；Brent从当前约100美元向70美元回落时点提前至明年四季度，但上半年柴油与原油供给仍紧。
  • 前提事实： 10月非农超预期但劳动参与率同步回升、失业率未大改善、实际薪资与工时偏弱；民主党夺回两院后对特朗普制衡上升、共和党内反战声音增加；沙特设施遭袭、俄出口低、大西洋炼厂关停。
  • 推导逻辑： 就业量强质弱+无过热 → 支持12月加息但无需连续激进 → 地缘降温预期压低远期油价 → 短期供给扰动仍支撑通胀担忧
  • 隐含假设： 劳动供给恢复持续；美伊谈判艰难但不全面开战；通胀数据以CPI/PPI/PCE与12月初非农为关键验证点。
  • 反例 / 证伪条件： 若失业率大幅下行且薪资加速，或油价不回落反而上冲，或美联储跳过12月加息，则基准路径被证伪。

观点 5：中国出口韧性+人民币升值降温+财政需中央发力

  • 观点归属： 邢自强 Robin + Jenny
  • 结论： 明年出口增速从今年20%多降至10%左右但仍远高于十年均值5.6%，且向不依赖进口芯片的非AI链扩散后对GDP净贡献或上升；人民币一揽子已近历史高点，央行已明确降温，内需需中央扩大赤字转向消费社保而非地方顺周期收税。
  • 前提事实： 今年出口靠AI硬件但大量芯片依赖进口，净出口对GDP贡献弱于去年；10月PPI表面高但中下游无法转嫁，属输入式油价扰动；央行10月发文+加大中间价逆周期因子+5年来首次上调外汇存准率；8000亿新型政策性金融工具已投完，基建高频略加快。
  • 推导逻辑： AI外需+电网绿能国防等共同支撑亚洲投资大周期 → 非AI出口接力 → 进口依赖下降使净出口改善 → 人民币升值损害非AI企业盈利+资本外流压力 → 央行稳汇率 + 需中央财政接力地方置换到期缺口
  • 隐含假设： AI capex周期延续只是延迟；汇率与经常账户非线性、资本账户流出构成贬值压力；地方2万亿置换结束後流动性压力大于今年。
  • 反例 / 证伪条件： 若明年出口远低于10%或再度集中于高进口依赖环节，或人民币在央行干预下仍单边大升，或中央赤字实质扩张且社保存量改善，则其中对应子判断需修正。

结构化笔记｜【重磅内容】大摩闭门会议（11-09）｜市场对数据中心反应过度，中选后中国市场布局思路

1. 核心结论

  • 结论1：美国AI并非基本面崩塌，而是建设节奏拉长，闭眼买硬件时代过去。 适用条件：2027年已过环评在建项目不受影响、头部云厂商27-28年CapEx总量预测维持不变成立时；边界是2028年相关州约1/5项目推迟至2029年，效率与融资分化加剧。
  • 结论2：中选后布局中国空间打开，应转向更平衡组合而非全面押注AI链。 适用条件：全球AI交易争议未消、美股波动未稳，且中国科技仍面临名单与限制风险时；边界是主线聚焦国产替代卡脖子标的，而非全面放弃科技。
  • 结论3：不要对中美关系缓和抱幻想，科技限制不缓和甚至小幅升级。 适用条件：民主党控制国会后贸易政策可预见性提高但方向不松动成立时；边界是非战略敏感消费、家电、机械出口确定性提高，不代表美国本土市场准入改善。
  • 结论4：美股短期宽幅震荡但2027年向上格局不变，中国红利仍需作为压舱石。 适用条件：基本面强劲+标普500约18倍估值合理+中选后6-12个月历史规律有效时；边界是短期标普500可能试探7000-7300点区间，全球未马上趋稳。

2. 专家观点与逻辑链

观点 1：美国数据中心推迟而非取消

  • 观点归属： 邢强 Robin，转述全球超20个团队联合评估
  • 结论： 27年建设无忧，28年相关州约1/5项目推迟至2029年，头部云厂商27-28年CapEx总量预测不变
  • 前提事实： 美国数据中心短板是电力供应和地方审批而非芯片；民主党大赢并拿下参众两院控制权及数据中心头部州州长职位；27年在建项目已拿批文
  • 推导逻辑： 民主党控国会+地方执政 → 提高审批、税收返还、电水价补偿要求 → 28年项目推迟至29年，但总量不变
  • 隐含假设： 监管仅加前置条件而非禁止建设；云巨头能消化更高成本和更慢速度；环评电力约束不进一步恶化到27年项目
  • 反例 / 证伪条件： 若27-28年头部云厂商下调CapEx指引，或28年推迟比例远超1/5、27年项目停工，则观点失效

观点 2：算力外溢与模型小型化加速

  • 观点归属： 邢强 Robin
  • 结论： 美国本土受阻将倒逼算力向东南亚、欧洲、中东转移，并加速模型蒸馏、小型化和单位兆瓦算力效率追求
  • 前提事实： 本土审批阻力上升；中国长期受芯片制约已走效率路线；大厂开始做模型蒸馏、架构优化和定制芯片
  • 推导逻辑： 本土建造成本上升+速度放缓 → 海外找地建+提升效率 → 算力结构性转移
  • 隐含假设： 海外电力、审批、政策允许承接；小型化模型能维持足够能力；地缘不阻断海外算力扩张
  • 反例 / 证伪条件： 若海外同样收紧数据中心审批，或效率提升停滞、大模型仍依赖暴力堆算力，则逻辑不成立

观点 3：AI融资分化加剧，边缘融资承压

  • 观点归属： 邢强 Robin
  • 结论： 只有资金雄厚、有存量发电资产和自研模型能力的云巨头能消化新成本，二三线依赖借贷套现式融资的NeoCloud类主体面临严苛审查
  • 前提事实： 融资市场类似05年脆弱格局，NeoCloud已现裂缝；新监管提高建设成本和周期
  • 推导逻辑： 监管成本上升+建设拉长 → 融资门槛提高 → 头部集中、尾部承压
  • 隐含假设： 利率和信用环境不大幅宽松救助尾部；电力批文锁定能力决定融资可得性
  • 反例 / 证伪条件： 若二三线主体仍能低成本大额融资扩建，或巨头出现资金链紧张，则分化判断失效

观点 4：中国出口存下行风险，需中央资产负债表发力

  • 观点归属： 邢强 Robin，转述中国经济学家观点
  • 结论： 今年出口好基于海外AI超级周期，若外需CapEx放缓则明年出口承压；10月PPI偏高是输入式油价昙花一现，中下游无法转嫁，仍需中央主动扩表而非顺周期收紧
  • 前提事实： 今年出口强、内需弱；PPI表面高但产能过剩、消费疲弱；地方债置换到期、五险一金收紧、税收倒查、海外征税等共振收紧
  • 推导逻辑： 海外AI周期遇阻 → 出口下行 → 叠加财政顺周期收紧 → 通缩压力 → 需中央扩表对冲
  • 隐含假设： AI外需与中国出口高度相关；地方财政流动性明年更紧；政策未到类似9·24级别转向阈值
  • 反例 / 证伪条件： 若明年出口保持强劲，或PPI向CPI持续传导、消费复苏，或中央提前大幅扩表，则风险判断需修正

观点 5：聚焦国产替代，而非放弃科技主线

  • 观点归属： 首席策略师 Laura
  • 结论： 上半年紧跟全球AI的国产替代+出口绑定主线中，28年后速度可能delay背景下，应更聚焦国产替代卡脖子、高市占率、可见性好的个股；地缘风险溢价未降
  • 前提事实： 上半年A股与美股高频共振，主线是AI周期；民主党执政期地缘风险溢价上升最快最持久；特朗普第二任期后中美进入相对可预见休战
  • 推导逻辑： 民主党控国会 → 科技/军备限制不缓和甚至升级 → 国产替代紧迫性提高 → 聚焦卡脖子标的
  • 隐含假设： 国会鹰派态度主导科技政策；国产替代标的盈利确定性高于受国内宏观拖累板块；名单风险持续存在
  • 反例 / 证伪条件： 若出现科技限制实质松绑，或国产替代龙头份额/盈利证伪，则应回摆全球供应链主线

观点 6：非科技板块打开，红利压舱+美股先震荡后向上

  • 观点归属： 首席策略师 Laura，转述美国策略师Michael Wilson观点
  • 结论： 贸易可预见性提高利好消费电子、家电、机械出口链；环保绿能主题回归利好中国链情绪与资金流；油价、收益率缓和利好交运航空下游化工及生物医药；短期全球震荡下高红利银行等仍需配置；美股短期试探7000-7300点震荡，2027年向上
  • 前提事实： 特朗普贸易政策摇摆不可预见，民主党贸易不松但可预见性更高；中国绿能全产业链全球第一；美股调整后标普约18倍PE合理；历史中选后6-12个月涨15-22%
  • 推导逻辑： 政策可预见性提高+油价收益率企稳预期 → 出口链/绿能/高油价高利率受伤板块修复 → 平衡组合可行；美股消化不确定性 → 短震荡长向上
  • 隐含假设： 伊朗问题及油价收益率逐步缓和；美国本土绿能准入不改善但情绪资金改善；全球流动性冲击可控
  • 反例 / 证伪条件： 若贸易实质升级、油价收益率再冲高，或美股基本面恶化跌破震荡区间并下调27年预期，则布局失效
