2. 专家观点与逻辑链

观点 1：错失时代比泡沫更贵

  • 观点归属： 但斌
  • 结论： 普通人对AI应克服担惊受怕，全力以赴参与伟大时代，否则一生短暂、事后终身后悔。
  • 前提事实： 从业34年经历互联网、移动互联网，真正赚到钱者极少；比特币、2000年搜狐新浪网易、腾讯等案例显示时代红利稍纵即逝；ChatGPT在2022年底发布开启新时代。
  • 推导逻辑： 重大技术革命出现 → 早期参与者获得指数级财富 → 犹豫只看泡沫者错过0到1 → 结论：宁可承担波动也要在正确方向坚持
  • 隐含假设： AI是堪比甚至超越互联网的跨世纪革命；个人有能力选对方向或买指数跟住时代。
  • 反例 / 证伪条件： 若AI资本开支长期无法转化为利润、巨头集体削减投入、通用人工智能证伪，则“全力以赴”将造成永久性亏损。

观点 2：从茅台到英伟达，标准没变：投创造巨大财富的伟大公司

  • 观点归属： 但斌
  • 结论： 投资要投改变世界商业模式的公司，都有清晰价值线，不能刻舟求剑。
  • 前提事实： 2003年茅台市值180亿低于库存价值220亿，5年酿造+茅台镇稀缺+产量扩张+草根调研显示价格终超五粮液；2015-2016年已研究英伟达，《时间的玫瑰》再版已论及；谷歌2000亿资本支出对应5000亿云订单。
  • 推导逻辑： 发现被低估的好企业基本面 → 伴随其成长为伟大公司 → 获得高回报 → 结论：茅台逻辑与英伟达谷歌逻辑同源，只是载体从消费变为技术
  • 隐含假设： 财务报表、订单、产能扩张能真实反映价值创造；研究者能持续学习迭代。
  • 反例 / 证伪条件： 若茅台中产消费、提价能力瓦解，或英伟达需求系虚假订单、推理需求100倍增长落空，则伟大叙事不成立。

观点 3：白酒逻辑曾成立，现在必须正视需求变迁

  • 观点归属： 但斌
  • 结论： 12-13年塑化剂反腐时坚持因认定是中产需求且基本面未变；现在年轻人结构、年龄、社交方式变了，不能死守。
  • 前提事实： 08年金融危机、12-13年塑化剂反腐一股没卖；近期观察到60岁前后酒量骤降、独生子女就业心态变化、掼蛋等新社交挤占酒局。
  • 推导逻辑： 当年基本面未变 → 坚持20年正确 → 现在人口结构与文化出现变化 → 结论：需迭代认知而非无条件坚守白酒
  • 隐含假设： 草根观察到的饮酒行为变化代表长期趋势而非周期波动。
  • 反例 / 证伪条件： 若商务宴请与中年转化恢复、白酒提价与销量回升，则“需求走弱”判断被证伪。

观点 4：AI不是互联网泡沫重演，是巨头重资产推动的更大革命

  • 观点归属： 但斌
  • 结论： AI革命比互联网更伟大、更颠覆，重资产即护城河，质疑者应去沽空而非嘴炮。
  • 前提事实： 当年互联网是从小公司从无到有；这次是谷歌、微软、亚马逊、台积电等巨头每年数千亿投入；台积电魏哲家称调研上下游需求确定、美光黄仁勋称供给受限、巴菲特亲购谷歌800亿债并成第三大重仓。
  • 推导逻辑： 只有巨头投得起万亿级投入 → 建成他人无法复制的算力护城河 → 先实现AI者达10万亿至30万亿市值 → 结论：这是大公司推动的革命，泡沫论不改变产业趋势
  • 隐含假设： 巨头管理层表态与订单真实可信；资本开支能形成有效护城河而非过剩产能。
  • 反例 / 证伪条件： 若巨头大幅削减资本开支、云增速断崖、做空AI者大赚，则革命叙事证伪。

观点 5：中国AI仍有机会，优势在制造与应用

  • 观点归属： 但斌
  • 结论： 中国在AI领域全力以赴，硬件产业链与应用场景最可能全球领先。
  • 前提事实： DeepSeek、Kimi、字节、腾讯、阿里资本开支接近上千亿；硅谷华人工程师占比高，华人创业融资5000万美元案例；美国企业采购中心在东莞深圳、速度快；伯克利博士成果直接创业。
  • 推导逻辑： 工程师红利+拼搏精神+国家支持+丰富应用场景 → 制造与应用环节承接英伟达谷歌机器人链 → 结论：中国公司可在配套硬件与应用上竞争
  • 隐含假设： 中美技术融合不彻底脱钩；A股波动可通过高位卖出应对。
  • 反例 / 证伪条件： 若核心算力被卡死、A股相关公司只有估值无订单利润，或人才回流创业失败率极高，则机会判断失效。

观点 6：投资是比远见和人性的行业

  • 观点归属： 但斌
  • 结论： 投资比谁看得远、看得准、敢重仓、能坚持；唯一铁律是不加杠杆；最大错误是想的和做的不一致。
  • 前提事实： 08年高仓位大亏没卖，15年6月预判类87年股灾卖到只剩茅台10%+平安，16年2月满仓回；25年贸易战误判系统性风险减仓AI后发现是次要矛盾，不计成本买回；中概私有化套利因政策跌破清盘线自掏数千万补仓。
  • 推导逻辑： 主因是AI大时代、次因是贸易战等扰动 → 次因不改变主因即纠错买回 → 结论：将军赶路不追小兔，短期价差回看无意义
  • 隐含假设： 投资者能区分主因与次因；自有资金、无杠杆才能承受回撤并纠错。
  • 反例 / 证伪条件： 若所谓次要风险演变为长期系统性衰退，或重仓标的基本面恶化仍不卖，则远见+坚持变为巨亏根源。

2. 专家观点与逻辑链

观点 1：A股回报不差但波动极大，散户难赚钱

  • 观点归属： 主嘉宾
  • 结论： 上证从100点到3900点约39倍，加回约2%分红复合约10%，与美股平均回报相近，但承担数倍波动率，故多数人赚不到钱。
  • 前提事实： 人口与股民规模特别大，极端行为更厉害；偏离基本面的时间与程度远超其他市场；波动率越大赚钱概率越小。
  • 推导逻辑： 人口股民基数大 → 乌合之众行为放大 → 偏离基本面更久更深 → 高波动吞噬10%均值回报 → 普通人难赚钱
  • 隐含假设： 指数点位可比且分红再投资假设成立；波动主要来自散户集体行为而非基本面本身。
  • 反例 / 证伪条件： 若剔除分红口径、指数编制偏差后长期回报显著低于10%，或波动率经测算并不高于成熟市场，则结论不成立。

观点 2：A股是多重博弈市场，散户是最后顺位

  • 观点归属： 主嘉宾
  • 结论： 国家、地方政府、大股东、管理层、社保公募等利益均在散户之前，散户必须认清弱者位置，只追求小股东利益。
  • 前提事实： 科技新股高估值背后是国家战略引导资金；巴菲特只研究企业在美国可行，在A股不只看基本面；中石油48元、好公司买贵仍亏是常态。
  • 推导逻辑： 多层强势利益叠加 → 价格不只由基本面决定 → 弱者以强者心态下注 → 必然踩坑输大钱
  • 隐含假设： 各利益方行为持续影响定价且信息不对称无法消除；散户无法通过专业能力逆转顺位。
  • 反例 / 证伪条件： 若散户能长期靠择时战胜多重博弈主体，或注册制+法治使中小股东保护达到成熟市场水平，则弱者论减弱。

观点 3：真钱标准——价格合理+现金流+分红

  • 观点归属： 主嘉宾
  • 结论： 第一价格要合理，第二必须有真金白银现金流和分红；无现金流的低PE是陷阱，赚了还得全投回去的是GDP公司。
  • 前提事实： 环保垫资股、地产产业链靠垫资无真实现金流后跌90%；重资产企业利润全变厂房设备，遇下行无回报；分红要缴税故难造假。
  • 推导逻辑： 无真实现金流 → 利润为假 → PE崩塌 → 低估值是陷阱；有现金流但被迫再投入 → 股东无分文 → 对投资者无价值
  • 隐含假设： 会计真实性虽进步但仍需分红验证；现金流可持续且可分配。
  • 反例 / 证伪条件： 若无分红、无现金流公司长期靠成长兑现高回报，或高分红公司出现财务造假，则标准失效。

观点 4：不买下行周期，等退出出清

  • 观点归属： 主嘉宾，主持人认同补充
  • 结论： 绝不在行业下行周期下重注，最大亏损来自低估下行的时间长度与惨烈程度，必须看到退出、破产、出清。
  • 前提事实： 资本过剩→回报率下降→股价下跌；钢厂、电解铝因退出难易不同反转分化；光伏、养猪退出难故难反转；金融地产下行超预期惨烈。
  • 推导逻辑： 资本涌入过剩 → 回报率下降 → 股价下跌亏损 → 无人退出则供过于求持续 → 贸然抄底加剧过剩
  • 隐含假设： 周期可观察且退出是供需再平衡的必要信号；地方政府输血等非经济因素不会无限延续。
  • 反例 / 证伪条件： 若行业靠技术跃迁未经历退出即反转，或政策强力出清一夜完成，则等待退出会错过底部。

观点 5：地产见底不等于出清，大概率永远不买地产股

  • 观点归属： 主嘉宾
  • 结论： 地产价格止跌不代表出清，因债务仍在奔跑；原有高负债房企难获超生，看好见底应买银行而非地产。
  • 前提事实： 2021年清仓地产在历史高位；银行股价先跌而业绩增长是市场提前计提坏账，坏账预期改善后银行上涨；房企债务未彻底重组。
  • 推导逻辑： 资产价格止跌 + 债务利息奔跑 → 资不抵债持续 → 外部股东分不到增量 → 银行坏账预期改善先受益
  • 隐含假设： 银行拨备与估值已充分反映坏账；房企无整体债务豁免或重组。
  • 反例 / 证伪条件： 若美元债等债务获彻底减免重组，或房价持续回升覆盖债务缺口，地产股可重估。

观点 6：新股首日冲天是散户买上去的，T+1与涨跌停是保护

  • 观点归属： 主嘉宾，依据交易所数据
  • 结论： 多只科技新股首日暴涨主力是散户而非机构，是T+1无做空下形成的投机盈利模式；放开T+0散户死更快，大陆保护好于港股。
  • 前提事实： 上市首日基金被限制买入；T+1当天不能卖，多头连续拉升胜率高；比亚迪式一天38元到18元再回38元在港股消灭融资盘；港股本地散户已被坑怕、流动性差。
  • 推导逻辑： 散户数量巨大且信念一致 → 首日合力抬价 → T+1锁定卖盘+无空方 → 短线打新投机胜率高 → 若改T+0+无涨跌停 → 强者碾压更快
  • 隐含假设： 交易所披露的账户类型数据准确；散户行为模式稳定可重复。
  • 反例 / 证伪条件： 若穿透数据显示实为机构分仓马甲，或T+0试点后散户生存率反而提高，则结论推翻。

观点 7：市场失衡源于过度抱团，需控增量、控两融、查漂移

  • 观点归属： 主嘉宾
  • 结论： 今年3倍到300倍畸形估值与价值股被抛弃加剧投机；应保持均衡水位，并用平准基金逐年增持不净退出、热门股提保证金限两融总量、新资金限投低迷方向、严查风格漂移。
  • 前提事实： 早年8-30倍区间跌到8倍大概率见底，现5倍仍可跌到3倍；4-6月科技抱团后7月腰斩，价值经理被迫砍仓追高左右打脸；2015年高杠杆教训与韩国教训；头部股日成交几百亿含大量融资盘。
  • 推导逻辑： 过度倡导单一方向 → 价值股估值塌陷亏损 → 价值派被迫投机 → 抱团更极端 → 波动失安全感被迫救市；控杠杆+锁增量+守契约 → 降低烈度与示范效应
  • 隐含假设： 监管有能力识别热门股与漂移并执行；平准基金操作公开透明不制造新不公。
  • 反例 / 证伪条件： 若严控两融与漂移后抱团依旧、流动性枯竭，或平准基金增持反而固化扭曲，则机制无效。

观点 8：金融新消费与偏见投资、时间复利

  • 观点归属： 主嘉宾
  • 结论： 地产泡沫破灭终结虚假高无风险收益，全行业负债成本大降但更安全，是新周期起点；只参与偏见造成的低估，做正确因、结果随缘，时间越长价值越大。
  • 前提事实： 过去存款4%需配6-7%资产赚利差，两融8.5%、险资成本3%，今存款约1%、贷款2.5-3%、两融约4.5%、寿险预定1.5-1.75%；当年煤炭6倍PE因碳中和、ESG、周期股三重偏见被抛弃后反转；茅台从8-25倍到奢侈品35倍+增速超预期。
  • 推导逻辑： 地产刚兑打破 → 无风险收益下行 → 低成本配低风险资产仍盈利且更安全 → 股东视角不卷；偏见压估值 → 基本面未坏 → 偏见消除估值修复 → 先50%熬三年、后50%三月完成
  • 隐含假设： 低利率持续且金融机构不重走高风险追收益老路；所认定的偏见确为认知错而非基本面恶化。
  • 反例 / 证伪条件： 若利率重回高位或金融机构风险反而上升，或低估实为需求永久消失，则新周期与偏见论不成立。
