# 结构化笔记｜【最新】大摩闭门会（2026-10-23最新）创新科技机会前瞻：中国创新药四季度三道关

## 1. 核心结论

1. ESMO常规摘要已落地、LBA在10月23-27日密集读出，科伦博泰肺癌一线与恒瑞/豪森/康方等LBA是四季度首道验证关。适用条件/边界：仅在LBA细节（OS曲线维持度、安全性拆分、全球与中国数据一致性）符合预期时成立，不以早期ORR单点外推。
2. 恒瑞三季度创新药销售环比二季度迷你反腐阶段复苏、全年192亿目标大概率达成，叠加GSK/BMS首付款年内确认，构成业绩+BD双支撑。适用条件/边界：仅适用于BD确认节奏不延后、降价与放量假设不变的情形，若首付款确认跨年则当年利润预期下修。
3. 康方Harmony-3全球三期大概率PFS显著，但OS趋势承压是全球化验证的关键分歧。适用条件/边界：该判断基于对照组换为K药、≥75岁及非亚裔VEGF相关不良反应更高导致停药率上升的假设；若停药率可控或随访延长后OS HR≤0.75，则悲观假设被证伪。
4. 板块维持选择性增持，优先具备现金+商业化+license-in资金的风险承担能力与全球差异化资产稀缺性的平台型公司。适用条件/边界：仅在授权首付款占比维持高位、现金跑道延长逻辑延续时成立；若高利率/弱风险偏好持续压制成长股估值，买入节奏需放缓，不改变基本面改善方向本身。

## 2. 专家观点与逻辑链

### 观点 1：ESMO LBA是四季度首道关，科伦博泰数据关注度最高

- **观点归属：** 摩根士丹利 Alex闫肖一
- **结论：** 科伦博泰与默沙东合作的肺癌一线数据及二线子宫内膜癌全球首次数据是最值得关注的LBA，其次是恒瑞3个LBA、豪森B7-H3 ADC骨肉瘤中国三期等。
- **前提事实：** 10月19日常规摘要已公布，LBA在10月23-27日陆续公布；已公布常规摘要中石药PD-1/IL-15双抗后线HCC ORR约40%、CRC约20%+，豪森B7-H3 ADC全球Ⅱ期二线小细胞肺癌8mg/kg ORR达61%，科伦博泰精致三阴乳腺癌中国三期final OS HR约0.60。
- **推导逻辑：** `常规摘要多为早期/确证性更新 → LBA集中承载一线大适应症与全球首发数据 → 科伦博泰一线NSCLC有效性+全球试验读出决定估值弹性最大`
- **隐含假设：** LBA数据质量与市场预期的差值仍是股价主要驱动；中国数据可部分外推至全球。
- **反例 / 证伪条件：** 若LBA仅为安全性更新、无PFS/OS细节，或全球数据与中国数据不一致导致可比性下降，则关注度逻辑失效。

### 观点 2：康方依沃西胆道癌OS成功支持肺癌外适应症扩张

- **观点归属：** 摩根士丹利 Jack廖志全
- **结论：** 依沃西单抗胆道癌三期OS成功意义超预期，看好其在肺癌以外适应症扩张，市场对该部分预期不足。
- **前提事实：** 胆道癌Ⅱ期中位OS 16.8个月，对照历史IMbrave151约13个月；既往贝伐珠单抗加入PD-L1方案改善PFS但未转化为OS；现三期OS已宣布成功，待公布曲线细节；已有Harmony-2/Harmony-6 OS证据。
- **推导逻辑：** `既往同适应症PFS获益未能转化OS → 依沃西此次实现OS获益 → 说明双抗机制在该领域具差异化生存获益能力 → 可外推至其他非肺癌适应症`
- **隐含假设：** Ⅱ期至Ⅲ期人群可比；OS获益主要来自药物机制而非后线治疗偏倚；安全性代价可接受。
- **反例 / 证伪条件：** 若周末公布的OS曲线后期收敛、HR边际显著，或≥3级不良反应显著高于对照导致获益风险比恶化，则扩张逻辑不成立。

### 观点 3：信达IBI343靠胃肠道耐受优势打开预期上调空间

- **观点归属：** 摩根士丹利 Jack廖志全
- **结论：** Claudin18.2 ADC IBI343后线胃癌三期若OS具竞争力，有望连同耐受性优势推动投资者上调目前有限的资产贡献预期。
- **前提事实：** 三期针对Claudin高表达三线后胃癌，PFS已宣布成功；早期确认ORR约32%、PFS 5.5个月；重度恶心呕吐各约1.6%，低于同靶点竞品CMG901历史约6%。
- **推导逻辑：** `胃肠耐受更好 → 持续用药依从性更高、联合空间更大 → 若OS再具竞争力 → 三期价值+耐受性形成双击 → 估值贡献上调`
- **隐含假设：** 早期耐受数据可在三期复现；OS与PFS方向一致；投资者当前计入贡献确实偏低。
- **反例 / 证伪条件：** 若三期OS未达统计显著或仅边际获益，或恶心呕吐在更大样本中上升，则上调逻辑失效。

### 观点 4：再鼎ADC+双抗一线小细胞肺癌双药方案有望替代化疗

- **观点归属：** 摩根士丹利 Jack廖志全
- **结论：** 偏好Zai Lab ZL-1310 ADC+免疫双药一线方案，有机会以更高缓解+更低化疗负担替代依托泊苷+铂化疗。
- **前提事实：** 历史免疫+化疗一线小细胞肺癌缓解率约60%、PFS约5.2个月；双药15例ORR达80%；管理层指引PFS增长50%以上、约8个月；双药≥3级治疗相关不良事件约27%，传统方案约67%。
- **推导逻辑：** `ORR 80%+预期PFS延长 → 疗效占优 + 严重不良事件减半 → 双药联用具备替代化疗基础 → 并为三药联用留出空间`
- **隐含假设：** 小样本ORR可外推；PFS指引可兑现；安全性在扩大样本中不恶化。
- **反例 / 证伪条件：** 若周末公布的PFS远低于8个月，或长期随访毒性累积、停药率上升，则替代逻辑不成立。

### 观点 5：恒瑞业绩复苏+BD确认节奏明确

- **观点归属：** 摩根士丹利 Alex闫肖一
- **结论：** 恒瑞三季度创新药销售环比改善，全年目标与BD收入确认节奏均偏正面。
- **前提事实：** 二季度受迷你反腐影响；公司全年创新药销售目标192亿；GSK合作预计约2.5亿美元首付款计入今年，BMS合作约2-2.5亿美元，诺和诺德口服GLP-1周制剂合作年内关闭但确认节奏未定；自免MIR124 UCⅡ期、SHR-1905银屑病Ⅱ期数据具竞争力。
- **推导逻辑：** `二季度低基数+临床需求恢复 → 三季度销售环比改善 → 叠加BD首付款年内集中确认 → 全年收入与利润支撑增强`
- **隐含假设：** 集采/谈判降价不超预期；BD里程碑确认会计处理符合预期；自免POC数据可延续至全球Ⅱ期。
- **反例 / 证伪条件：** 若三季报创新药增速未环比改善，或GSK/BMS首付款递延至2027年确认，则全年达标判断下修。

### 观点 6：Harmony-3全球验证：PFS成功概率高，OS是主要风险

- **观点归属：** 摩根士丹利 Jack廖志全、Vanessa
- **结论：** 预计Harmony-3 PFS达统计显著，但相对中国Harmony-6优势幅度收窄，OS随访短、主要看趋势；FDA 11月14日对三代EGFR-TKI经治肺癌适应症审批仍要求PFS与OS双显著，OS HR 0.79-0.76未达显著是主要风险，但仍有获批可能。
- **前提事实：** Harmony-6中国PFS 11.1 vs 6.9个月、HR 0.6，OS HR约0.66；Harmony-3对照为K药+化疗，可用白蛋白紫杉醇，美国专家认为OS HR 0.7-0.75具说服力；全球Harmony研究PFS达标、首次OS HR 0.79未显著、更新约0.76；亚裔占比从30%提至50%仅改善总体HR约0.01。
- **推导逻辑：** `对照换K药+≥75岁占比高+非亚裔VEGF毒性及停药管理差异 → PD-1暴露下降 → PFS影响小、OS稀释大 → PFS成功但OS需更长随访验证`
- **隐含假设：** K药OS优于特瑞普利单抗；75岁以上及白人出血/血栓风险更高且停药更多；中国医生不良反应管理使停药率更低。
- **反例 / 证伪条件：** 若Harmony-3 PFS未显著，或OS HR≤0.7且随访成熟后显著，则稀释担忧被证伪；FDA若明确不坚持OS双显著，审批风险逻辑亦重估。

### 观点 7：四季度选择性增持，沿双主线配置

- **观点归属：** 摩根士丹利 Jack廖志全
- **结论：** 市场情绪偏弱但基本面持续改善，建议沿核心平台+明确催化剂新兴创新两条线选择性增持，核心偏好信达、康诺亚。
- **前提事实：** 授权首付款已占资金来源约16%+，现金跑道中位数从2023年2.6年延至2025年4.9年，更多公司1-2年内走向盈利；创新药支付CAGR 2025-2030年约21% vs仿制药2%，占比有望29%提至53%；医保谈判9月完成、11月14日公布结果。
- **推导逻辑：** `license首付款+商业化放量 → 融资依赖下降、现金延长 → 有能力将临床推更远再谈合作、保留更多海外权益 → 具备风险承担力+稀缺资产的平台最受益`
- **隐含假设：** 政策支持真正落到支付端、医保降幅温和；BD市场持续活跃；盈利改善可持续。
- **反例 / 证伪条件：** 若医保平均降幅仍达50-60%未收窄，或BD首付款大幅下滑、再融资依赖回升，则增持框架失效。
