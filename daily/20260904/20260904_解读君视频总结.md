# 解读君视频摘要

## 1. 【最新分析】大摩内部闭门会（2026-9-4最新）科技项目下一步的思考和布局

1. **模型能力仍是估值第一因子，ARR超预期只是加分项，适用条件是买方认可模型为SOTA或接近SOTA。** 若模型口碑不佳，即使ARR超预期或指引上调，市场也不愿给高估值；反之模型被认可，指引偏保守也可被容忍。
2. **MiniMax与智谱下半年ARR高增长高度依赖新旗舰模型+算力交付，存在兑现节奏风险。** MiniMax 8月底ARR约8亿美元（周口径），年底指引维持10亿美元以上，大摩上调预期至13亿，隐含假设是M4.1/视频H4.1及M4 Pro如期发布并带来推理量爬坡；智谱7月ARR约10亿美元、8月约16亿美元（月均口径，周口径超20亿），年底指引24亿美元被认为偏保守，但公司明确下半年实现程度取决于算力集群到货，四季度国产卡交付是关键变量。
3. **两家模型公司上半年毛利率偏低多为一次性因素，下半年有望环比改善，但长期分化明显。** 前提是推理优化爬坡完成、补贴退坡、新模型放量。若推理成本优化不及预期或持续降价补贴，改善会被推迟；稳态上文本模型毛利率40%-50%，多模态高于50%，智谱对未来12-18个月开放平台毛利率50%以上的预期偏积极，需验证。
4. **腾讯AI叙事正从“模型追赶”转向“模型+应用生态协同”，但收入兑现仍需SOTA背书。** 混元4 Preview发布早于预期、内部盲测略高于GLM-5.3和Kimi K3，若正式版能进SOTA则可期待Model-as-a-Service；若只是“还不错”，则主要靠元宝开放Agent生态和微信AI带来的数据飞轮间接变现，短期难量化。
5. **美团与阿里短期股价更多受补贴节奏、融资情绪与催化时点驱动，而非基本面突变，适用区间是竞争不退补但趋稳的环境。** 美团Q2超预期主要靠到店margin回升至30%及费用后移，Q3指引偏弱（外卖UE约0.3→0.1，到店margin回25%），目标价120→110港元，70-90港元区间震荡；阿里基本面变化不大，弱势主因拥挤交易、配售时点差及缺乏催化，下一催化看9月22日当周云栖大会及通义千问4.0更新。

## 2. 私募大佬王文深层次讲解（2026-9）中国A股的底层到底存在什么问题？

**结论1：A股难做价值投资，根源是2亿账户主导的投机结构，短期投机淹没价值，但极端投机反为价值者创造低价机会。**
适用条件/边界：仅在散户占比高、追涨题材的市场阶段成立；若市场机构化程度大幅提升或投机资金退潮，该矛盾会弱化。不意味着所有低价股都有价值，仍需基本面筛选。

**结论2：A股缺乏小股东价值是制度性结果，而非企业技术不行；企业有社会价值、国家价值、大股东价值，唯独流通小股东价值缺失。**
适用条件/边界：适用于依赖融资扩张、竞争格局恶化的制造业与科技股；对真正能持续分红、治理向小股东倾斜的公司不适用。判断关键是分红与自由现金流是否到小股东手里。

**结论3：过度融资迎合国家催肥科技产业目标+地方政府以GDP为目标深度下场，是摧毁行业股东价值的主因。**
适用条件/边界：适用于光伏、动力电池、新能源等地方基金、土地、政策重投入行业；若地方财政约束增强、产业出清完成，或竞争格局转向寡头稳定，该逻辑边际减弱。技术进步好不等于股东回报好。

**结论4：弱者策略才能活下来：以低估值、高现金流、高分红、业务长期可持续为底线守住不亏，再以“被市场忽视的边际变化”博超额收益；并严格区分风险与波动。**
适用条件/边界：适用于以绝对收益、控制回撤为目标的二级价值投资资金；对高仓位单一赛道博弈型资金不适用。分红减震的前提是估值已低且现金流真实可分。
