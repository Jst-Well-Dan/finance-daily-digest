结构化笔记｜大摩周期论剑闭门会（2026-9-9）深入地分析当前整体市场具体细分板块的投资策略解析

1. 核心结论

  • 国有大行注资是预防性、更平衡的安排：在信贷理性放缓、隐债严控背景下，监管不鼓励大行扩张信贷，本轮对大行摊薄更小并分流至保险与政策性金融机构；若基建融资回暖或结构性货币工具加码，结论需修正。
  • 保险注资与保险法大修指向头部集中：嘉宾认为资本补充摊薄可控、利好长期资金入市与风险抵御，监管转向风险导向将强化分化；若定增定价大幅折价或细则放松，摊薄与分化逻辑会被削弱。
  • 集运维持相对谨慎，2027年供给压力难消化：2026年因战争扰动、高油价减速、备库存与港口拥堵而偏紧，但2027年新增交付叠加红海复航的有效运力增幅远超需求增速；若复航停滞或拆解超预期，观点不成立。
  • 现房销售是慢变量的供给侧改革：有助于长期房价企稳但短期关键仍看需求端，一线企稳早于二线与低线；若需求端刺激明显加码，企稳时点可能提前。
  • 开发商分析框架需从利润率转向“净利润率×IRR”：嘉宾测算周转放缓将使销售与长期规模明显收缩，利润修复难对冲，幸存者集中但面临估值下修风险；若地价大幅下调或房价持续上涨，结论需重估。

2. 专家观点与逻辑链

观点 1：金融注资更理性、更平衡，意在防风险而非刺激信贷

  • 观点归属： 嘉宾：中国金融行业首席（转写记为“ri/Ricature”等，待核验）。
  • 结论： 对金融整体偏中性稳健；不认为注资会带来大行信贷扩张，看好长期可持续发展。
  • 前提事实： 转写称2024年9月末宣布大行注资，去年已注资5000亿元（待核验）；年初财政部称用3000亿元特别国债注资（待核验）；本轮为最后一段，除大行外还包括保险和政策性金融机构；嘉宾称去年市场预期1万亿元、实际不足8000亿元（待核验）。
  • 推导逻辑： 预防性注资信号 → 大行信贷仍理性放缓 → 本轮规模更小且分散 → 工行摊薄约3%多、农行约6%（待核验），低于去年建行约4%、他行约10%—20%（待核验） → 监管定位转向理性经营与股东平衡 → 保险获注资支持长期储蓄与资本市场稳定，政策性机构支持海内外平衡 → 观点结论
  • 隐含假设： 我对其逻辑的整理是：资本充足已够、无需信贷脉冲；保险自然保费维持双位数增长可消化注资；政策性项目利润低需财政支持。
  • 反例 / 证伪条件： 大行贷款增速重新加速、保险保费失速导致摊薄超预期、政策性机构风险暴露上升，则“理性平衡”判断被证伪。

观点 2：保险注资摊薄可控，保险法大修利好头部合规公司

  • 观点归属： 嘉宾：保险行业分析师（转写记为“瑞”，待核验）。
  • 结论： 对保险注资偏正面，对大型资本充足、治理透明公司偏乐观，对合规基础弱公司偏谨慎。
  • 前提事实： 转写称财政部注资国寿、人保集团、太平集团（待核验）；人保已公告A股定增，按过去20日均价测算摊薄约4%多（待核验），中期DPS增速近50%（待核验）；极端假设下注资全进上市主体，国寿摊薄约3%出头、太平约9%—10%（待核验）；保险法自1995年发布、经4次小修，本次85条增至214条、征求意见至10月初（待核验）。
  • 推导逻辑： 低利率与偿付能力环境趋紧 → 前瞻性补充资本夯实资产负债表 → 实际注资多在集团层面、用途分散至养老财险海外等子公司 → 真实摊薄小于极端测算 → 法修订强化资负管理法制化、股东穿透、中介准入与有限救助 → 头部份额与估值优势扩大 → 观点结论
  • 隐含假设： 我对其逻辑的整理是：中报强劲可持续；集团层面资金不会一次性压向上市股东；“有限救助”能真正打破隐性兜底预期。
  • 反例 / 证伪条件： 定增大幅折价、集团资金大部注入上市主体致摊薄接近上限，或财险取消4倍杠杆后中小公司加杠杆冒进，则判断失效。

观点 3：集运上调短期盈利但维持相对谨慎，海丰国际降至低配

  • 观点归属： 嘉宾：中国交运行业首席（转写记为“倩磊”，待核验）。
  • 结论： 海运子板块中继续超配油运与干散货、低配集运；将海丰国际由平配下调至低配。
  • 前提事实： 转写称年初至今油运干散货股价近翻倍，中远海控、东方海外涨约20%—30%，海丰国际近翻倍（待核验）；三季度盈利超预期；2027年名义交付近10%、有效运力约+7%，完全复航再增约7%供给，需求仅与全球GDP同步约3%—4%（均待核验）。
  • 推导逻辑： 中东扰动超预期＋高油价减速＋备库存＋天气拥堵 → 2026年有效运力+6%被1—2个点减速与1—2个点扰动对冲至约+3%，供需偏紧运价上行 → 上调2026—2027年盈利 → 2027年新增与复航合计有效增幅超10%，远超需求 → 估值已满 → 观点结论
  • 隐含假设： 我对其逻辑的整理是：红海将现“羊群效应”式复航；海丰历史均值约9倍PE、股息约7%、±1倍标准差约6—12倍的估值锚仍有效（待核验）；市场已计入四季度旺季与特别股息。
  • 反例 / 证伪条件： 红海持续绕行、高油价长期维持减速、拆解量大增，或需求因补库超3—4%假设，则供给过剩推迟；四季度运价显著再超预期也会挑战低配时点。

观点 4：现房销售重构开发商逻辑，短期股价或低估周转冲击

  • 观点归属： 嘉宾：中国房地产行业首席（转写记为“teven/Steven”，待核验）。
  • 结论： 对纯开发房企保持谨慎；相对看好二手成交链与有经营性现金流缓冲的标的。
  • 前提事实： 转写称新政后地产平均回调中高单位数，绿城、建发、经贸等除外（待核验）；已获施工许可项目仍可预售，新规主要针对新出让及未获规划项目；嘉宾一线mass项目IRR由20%出头降至中单位数，拿地到开盘由6—9个月延至24—30个月、现金转正再加12—18个月，周期由约2年延至3—4年（均待核验）；测算覆盖房企销售2027年降约17%、2028年降约35%、两年复合约-24%（待核验）。
  • 推导逻辑： 现房销售属供给侧改革而非需求刺激 → 新增供给下降慢＋工程量降拖累财政就业收入＋存量新房难去化 → 房价企稳慢且分化 → 周转放缓经复利传导为拿地与可售资源收缩 → 利润率改善难抵周转下降 → 流动性分化但不重演大面积违约 → 行业集中但幸存者估值仍有下修压力 → 观点结论
  • 隐含假设： 我对其逻辑的整理是：地方细则不会大幅放松土地付款、开盘与税款节奏；一线地价难大降、弱二线低线才可能调整；银行对民企风险偏好维持低位。
  • 反例 / 证伪条件： 地方给出极友好细则、地价大幅下调、房价年涨2%—3%以上持续兑现，或需求端强刺激提前拉动成交，则销售降幅与估值下修判断需修正；流动性方面若公开债或应付账款集中违约超预期，则“不重演危机”被证伪。
