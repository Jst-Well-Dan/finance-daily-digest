*说明：以下为对转写稿的结构化整理，不是发言人原话。转写稿存在较多语音识别错字（如“新智生产力”应为“新质生产力”、“民生中国指数”应为“MSCI中国指数”、“男皮书”应为“蓝皮书”等），已按语境校正；涉及人名、技术路线和具体数字处仍建议核对原报告。*

## 1. 核心结论

- **2027年仍是转型调整年，不是全面通缩年。** 大摩基准情形为2027年实际GDP约4.4%、官方目标约4.5%，内需增速由3.5%降至3.1%，名义GDP仍受准通缩约束；该判断成立的前提是外需与AI资本开支不明显失速、政策不搞强刺激。若财政/消费政策超预期或出口大幅上修，则“弱内需”判断需调整。
- **全球风险资产被提到最大超配，但中国股票暂不超配。** 多资产组合中股票加仓15个百分点至70%，超配美国、日本、欧洲，新兴市场平配，中国维持平配/持有；前提是AI资本开支不大幅下修、美国2027年盈利增速约14%。若AI资本开支推迟、盈利预期下修或中美科技限制急剧升级，该配置会失效。
- **中国供给侧有三条结构性支撑，但2027年不足以对冲内需。** 全球AI基建与能源转型超级周期、物理AI/工业5.0、投资从“扩产”转向“存量改造”是中期积极因素；条件是全球资本开支兑现、工业5.0投资真实落地。若出口降至个位数或工业5.0变成新一轮重复建设，则结构性逻辑被证伪。
- **2028—2029年走出通缩需要三项政策前提。** 即坚决管住投资冲动、以制度改革落实反内卷；房地产止跌回稳，按揭贴息覆盖存量房并放松一线行政限制；财政避免顺周期紧缩。缺少任一项，可能重演“赢了技术和份额、输了价格和利润”的ROE陷阱。
- **板块方向明确但属研究观点，不构成买卖建议。** 大摩上调生物医药至超配、下调互联网至低配，偏好A股、国产替代与新质生产力；黄金维持看多、铜转谨慎、油看空。上述方向需以盈利、订单、政策落地和估值消化验证。

## 2. 专家观点与逻辑链

### 观点 1：2027年是“磨底调整、准通缩”之年

- **观点归属：** 邢自强（Robin）
- **结论：** 2027年中国经济仍处于K型分化延续期，内需偏弱、新质生产力净拉动不明显，实际GDP约4.4%，名义GDP受准通缩压制；2028年才具备渐进走出通缩的基础。
- **前提事实：** 房价调整带来负财富效应，就业和收入预期偏弱；居民部门持续去杠杆，转写稿称过去13—14个月居民贷款余额累计下降近2万亿元；社保征管规范化短期提高中小企业用工成本；以旧换新政策对2027年有退坡效应；地方化债额度在2027年缩减，地方现金流偏紧；AI算力、电网投资增速虽快，但占全社会固定资产投资比重仍小，且AI初期对初级白领岗位有替代摩擦。
- **推导逻辑：** `居民去杠杆+地方财政收缩+新技术仍处J曲线底部磨合期 → 消费与投资需求偏弱、名义GDP受抑 → 2027年仍是准通缩式调整年`
- **隐含假设：** 没有大规模居民收入或社保刺激；房地产不会快速反弹；外需不出现断崖式下滑；AI资本开支不突然失速。
- **反例 / 证伪条件：** 若财政明显扩张、地产提前止跌、消费补贴加码，或AI应用迅速形成生产率并带动就业，则“2027准通缩”判断需上修。

### 观点 2：全球股票最大超配，中国股票暂不超配

- **观点归属：** 王滢（Laura）
- **结论：** 2027年多资产配置中，股票加仓15个百分点至70%，为可用的最大风险资产超配；超配美国、日本、欧洲，新兴市场平配，中国维持平配而非超配。目标价：标普500为8700点（约+15%）、MSCI欧洲3030点（约+15%）、日经4800点（超+20%）、MSCI新兴市场1760点（约+13%）。
- **前提事实：** 美国2026年盈利增速约34%，2027年约14%，2028年放缓至9%；AI资本开支2027年整体不变，仅少部分从2028年挪至2029年；罗素3000成分股调查中，预计2027年AI能提升本公司业绩的比例升至44%，高于去年的30%多；中国MSCI 2027年盈利增速约8%，对应9.6倍前瞻市盈率，较新兴市场仍有14%溢价。
- **推导逻辑：** `AI资本开支延续+美股盈利扩散+AI应用可见度提高 → 美日欧风险回报优于其他市场 → 股票整体最大超配；中国盈利仅温和修复且估值仍有溢价 → 维持平配`
- **隐含假设：** AI资本开支不因融资、电力或政治约束大幅下修；通胀不迫使央行超预期加息；中美不出现全面科技脱钩；日本盈利和弱日元逻辑延续。
- **反例 / 证伪条件：** 若AI资本开支在2028年前明显推迟、美国盈利预期下修、欧洲或日本盈利不及预期，则超配逻辑弱化；若中国出现强政策刺激、地产企稳且盈利上修，则中国应从平配上调。

### 观点 3：中国盈利温和修复，但估值尚未便宜到“必须超配”

- **观点归属：** 王滢（Laura）
- **结论：** MSCI中国2027年盈利增速约8%（2026年约6%），2028年恢复至约11%；当前9.6倍前瞻市盈率，距8倍历史底部仍有距离，且较新兴市场有14%溢价，因此暂不把中国整体提升为超配。
- **前提事实：** 2026年四季度至2027年上半年仍可能看到盈利预期下修，2027年增长部分来自低基数；人民币小幅升值对盈利有正贡献；2027年市场可能从过度集中AI交易转向更多板块和个股扩散。
- **推导逻辑：** `低基数+汇率小幅升值+板块扩散 → 中国盈利增速由6%小幅升至8%；但估值仍有溢价、盈利仍有下修风险 → 不足以支持整体超配`
- **隐含假设：** 人民币不出现大幅贬值；互联网和地产盈利不再大幅暴雷；中美科技限制不急剧升级；政策不出现大规模需求刺激。
- **反例 / 证伪条件：** 若政策强刺激带动地产和消费企稳、AI应用盈利兑现，使2027年盈利上修至双位数且估值回落，则“平配”判断需改。

### 观点 4：三大供给侧结构性变化支撑2028年之后

- **观点归属：** 郑琳（Jenny）、邢自强
- **结论：** 全球AI基建与能源转型超级周期、物理AI/工业5.0、投资结构边际改善，是2028年后中国走出通缩的中期支撑；但2027年这些力量仍“小荷才露尖尖角”，不足以扭转内需。
- **前提事实：** 全球资本开支预计从2025年约11万亿美元升至2030年约16万亿美元，增量近一半来自广义工业投资，AI与半导体及间接投资再占约两成；中国占全球制造业增加值约28%，拥有超过3万座智能工厂和1亿多台联网工业设备；中国数据中心用电仅占全社会用电约2%，美国已超过6%，中国到2030年预计仅升至4%；中国从研发到量产速度可短于两年，海外常需约四年。
- **推导逻辑：** `全球工业资本开支上行+中国制造/电力/数据/工程师优势 → 出口与工业5.0存量改造受益 → 消化过剩产能、提升生产率 → 2028年后通缩压力缓解`
- **隐含假设：** 全球不出现深度衰退；关税和贸易壁垒不完全抵消中国份额优势；工业5.0以存量改造为主，不演变为新一轮扩产；电力与供应链优势可持续。
- **反例 / 证伪条件：** 若全球资本开支周期见顶、出口份额因贸易壁垒明显下降，或工业5.0变成地方重复建设，则结构性支撑不成立。

### 观点 5：走出通缩需要三项政策前提

- **观点归属：** 邢自强（Robin）
- **结论：** 2028—2029年要真正走出通缩、推动企业ROE显著回升，除技术J曲线跨过拐点外，还需三项政策条件：管住投资冲动、落实反内卷；房地产止跌回稳；财政避免顺周期紧缩。
- **前提事实：** 转写稿称中国约80%的产业政策源自地方招商引资、抓生产搞建设，容易形成重复建设；2009—2015年、2020—2023年两轮扩产均出现“赢技术和份额、输价格和利润”，ROE未改善；当前地方有找税源、加强征管的动机；房地产负财富效应仍压制消费。
- **推导逻辑：** `地方投资冲动+地产下行+财政收缩 → 产能过剩与需求不足并存 → 通缩持续；若制度约束投资、地产修复、财政托底 → 产能利用率和利润率回升 → ROE改善、通缩缓解`
- **隐含假设：** 政策有执行力，不只是口号；按揭贴息能覆盖存量房并形成实际购买力；财政资源足以避免地方现金流断裂。
- **反例 / 证伪条件：** 若反内卷只停留在文件、地产继续下跌、地方财政进一步收缩，则2028年仍难走出通缩，“技术升级自动带来回报”的判断被证伪。

### 观点 6：全球增长有韧性、通胀有粘性，央行进入“迷你加息”

- **观点归属：** 蔡志鹏
- **结论：** 2027—2028年全球增长约3.3%—3.4%，通胀2027年缓慢回落、2028年趋势更明确；美联储、欧洲央行、日本央行均在2026年12月和2027年3月各加息25个基点，随后维持，2028年才进入降息。
- **前提事实：** 2027年增长主要靠AI投资，2028年逐步转向软件、应用和更广泛技术渗透；能源价格总体回落，但柴油等成品油因炼化和运输问题偏紧，可能延续到2027年年中；美国2027年四季度实际GDP同比约2.5%，失业率约4.3%；欧洲年初通胀约4.5%、全年约3.4%；日本2026年增长约0.8%、2027年约0.5%。
- **推导逻辑：** `AI投资+就业韧性 → 增长不差；能源与运输成本+服务通胀 → 通胀有粘性 → 央行只能谨慎加息、延迟降息`
- **隐含假设：** 能源价格不失控；AI投资不突然断崖；工资和服务通胀不加速；地缘冲突不显著升级。
- **反例 / 证伪条件：** 若油价大幅飙升或AI资本开支骤停，则“增长有韧性+通胀有粘性”的组合被打破，央行路径需重估。

### 观点 7：超节点是国产算力的“折中方案”，产业链需求高速扩张

- **观点归属：** 科技分析师 Andy（转写稿末段写作“孟宇”，姓名待核）
- **结论：** 在先进制程受限、单芯片性能落后海外的背景下，超节点是中国AI基础设施的必然选择；市场规模有望从2025年的百亿级增至2030年的万亿级，年均增速超过100%；光互联、PCB/CCL、AI电源、液冷、储能等环节受益。
- **前提事实：** 中国单芯片性能大幅落后海外GPU；中国在网络通讯、光互联领域具备国际领先的研发和产业生态；华为384超节点已发布并商用；海外先进芯片获取越困难，国内对国产超节点的需求越旺盛；但国产超节点也受国内芯片产能和核心零部件制约。
- **推导逻辑：** `先进制程受限 → 单卡性能不足 → 用网络互联和超节点“以长板补短板” → 国产算力系统需求上升 → 光互联/PCB/电源/液冷等产业链扩容`
- **隐含假设：** 国内芯片产能和良率能逐步跟上；客户愿意为超节点付出耐心；生态系统伙伴愿意构建独立编译体系和生态；光互联路线（转写稿中MPO/CPO/NPO混用，需核对）由中国企业保持优势。
- **反例 / 证伪条件：** 若海外先进芯片供应放松、国产芯片产能或良率不及预期、CPO等路线被海外主导，则超节点经济性和产业链受益逻辑减弱。

### 观点 8：2030年三个里程碑

- **观点归属：** 郑琳（Jenny）
- **结论：** 到2030年，中国前沿产业收入规模有望从2025年约1.4万亿美元扩大到3.2万亿美元；商品出口全球份额从约15%升至16.5%；AI与工业5.0有望把2028—2030年年均潜在增速抬高0.3个百分点至约4.2%。
- **前提事实：** 前沿产业增量约九成来自AI、工业5.0和生物医药；中国企业海外扩产、技术商业化和生产体系出海，使“Made by China”的实际影响力大于出口份额数字；反内卷和全国统一大市场有助于约束地方重复建设。
- **推导逻辑：** `产业升级+企业出海+市场扩张 → 收入与份额上升 → 生产率和利润率改善 → 潜在增速提高、通缩压力缓解`
- **隐含假设：** 全球需求不深度衰退；贸易壁垒可控；技术商业化顺利；国内投资效率提升。
- **反例 / 证伪条件：** 若海外再工业化加速替代中国供应链、国内投资回报率持续低下，或AI应用迟迟不能商业化，则2030年里程碑难以实现。
