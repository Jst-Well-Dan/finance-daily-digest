# 结构化笔记｜【2026-11-15最新】华创张瑜最新： 目前整体居民的风险偏好又下去了 中选之后先做均衡才是策略

## 1. 核心结论

1. **居民部门再度进入“预期不稳定、风险偏好全面下行”状态，这是评估一切政策效果的核心约束。** 四条证据同向：二季度起居民贷款对社融拉动转负（消费贷、按揭、经营贷逐月少增，属绝对缩表）；5月起新增居民存款中定存占比上升；二、三季度消费倾向回落至近6年低位（三季度仅高于2020、接近2022）；上市公司人均薪酬与农民工工资增速仅从约2%回到约3%，明显跟不上名义GDP两个点以上的修复与利润增速回升。**边界：** 该判断以居民信贷需求、消费倾向、收入预期三项未出现连续2–3个月企稳为前提；任一环节连续改善即需重估。
2. **股市处于反弹“中段”而非起点，拔估值已变得困难，策略上应借反弹降锐度、促均衡。** 本轮反弹被定性为“宏微观流动性缓解后的估值修复”，12月需防美国通胀粘性、金融条件再度收紧，以及中选后政策不确定性常态化。**边界：** 若12月加息落地后金融条件反而放松、或AI业绩超预期，则“中段”判断偏保守；结构上仍围绕AI硬件，进攻看国产替代/AI应用与困境反转。
3. **红利是2–3年维度的战略底仓，但未来12个月需等风险溢价回落再加大配置。** 收益拆解显示现金分红贡献约45%、盈利约25%、红利再投约21%、无风险利率约18%，风险溢价与调仓为负贡献；据此测算未来一年回报约2%–4%，乐观9%–11%，悲观-2%至-4%；若出现约10%回调、股息率增厚0.2–0.3个百分点，性价比显著抬升。**边界：** 前提是成分股分红稳定、盈利波动可控、无风险利率不大幅上行。
4. **债市中期友好、短期有扰动：政策利率换锚带动资金中枢下移约10BP，但年末止盈赎回与政府债免税政策调整预期压制情绪，宜逢高布局。** 换锚后隔夜逆回购1.25%成为主要政策利率，DR001运行区间由1.15%–1.65%改为1.0%–1.5%，中枢从约1.35%–1.4%降至约1.25%–1.3%。**边界：** 10年国债1.62%、30年约2.08%被视为配置盘有效窗口，但若赎回负反馈扩散至利率品或央行数量投放转紧，则下移逻辑失效。
5. **“新房供地减少→明年房价止跌”的推论不成立：新房只能决定边际溢价，价格锚在二手房与总需求。** 供地较峰值降约75%，但核心城市核心区新房库存仍在增加、今年开发商推盘密集度低于去年；在人口不增、城市不再扩张的条件下，新增住宅需求极小。**边界：** 若核心城市人口重新净流入、二手房价企稳回升或库存显著去化，则该结论需修正；地产股机会在于“选地块赚钱”的alpha（如建发国际）与红利属性标的（如贝壳）。

## 2. 专家观点与逻辑链

### 观点 1：居民风险偏好二次下行，政策效果须以“能否对冲居民收缩”为标尺

- **观点归属：** 华创证券 张瑜（宏观）
- **结论：** 居民部门已再次进入预期不稳定、风险偏好全面下行的状态；评价任何货币/财政政策，核心看它能否抵得过居民风险偏好的下行与收缩，并重新启动“居民加杠杆—消费—再循环”。
- **前提事实：** ①二季度起居民贷款对社融拉动转负，消费贷、按揭、经营贷三大项加总逐月少增，属贷款绝对意义上的缩表；②5月以来新增居民存款中定存比例上升，居民重新“攒定存”；③二、三季度消费倾向在近6–7年同期位置中持续下移，三季度仅高于2020、与2022接近持平，为近6年最低；④上市公司人均薪酬与农民工工资增速约从2%回到3%，方向向好但幅度远小于名义GDP两个点以上的修复与工业利润、上市公司利润的回升，收入与增速的裂口在扩大。
- **推导逻辑：** `居民贷款缩表 + 存款定存化 + 消费倾向回落 + 收入增速跟不上利润修复 → 居民预期不稳定、风险偏好下行 → 政策传导被居民端“收缩”抵消 → 政策效果取决于能否对冲该收缩；对股市意味着拔估值困难、进入区间震荡，对债市意味着核心矛盾从基本面转为央行宽松力度能否对冲存款回表带来的流动性冲击`
- **隐含假设：** 居民行为由预期驱动、短期难以自我修复；宽信用的瓶颈在居民信贷需求而非银行供给；存款回表对股债均构成流动性冲击。
- **反例 / 证伪条件：** 居民中长贷连续2–3个月同比多增、定存占比回落、消费倾向回到同期中位以上；或股市在估值不扩张的情况下由盈利驱动上涨，则“风险偏好下行”与“拔估值困难”同时被削弱。

### 观点 2：反弹已至中段，12月主线是“降锐度、促均衡”而非追高

- **观点归属：** 华创证券策略（“华资疗配”段落，转写不清）
- **结论：** 10月底以来看多的反弹属宏微观流动性缓解后的估值修复，目前处于中段；往后需防美国通胀粘性与金融条件再收紧，以及中选后政策不确定性快速显现，建议借反弹降低组合锐度、做均衡。
- **前提事实：** 12月存在50BP加息的可能（最新PPI数据后基准情景仍为25BP）；若真落地50BP，并非利空出尽式冲击，而说明过去半年市场对通胀持续性与紧缩程度定价不足；中选落地后AI业绩不确定性上升，英伟达管理层变动进一步扰动产业链；红利内部对4.5%股息率（部分银行仅3%出头）分歧较大。
- **推导逻辑：** `流动性缓解 → 估值修复 → 修复已行至中段 → 叠加海外通胀/金融条件与政策不确定性 → 继续追涨的赔率下降 → 降锐度、促均衡；结构上守AI硬件，进攻端配置国产替代+AI应用与困境反转（地产链、消费、光伏链等）`
- **隐含假设：** 本轮上涨由估值而非盈利驱动；海外流动性收紧会通过风险偏好传导至A股；AI硬件是反弹中确定性相对最高的方向。
- **反例 / 证伪条件：** 12月未加息或加息后金融条件反而转松；AI资本开支与订单超预期推动盈利上修；中选后政策不确定性反而下降——任一情形都会使“中段+降锐度”偏保守。

### 观点 3：红利长期靠分红与盈利韧性，年内需等风险溢价回落

- **观点归属：** 华创证券策略（红利部分）
- **结论：** 站在2–3年视角，红利不必过度择时，收益主要来自现金分红与盈利韧性；但站在未来12个月视角，风险溢价尚未充分调整，回落后再配置性价比更高。
- **前提事实：** 中证红利股息率约4.5%，较2023年初明显下降，部分银行股息率仅3%出头；收益拆解：现金分红约45%、盈利约25%、红利再投约21%、无风险利率约18%，剔除无风险利率后的风险溢价与调仓为负贡献；22–23年经验：美联储加息与资金再平衡使红利估值收缩，待加息终点明确、其他行业利润增速下行后，红利相对配置价值才显现；未来一年测算回报2%–4%，乐观9%–11%，悲观-2%至-4%。
- **推导逻辑：** `红利收益=分红(稳定)+盈利(韧性)+再投+无风险利率-风险溢价损耗 → 长周期分红与盈利足以支撑底仓价值 → 但当前风险溢价未充分补偿 → 12个月预期回报偏薄 → 需约10%回调、股息率增厚0.2–0.3pct后才具极优性价比`
- **隐含假设：** 红利成分股以成熟经营、市场地位稳固的企业为主，现金流创造能力强、盈利依托存量业务；分红政策稳定；无风险利率不出现大幅上行。
- **反例 / 证伪条件：** 加息推动无风险利率快速上行、风险溢价被动走扩；银行等权重成分股分红率下调或盈利明显恶化；其他行业利润增速回升使红利相对优势消失。

### 观点 4：政策利率换锚≈一次“准降息”，但年末赎回扰动压制短期节奏

- **观点归属：** 华创证券固收 周冠南
- **结论：** 央行将主要政策利率由7天逆回购（1.4%固定利率）换锚至隔夜逆回购（1.25%固定利率），临时正逆回购同步改为隔夜±25BP，DR001区间由1.15%–1.65%调整为1.0%–1.5%；换锚虽不等同降息、不带动LPR下调，但在银行间市场带来接近10BP的资金中枢下移，中期利好债市；短期受年末止盈、赎回与税制预期扰动，宜逢高布局。
- **前提事实：** 换锚前DR001围绕政策利率偏低约5BP、在1.35%–1.4%运行；换锚后围绕1.25%波动、约在1.25%–1.3%；隔夜作为引导利率下行会带动存单、同业存款等短端下移并向长端传导，改善银行同业负债成本；10月已较充分交易换锚与央行买债的增量利好，10年国债从1.72%→1.68%→1.62%阶台阶式下行；近期出现三方面扰动：央行提示利率难进一步下行、权益风险偏好较三季度略有企稳、华发事件后珠海方面未给出明确官方方案导致部分低等级信用调整；上周市场关注央行调研政府债利息收入免税政策调整对银行配置行为的影响，叠加年末止盈，周四周五赎回演绎较明显。
- **推导逻辑：** `政策利率换锚 → 隔夜利率成为锚、中枢下移近10BP → 短端（存单/同业存款）跟随下移 → 银行同业负债成本改善、向长端传导 → 债市定价中枢小幅下移（10年从1.6%附近仍有约10BP空间） → 但年末止盈+赎回+税制预期先行交易 → 节奏上先调整、后配置`
- **隐含假设：** 换锚不改变货币政策取向、LPR与存贷款报价利率基本稳定；流动性传导顺畅、央行数量投放配合；税制调整短期落地概率低。
- **反例 / 证伪条件：** DR001持续高于1.35%、资金面反而收紧；赎回负反馈从信用品扩散至利率品并形成自我强化；政府债免税政策超预期落地并显著改变银行配置行为。

### 观点 5：美股成长风格三次走弱源于估值下杀而非盈利，年底可能再走强

- **观点归属：** 华创证券海外研究（美股AI部分）
- **结论：** 过去12个月AI科技股跑赢力度减弱、成长风格三次修正，但三次都是“相对盈利差在扩大、股价却在跑输”的背离，本质是估值压缩；当前AI科技股远期估值已显著低于今年3月低点，在利率曲线未倒挂的前提下，盈利下修压力小于估值下行压力，年底成长风格很可能再度走强。
- **前提事实：** 三次走弱分别对应：2025年10月–2026年2月（甲骨文等云厂商大幅增加资本开支）、2026年6–7月（存储半导体盈利增速升至不可持续水平）、2026年10月至今（AI产业与相关公司营收前景出现系统性消极预期）；背离证据：标普500/等权标普500由0.89降至0.83而EPS同比差由4.1%升至6.2%，纳指100/罗素2000由10.1降至9.4而EPS差由5.8%升至6.2%；第二轮纳指100/罗素2000由10.5降至9.5而EPS差由23.8%升至44%；第三轮标普500/等权由0.9降至0.85、EPS差维持14.7%，纳指100/罗素2000由10.9降至10、EPS差由42.6%升至43.1%；截至11月13日，标普500远期PE 19.5倍、纳指100 20.8倍，均低于3月低点，信息技术19.3倍反而低于必选消费25.3倍、医疗保健20.4倍。
- **推导逻辑：** `AI叙事受多重打击（营收不及预期、AI债券抛售、中选后资本开支分歧、管理层变动） → 成长股估值压缩而盈利差仍在扩大 → 估值已便宜、传统行业反而更贵 → 利率曲线未倒挂下盈利下修压力<估值下行压力 → 年底成长风格再度走强、AI股可能重新跑赢`
- **隐含假设：** AI盈利预期不再系统性下修；美债利率不出现失控上行；资本开支叙事不再被证伪。
- **反例 / 证伪条件：** AI资本开支或营收指引再被大幅下修（第四轮背离转为盈利下修）；长端美债利率快速上行压制远期估值；AI相关信用风险（债券抛售）扩散为融资链断裂。

### 观点 6：A股“先抑后扬”、港股谨慎偏空，短期多空交织

- **观点归属：** 华创证券金工 王小川
- **结论：** A股短期模型多空交织，中长期多数指数仍看多，判断未来先抑后扬（甚至可能跌得很少、周一开盘不跌）；港股各模型一致偏空，维持谨慎。下周推荐行业：综合、电力公用事业、纺织服装、家电（轮动模型）、钢铁（基本面改善）。
- **前提事实：** 本周上证跌0.4%、创业板指跌1.59%，行业涨少跌多，通信、银行、电子、煤炭、家电涨幅居前，电新、有色、化工、石油石化跌幅居前；主力资金净流入通信、电子、轻工制造、家电、煤炭，净流出电新、化工、有色、计算机、医药；偏债混合型基金平均-0.5%，股票型ETF平均-0.98%；新发基金57只、合计157亿元（混合26只25亿、股票18只38亿、债券13只93亿）；VIX略降至14.36；短期模型：深100看多、成交量模型看空、智能300看空、智能50看多；中期：涨跌停模型看多，上行收益差模型对上证与中证500看多，月效模型中性；长期：动态估值模型对上证、沪深300、上证50看多；港股成交量/成交额、上下行收益差、相似多空模型均看空；仓位：股票型-13BP、混合型+66BP，加仓通信（及电力，转写不清）、减仓电子与汽车。
- **推导逻辑：** `短期模型多空交织 + 中长期指数普遍看多 → A股先抑后扬；港股各模型一致看空 → 谨慎偏空；仓位变动信息量有限 → 结构上跟随资金流入方向（通信、家电、煤炭、银行）`
- **隐含假设：** 模型信号在年末流动性环境下仍有效；行业轮动模型对下周一月内有效。
- **反例 / 证伪条件：** 出现放量突破使成交量模型翻多、或港股模型同步转多；年末资金面/政策事件导致“先抑”幅度远超预期并破坏中长期趋势。

### 观点 7：三项流动性工具加速投放，红利为压舱石、非银博反弹

- **观点归属：** 华创证券金融 徐刚
- **结论：** 11月初以来一行一会一局推动存量工具加大使用，互换便利、中证A500相关ETF、回购增持再贷款三线放量，对市场流动性与权重板块形成增量支撑；但工具生效需要时间，年末绝对收益资金止盈与海外风险释放削弱反弹持续性，当前位置偏左侧，红利（尤其银行）是战略底仓，非银可用于博反弹。
- **前提事实：** 互换便利本轮券商与基金申报超千亿，头部券商单家超100亿、中小券商30–50亿，首批存续约1050亿加新增约1000亿，未来体量有望达约2000亿；中证A500相关ETF（转写为“主的EDF”）18家基金公司合计募集超350亿，风格延续均衡、红利蓝筹与部分量化策略，建仓明显加快；回购增持再贷款方面，截至10月底约900家上市公司披露约1100单，含国新、诚通两家国有资本运营公司新增申请，工具利率由创设时约1.75%降至约1%，累计下调约75BP，并已从阶段性安排转为长期制度性安排；证券行业自营对方向性投资有明确要求，增量资金一部分投科创、一部分留在红利。
- **推导逻辑：** `监管引导+利率成本下行 → 三类工具申报与投放放量 → 增量资金进入科创ETF与红利资产 → 改善流动性与权重股支撑 → 但机制生效需时间、年末止盈与海外风险共振 → 市场偏左侧、底部区域逐步显现 → 红利为压舱石，非银博反弹`
- **隐含假设：** 机构按监管导向加快实际投放；负债端成本继续下行、险资对红利资产的准入标准（股息率、ROE、商业模式稳定性）趋于优化；工具资金不会因市场下跌而被风控收回。
- **反例 / 证伪条件：** 申报到实际投放的转化率显著低于预期；市场调整导致券商自营收缩方向性敞口；险资红利准入标准未放松、银行股息率继续下移使配置吸引力下降。

### 观点 8：新房供给减少不足以让明年房价止跌，价格锚在二手房与总需求

- **观点归属：** 华创证券房地产/多元资产 尚哥
- **结论：** 对新房供给减少能否带来明年房价止跌，答案偏否定。新房只能决定边际溢价，决定不了价格锚；决定价格锚的是二手房与总需求（后周期理论），需看到总需求曲线右移，房价才能止跌回稳。
- **前提事实：** 新增供地量较高点下降约75%，但新出让地块对应的新房是以更有性价比的方式卖掉的；核心城市核心区新房库存是增加而非减少；今年开发商推盘密集度明显低于去年，说明相对需求而言新增地块并不稀缺；多数城市新房去化周期并未明显下降；新房定价逻辑为“二手房价格锚+新房边际溢价”，同价格段新房与二手房本质是居民偏好的选择，周边新房竞争多则溢价极低甚至对二手房砸盘。
- **推导逻辑：** `新增住宅需求主要来自城市扩张 → 城市不再扩张、常住人口不增则无刚性新增需求 → 供地减少不等于供给相对需求不足（库存与推盘数据佐证） → 新房只定边际溢价、定不了价格锚 → 供给收缩无法推动房价止跌回稳；价格锚取决于二手房与总需求右移`
- **隐含假设：** 城市扩张阶段已结束、常住人口不增；二手房价格是新房定价锚；居民加杠杆能力与意愿不出现大幅反转。
- **反例 / 证伪条件：** 核心城市人口重新净流入带动刚性需求；二手房价企稳回升、成交量持续放大；供地进一步收缩至库存显著去化、去化周期明显下降。
