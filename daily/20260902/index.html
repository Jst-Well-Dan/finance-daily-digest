3. 专家观点与逻辑链

观点 1：融资成本上行预期下，选股因子从"成长/Capex/订单"转向"自由现金流与盈利确定性"

  • 观点归属： Laura（摩根士丹利股票策略）
  • 结论： 美股持续看好 AI 应用层、金融、可选消费；映射中国，聚焦盈利确定性强的上市公司，K 型经济下不依赖个股对抗宏观。
  • 前提事实： 融资成本有提高可能；市场波动性加大；K 型经济下板块盈利表现严重分化（中国 IT/生物医药超预期比例高、消费最弱）。
  • 推导逻辑： 融资成本上升 → 高 Capex/重订单的成长因子风险上升 → 资金转向"谁手握现金、谁能穿越波动" → 自由现金流与盈利可预见性成为美股主要定价因子 → 中国市场映射为聚焦盈利确定性板块（与中长期战略方向重合的板块盈利增速亦更优）。
  • 隐含假设： ① 利率环境确立"更高更久"或收紧；② 中国市场（A 股与美联储敏感的港股）与美股定价因子联动性持续；③ "盈利确定性"板块与"中长期战略方向"板块（硬科技）高度重合的判断成立。
  • 反例 / 证伪条件： 若融资成本预期逆转（降息），成长/Capex 因子重新占优，该选股框架失效；若消费在政策强刺激下盈利确定性反超，回避消费的结论证伪；若 A 股与美股联动脱钩，映射逻辑失效。
  • 原文位置： 转写第一节（"现在我们看到的美股资金流向聚焦最为明显的方向呢是这种自由现金流……映射回我们中国的股票市场"）。

观点 2：二季度盈利边际改善只是"降速递减"，真拐点未现

  • 观点归属： Laura（基于上周发布的中报全盘梳理报告）
  • 结论： 二季度环比一季度，A 股与 MSCI 中国盈利超预期净值明显改善、二阶导现拐点苗头，但仅是下降速度放缓，尚未形成真正拐点。
  • 前提事实： 已披露公司约 50% 市值覆盖；MSCI 中国超预期净值 +4%（一季度 -6%）；A 股从约 -13pct 收窄至不及 -6pct。
  • 推导逻辑： 业绩超预期净值由负转正 → 盈利下修动能衰竭 → 但宏观（通缩、消费需求不振）拖累仍在 → 只能定性为"降速趋缓"，距离"历史上一次意义上的拐点"仍需数个季度确认。
  • 隐含假设： 盈利拐点的判定以"超预期净值占比"为核心先行指标；样本（已披露约半数市值）对未来全貌无显著偏误。
  • 反例 / 证伪条件： 若三季度超预期净值重新转负或环比恶化，则"改善"被证伪；若某季度单季盈利同比转正且扩散面扩大，则可升级为"真正拐点"。
  • 原文位置： 转写第一节（"很多投资人问说宏观不行，我们的盈利什么时候给拐点……他只是一个下降的速度减缓"）。

观点 3：人形机器人已越过"纯 demo"，进入广度大于深度的早期商业化，数据—部署有望形成正循环

  • 观点归属： 钟晨/中盛（摩根士丹利行业首席，基于世界机器人大会与运动会现场调研）
  • 结论： 行业并非停留在叙事：出现小规模真实部署（单客户几十台级）、上下料等场景出现复购、效率同比翻倍（人类 60–80%）；判断 2026 全年出货超 5 万台、2030 年近 50 万台/年；核心瓶颈在智能与操作能力（模型 + 数据），尤其是真机数据。
  • 前提事实： 赛事规模为历年最大（666 队/2056 台、参展商 +30%）；展示重心从运动性能转向多步骤"长程任务"与灵巧操作；模型路线从强化/VLA 演进至世界模型；发改委 8 月 28 日发布会表态支持真实场景落地并提示防止一哄而上。
  • 推导逻辑： 运动能力大幅突破 + 展示向应用倾斜 → 客户从验证走向部署 → 部署量提升产生真实数据 → 数据反哺模型与操作能力 → 效率/泛化性提升 → 更多部署（正循环）；政策层面"真实场景迭代 + 应用闭环"的表述与该路径同向。
  • 隐含假设： ① 出货/部署曲线为乐观线性外推（上半年 1.9 万台 → 全年 5 万台 → 2030 年 50 万台）；② 数据瓶颈可通过部署规模化自然缓解；③ 政策支持不演变为盲目补贴与产能过剩（发改委自己已提示该风险）。
  • 反例 / 证伪条件： 出货量与国内"上半年超 4 万台"口径冲突，若 5 万台/年的预测过高则整条曲线证伪；若复购率长期不上升、效率停留在 60–80% 无法泛化，则"商业化广度>深度"难以深化；若终端需求未形成闭环、仅靠补贴拉动，正循环不成立。
  • 原文位置： 转写第二节（"整个行业呢现在不完全是在一个 demo 的阶段……商业化的广度大于深度""部署数量的提升能够产生更多的真实数据……正循环"）。

观点 4：现房销售新政的本质是改变资本周转模式，IRR 冲击远大于利润率冲击

  • 观点归属： Steven（摩根士丹利房地产首席，基于"周五快评 + 次日定量报告"）
  • 结论： 新政后开发商"卖得少、周转慢、IRR 更低、集中度更高"；对开发商整体保持谨慎，更偏好受益二手房交易的贝壳及经常性收入强劲的华润置地、新城控股。
  • 前提事实： 政策（2026-08-28 三部门通知）收紧预售条件（封顶销售、资金全额监管至竣工交付）、鼓励现房销售；开发商回款时点从"开工约一年"推迟至"建成后 2–3 年"。
  • 推导逻辑： 预售→现售 → 销售现金回笼大幅延后 → 同一笔资金的占用时间拉长 → 资产周转率与 IRR 显著下降（10 万方项目模型 IRR 降近 18pct，远超净利率 -2pct）→ 销售额未来三年 -11%/-17%/-35%（压力在 2027 年后集中释放）→ 资金实力决定拿地能力 → 行业寡头化；缓冲项（需求刺激、地价/分期付款、成本控制、加杠杆）只能部分对冲。
  • 隐含假设： ① 政策按"严格执行"情景落地且地方政府跟进节奏近似同步；② 需求端刺激力度不足以逆转周转放缓；③ 开发商不倾向大幅加杠杆；④ 房价上涨中单位数仍无法挽回 IRR（因土地增值税侵蚀）。
  • 反例 / 证伪条件： 若政策仅为试点、执行宽松（地方政府差异化），销售降幅显著低于 35%；若出现大幅降息/去库存强刺激使需求快速恢复，短期销售与周转改善；若头部开发商加杠杆能力超预期，"供给能力不足"的长期约束弱化。
  • 原文位置： 转写第三节（"这一次的政策的意义不仅仅是把卖房的时间往后推，而是可能从根本上改变房地产开发的商业模式""IRR 下降的幅度会接近 18 个百分点""未来开发商可能卖的更少、周转更慢、IRR 更低"）。
