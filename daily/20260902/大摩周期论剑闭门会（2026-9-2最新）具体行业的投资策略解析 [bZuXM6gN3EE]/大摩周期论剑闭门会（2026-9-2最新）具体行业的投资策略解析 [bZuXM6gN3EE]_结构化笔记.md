# 结构化笔记｜大摩周期论剑闭门会（2026-9-2最新）具体行业的投资策略解析

## 1. 核心结论
1. **银行业进入“可持续增长+防风险”主线，降杠杆背景下盈利反而加速**：二季度总资产增速从9%多回落至7%多、贷款增速放缓，但净息差略有反弹、净利息收入回双位数增长，手续费因资本市场活跃维持高增；结论适用条件为政策持续纠偏过去过度宽松（取消信用卡/地产白名单/普惠展期等）且未再大幅放水。
2. **“以量补价”阶段结束，银行对规模扩张的执着明显退潮**：管理层讨论显示对“量”的执着取舍，扩张更理性；该判断仅在当前监管定调不变、且息差企稳前提下成立，若再出现稳增长加码则可能逆转。
3. **大行PPOP与净利润增速改善，拨备计提仍积极**：成本收入控制较好，PPOP双位数增长，国有大行净利润增速从一季度1.2%加快至5-6%，同时仍积极提拨备；结论依赖中报数据的持续性，需跟踪资产质量是否同步稳定。
4. **行业策略机会在于“量稳价稳+财富管理”而非总量扩张**：总收入保持不错增长的结构来自息差企稳+交易/理财/基金/保险销售高增，反映资本市场活跃度的传导；若债市与基建投资持续放缓、市场回落，则手续费与交易收入的高增不可持续。

## 2. 专家观点与逻辑链
### 观点 1：可持续增长与防风险为主线的监管定调未变，即便二季度对经济略有放款
- **观点归属：** 摩根士丹利中国金融首席
- **结论：** 中性偏谨慎看银行规模扩张，看多质量与息差企稳带来的盈利韧性。
- **前提事实：** 政策层面持续调整/取消过去过度宽松安排（待核验）；二季度增速回落（待核验）
- **推导逻辑：** `过去过度放松的展期与支持政策被取消 → 总资产/贷款增速放缓至7%多理性区间 → 量减但价（息差）略反弹 → 净利息收入双位数增长 → 盈利可持续性优于单纯冲量`
- **隐含假设：** 监管不因短期经济压力而重回大幅宽松；息差反弹可持续而非一次性因素；银行主动放弃规模竞赛。
- **反例 / 证伪条件：** 若三季度再度推出大规模信贷支持或LPR大幅下调导致息差二次探底，则“量稳价稳”逻辑被打破。
- **原文位置：** 开头“可持续增长还有防风险…更明显的趋势…即使二季度对经济略有放款…没有太大变化”至“总资产增速从9%多降到7%多”

### 观点 2：盈利改善由“价稳+非息高增+成本控制”驱动，而非总量
- **观点归属：** 摩根士丹利中国金融首席
- **结论：** 看好大行盈利修复持续性，但需区分一次性高基数与资本市场贝塔。
- **前提事实：** 净息差反弹、交易/理财/基金/保险销售活跃、成本收入控制不错（待核验）
- **推导逻辑：** `资产增速放缓但息差企稳 → 净利息收入反弹 + 资本市场活跃带动中收与交易收入正增长 → 成本收入比控制 → PPOP双位数 → 拨备后净利润5-6%`
- **隐含假设：** 资本市场活跃度维持；去年同期一次性理财收入的高基数影响边际减弱；信用成本不大幅上升。
- **反例 / 证伪条件：** 若二季度后股债市场回调或发债/基建持续放缓，则手续费与交易收入高增将回落；若不良生成加速致拨备计提超预期，则净利润增速回落。
- **原文位置：** 中段“净利息收入继续反弹…手续费…去年一次性理财收入…发债以及基建投资放缓…理财基金保险销售维持高增…PPOP双位数…净利润1.2%到5-6%”

### 观点 3：行业配置上应淡化“以量取胜”，关注息差与财富管理链
- **观点归属：** 摩根士丹利组织者与金融首席（推断）
- **结论：** 对银行业“看结构而非总量”，隐含方向为优选息差韧性强、财富管理与交易能力突出的大行。
- **前提事实：** 量增速放缓已成事实，价格与中收成为主驱动（待核验）
- **推导逻辑：** `总量扩张受限 → 竞争转向定价与中收 → 具备负债成本优势与财富管理客群的机构受益 → 盈利分化`
- **隐含假设：** 财富管理需求与资本市场正相关且可持续；负债端成本管控能力分化是关键。
- **反例 / 证伪条件：** 若市场转向“宽信用”总量竞赛，则以往以量取胜的中小行可能阶段性反弹，逻辑逆转。
- **原文位置：** 全篇银行业讨论隐含，配合开场“覆盖金融保险交运、工业和房地产等行业更新”但实录仅银行业，推断为闭门会节选
