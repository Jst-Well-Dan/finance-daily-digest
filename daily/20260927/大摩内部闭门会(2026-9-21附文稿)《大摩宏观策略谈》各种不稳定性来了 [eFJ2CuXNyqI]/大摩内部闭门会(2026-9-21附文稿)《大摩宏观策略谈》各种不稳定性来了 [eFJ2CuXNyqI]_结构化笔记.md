# 结构化笔记｜大摩内部闭门会(2026-9-21附文稿)《大摩宏观策略谈》各种不稳定性来了

## 1. 核心结论

- **美联储进入温和加息周期，但终点低于市场预期**：适用条件为核心PCE环比持续在0.25%附近、通胀预期不回落；若未来2—3个月核心PCE回落到0.2%以下，加息周期可能提前结束，反之仍有上调风险。
- **中国家庭去杠杆进入信心驱动的第二阶段，消费修复慢于资产负债表修复**：债务收入比、偿债率、负债资产比三指标均改善，但因靠主动压负债、压消费实现，社零趋近零增长；仅当房价、就业与收入预期持续回升后，消费与加杠杆意愿才会改善。
- **中国市场目标价下调后空间有限，港股短期承压大于A股**：截至2027年年中仅有个位数上行空间；适用条件是美联储加息预期叠加资本流动管理趋严未缓解，盈利改善（MSCI中国仅增约6%）不足以大幅推高指数。
- **亚洲（除中国外）私人部门能承受利率与油价温和上升**：适用条件为油价维持100—110美元/桶、美联储仅再加息1—2次；若油价升至120美元以上并维持半年，或央行被迫在增长放缓时加息，组合将明显恶化。
- **中美9月底会晤大概率维持休战而非破局，关键看11月10日三项到期条款是否延期**：适用逻辑为“芯片换稀土”相互制约；若301关税排除清单、BIS关联规则暂停、中国稀土管制暂停三者得以延长，则现有平稳交易状态延续。

## 2. 专家观点与逻辑链

### 观点 1：美联储转向迷你加息周期

- **观点归属：** 蔡志鹏（转述摩根士丹利美国经济团队）。
- **结论：** 9月加息并非孤立预防式加息，而是温和加息周期起点；基准为12月再加25基点、2027年3月再加25基点，终点利率仍低于市场预期。
- **前提事实：** 9月已加息25基点至3.75%—4%；7月核心PCE环比0.25%、8月预计亦0.25%，高于此前假设的0.17%；机票、交通等服务价格韧性强；美债长端一度突破5%（待核验：以官方利率与收益率数据为准）。
- **推导逻辑：** 通胀回落慢于预期（0.17%→0.25%，年化2%→近3%）→ 美联储7月未兑现紧缩预期导致曲线变陡、公信力受质疑 → 市场对9月加息充分定价下按兵不动代价更高 → 转为连续温和加息。
- **隐含假设：** 能源向核心的二阶传导持续；AI资本开支短期挤出效应偏通胀；美联储反应函数更看重公信力与长端风险溢价。
- **反例 / 证伪条件：** 若核心PCE连续2—3个月回落到0.2%以下，则加息周期提前结束；若AI生产率效应快速显现压低通胀，同样证伪。

### 观点 2：中国家庭“分子驱动”去杠杆压制当期消费

- **观点归属：** 蔡志鹏。
- **结论：** 对增长与政策持谨慎态度，政策姿态“拖而不举”；实际GDP或靠“六张网”铺开在四季度企稳，但名义增长压力更大，2027年GDP平减指数或仅0.2%且有下行风险。
- **前提事实：** 2021—2023年为地产驱动去杠杆，2023年中后转为信心不足驱动；债务占可支配收入比从约110%降至100%以下，偿债率从12.4%降至不足11%，负债资产比2025年中开始改善，但社零趋近零增长（比例与时点为视频陈述，待核验）。
- **推导逻辑：** 房价与就业收入预期走弱 → 居民理想负债水平低于存量 → 主动偿债、增储蓄、压消费 → 微观杠杆改善但宏观总需求走弱 → 企业收入与居民收入预期再走弱 → 负反馈循环。
- **隐含假设：** 中央政府扩大赤字态度谨慎，经常账户顺差（占GDP从0.6%升至3.8%）难以无限扩张对冲；出口集中于高科技与资本密集行业，对就业传导弱。
- **反例 / 证伪条件：** 若房贷贴息、生育养育补贴、社保夯实等外力大规模落地且社零持续回升，或经常账户与财政同时发力稳住名义增长，则“通缩循环”判断被证伪。

### 观点 3：中国市场下调目标价、增配金融，港股受流动性挤压更大

- **观点归属：** Laura（摩根士丹利策略）。
- **结论：** 9月3日全面下调中国市场目标价（恒生、国企、MSCI中国、沪深300，至2027年6月），战术上8月中旬已降港股回A股，当前增配金融；对美股维持偏积极，不必大幅降仓。
- **前提事实：** 新基准目标价恒生22550点、恒生国企8900点、MSCI中国80点、沪深300 4880点（视频口播数字，待核验）；3月红筹解绑、5月居民境外投资账户严控、6月境外金融资产红利征税、7月海外信托穿透征税、9月个人境外分红征税陆续落地；共识对MSCI中国2026年盈利增12%—13%，摩根士丹利仅预期6%。
- **推导逻辑：** 美联储加息预期升温 → 港币盯住美元＋港股无资本管制 → 全球收紧时港股成“提款机” → 叠加资本流动管理趋严致外资配置放缓 → 估值支撑有限 → 指数上行依赖盈利但盈利预期偏高 → 下调目标、转向金融等防御。
- **隐含假设：** 美联储加息已较充分定价于美股估值；美国名义GDP（5年均近7%）支撑美股盈利；加息前后quality、动量、周期跑赢的历史规律重演。
- **反例 / 证伪条件：** 若盈利大幅超预期（接近共识12%以上）或资本流入重回加速，或美联储加息不及预期导致港股流动性迅速恢复，则下调过度的判断被证伪。

### 观点 4：日本央行12月与明年3月各加一次，终端利率1.75%

- **观点归属：** Jonathan（转述摩根士丹利日本团队）＋亚洲宏观判断。
- **结论：** 亚洲复苏未被打断；多数亚洲央行无需与美联储同步加息；例外是日本央行12月再加息、明年3月再加一次至1.75%，市场定价的2%—2.25%以上偏高。
- **前提事实：** 亚洲（中国以外）私人部门债务占GDP明显低于疫情前；美国中性利率过去一年升50基点至1.3%，当前政策利率非限制性；美元对日元模型公允值约170附近（模型结果，待核验）；日本核心通胀温和。
- **推导逻辑：** 私人杠杆低＋增长基础强 → 利率与油价温和上升仅构成阻力 → 多数央行宏观稳定指标无警报 → 无需跟随加息保汇率；日本因日元贬值传导通胀权重上升 → 需加息但过快或致2027年核心通胀低于预测。
- **隐含假设：** 美联储仅再加1—2次且美元不大幅升值；前期加息对日本内需的滞后影响可观察；汇率框架（美终端利率定价、贸易条件、风险情绪）稳定。
- **反例 / 证伪条件：** 若美元大幅走强或日本核心通胀显著上行，则终端利率高于1.75%；若美国加息超预期且亚洲经常账户恶化，则“无需同步加息”被证伪。

### 观点 5：油价100—110美元可控，120美元是危险线

- **观点归属：** Jonathan。
- **结论：** 基准四季度油价约100美元/桶；100—110美元区间对亚洲影响可控但分化，印度、菲律宾、日本承压更大。
- **前提事实：** 以亚洲货币计油价自2月底涨约50%，但本地汽油均价仅涨约10%；能源支出占GDP约4.7%，接近历史均值；韩台自6月起与美国签长期天然气合同分散采购（价格与合同细节待核验）。
- **推导逻辑：** 国际油价上涨 → 补贴限价＋分散采购缓冲 → 传导至居民有限 → 能源负担未达极端 → 经济可承受；若升至120美元并维持半年 → 财政缓冲耗尽、购买力受损、央行被迫加息 → 滞胀式组合。
- **隐含假设：** 中东供应减量不进一步恶化；二季度美出口增、中国进口减的缓冲减弱但不再逆转；各国补贴可持续。
- **反例 / 证伪条件：** 若补贴退坡导致传导加快，或供应中断超预期，即使100美元也可能超调；若油价快速回落，则分化担忧解除。
