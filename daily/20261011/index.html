结构化笔记｜【观点交锋！新维度】张维迎、黄益平等经济学家共论AI经济和中国消费低迷困境

1. 核心结论

  • 结论1：中国消费低迷根在供强需弱与分配结构，非短期周期波动。 适用条件/边界：总量与宏观视角成立；人均可支配收入占人均GDP比重低、储蓄率高、地方重投资轻消费格局未改之前，单纯刺激政策难以扭转。

  • 结论3：AI对消费总体是促进而非替代，C端变革仍需3-5年。 适用条件/边界：AI能提供十倍级效率提升并改变决策习惯时成立；若仅为两倍效率优化或B端降本工具，则不构成零售业态升级。
  • 结论4：品牌本质是降低信息不对称的信任信号，长期主义与基本功是AI时代稀缺品。 适用条件/边界：适用于信息不对称高、品质难辨的品类，以及有复购和溢价需求的品牌生意；完全同质、低价透明的标品主要靠价格竞争，品牌溢价有限。

2. 专家观点与逻辑链

观点 1：供强需弱与分配失衡导致消费冷

  • 观点归属： 黄益平
  • 结论： 消费短板是分配和信心问题，需收入层面的结构性改变
  • 前提事实： 储蓄率特别高，家庭与公共部门储蓄均高；地方政府行为偏好重投资轻消费；1-8月社零增速低迷与政策扩消费目标反差大
  • 推导逻辑： 高GDP未转化为居民购买力 → 内需相对弱 → 创新与促消费努力难以弥补收入信心缺口
  • 隐含假设： 储蓄高主因是分配与保障不足而非文化偏好；收入提升会自动转化为消费
  • 反例 / 证伪条件： 若居民收入占比回升后消费率仍不回升，或高储蓄转向高消费而无收入变化，则逻辑不成立

观点 2：AI向好，企业家须从套利转向创新

  • 观点归属： 张维迎
  • 结论： AI会让世界更好，消灭部分工作但创造更多工作；产能过剩是企业家未尽创新责任
  • 前提事实： 网购、快递等新技术扩大了购买行为；过去套利型机会（中美产品落差）收窄；企业家创新需5-7年潜伏期
  • 推导逻辑： 技术降低交易与选择成本 → 激发潜在需求 → AI促进消费而非替代最终服务
  • 隐含假设： 人类需求无限且企业家活力可被激发；马尔萨斯式资源悲观论不成立
  • 反例 / 证伪条件： 若AI长期只替代就业而无新职业品类出现，或创新长期无商业回报，则判断失效

观点 3：坏的是总量，强的是新供给

  • 观点归属： 启程资本常斌（一线投资视角）
  • 结论： 对中国消费充满信心，新一代消费公司正在接替老品牌
  • 前提事实： 零食很忙系26000店、上半年增长60%；实木家具品牌从十几亿做到约150亿并开1600店；A股老消费下跌，港股新消费批量上市；65后靠分销渠道、80后靠电商，95/00后开始入场
  • 推导逻辑： 基础设施切换 → 一代人有一代人品牌 → 性价比+情绪价值创新爆发
  • 隐含假设： 所举高增长案例具代表性而非幸存者偏差；日本式迭代（大荣倒下、711/优衣库崛起）可类比中国
  • 反例 / 证伪条件： 若折扣业态的增长来自短期价格战且盈利不可持续，或新生品牌复购率大幅下滑，则结论不成立

观点 4：单一大市场决定消费确定性，AI须十倍效率

  • 观点归属： 淘天集团基云
  • 结论： 中国与美国是未来10-50年最确定的消费市场；AI在C端零售的机会在于业态重构
  • 前提事实： 东南亚6亿人口但无单一大市场，消费规模层次不可比；历次技术革新：集装箱→跨国贸易，POS/主机→大卖场，PC互联网→电商，移动互联→个性匹配；AI在B端已是确定性提效工具
  • 推导逻辑： 单一大市场让小众需求成巨大空间 → 中国企业家创新+吃苦 → 只要AI解决十倍效率痛点即爆发
  • 隐含假设： 市场统一性持续；两国消费能力不发生断崖式下滑；C端购物心智可被AI改变
  • 反例 / 证伪条件： 若3-5年后AI仍未改变下单、连带购买、退货率三大痛点，或市场分割加剧，则判断失效

观点 5：品牌是信任信号，广告只是手段之一

  • 观点归属： 黄益平、张维迎、基云共识整理
  • 结论： 品牌提供价格之外的品质信号，降低搜寻与交易成本；投资品牌是加强沟通而非单纯投广告
  • 前提事实： 平台品牌信息清晰则匹配成本低；收入高者更重视品牌以省时间；第三方品牌指数类似金融评级，可使决策分化；搜品牌词是人找货，搜品类词易陷入比价
  • 推导逻辑： 信息不对称越高 → 品牌附加值越高 → 品质信息透明推动良性循环，反之言过其实加速抛弃
  • 隐含假设： 消费者愿意为确定性支付溢价；第三方指数保持独立无商业利益；AI改变触达方式但不改变信任本质
  • 反例 / 证伪条件： 若加大品牌投入后营销成本不降反升、复购不升，或低收入群体长期只选最低价，则品牌溢价逻辑在该品类不成立

  • 推导逻辑： 央行缩表/QT退出 → 持有结构转向市场化机构 → 同样基本面要求更高期限补偿 → 利率中枢上行
  • 隐含假设： 央行不再大规模回归购债；市场化机构风险偏好与久期承受力不变。
  • 反例 / 证伪条件： 若央行重启大规模QE且利率不下，或利率上行伴随认购倍数大幅坍塌，则重定价解释失效。

观点 2：美债纪律丧失是长期慢变量而非短期交易主因

  • 观点归属： 张瑜
  • 结论： 美债余额/GDP创新高同时，美股次市值/GDP亦创新高；美债余额/美股市值处十年偏低分位，美债余额/全球股债总市值十年稳定，认购倍数稳定，故短期更多是叙事。
  • 前提事实： 美债认购倍数过去2-3年基本稳定；上述两个比值未系统性恶化。
  • 推导逻辑： 债务余额上升 ↔ 金融市场同步膨胀 → 相对比例稳定+认购稳定 → 短期无偿付危机式抛售
  • 隐含假设： 安全资产需求随金融市场规模同比例扩张；认购倍数能代表真实需求而非一级交易商被动接盘。
  • 反例 / 证伪条件： 若认购倍数持续下滑、美债余额/全球市值比值跳升2个百分点以上，则长期变量转化为短期定价主因。

观点 3：短缺经济与充裕经济分化解释中外利差

  • 观点归属： 张瑜
  • 结论： 海外中间品资本品短缺推高海外通胀与利率，中国因庞大供给隔离通胀、利率偏低。
  • 前提事实： 过去2-3年全球中间品资本品出口份额占比快速上升；关税战、有色暴涨、地缘冲突致供给收缩；科技硬件制造品价格上涨快。
  • 推导逻辑： 供应链备份+军备+AI基建+能源转型+城镇化共振 → 中间品资本品需求爆发+供给收缩 → 海外短缺涨价 vs 中国充裕低利率
  • 隐含假设： 中国供给能力持续过剩且能对外输出；海外需求分散不可快速回流中国以外供给修复。
  • 反例 / 证伪条件： 若中国PPI与利率同步上行，或海外资本品价格回落而利率仍创新高，则该解释失效。

观点 4：财政发力确认与观察方法

  • 观点归属： 张瑜、银波
  • 结论： 9-12月新增政府债5.2万亿，其中一般债3.5万亿远超2025年同期落地工作量2.8万亿，增量约7000亿-1.35万亿，明确发力；效果取决于资金用途与项目改善。
  • 前提事实： 2025年9-12月新增3.4万亿，11-12月专项债0.6万亿，落当年工作量约2.8万亿；2024年同期约3万亿；2026年一般债当年发完用完。
  • 推导逻辑： 一般债3.5万亿 > 去年同期2.8万亿 → 即使专项债跨年仍有7000亿+增量 → 发力成立 → 能否转投资取决于项目落地
  • 隐含假设： 一般债发行即使用、无大量结转；去年10月政策加码后投资未起是因项目未改善的经验仍适用。
  • 反例 / 证伪条件： 若PMI建筑业订单好转但项目数据与固投仍不回升，或资金用于发工资三保而非形成消费投资循环，则发力不等于见效。

观点 5：货币政策核心是找最后借款人

  • 观点归属： 罗宇（华创宏观文文宇）
  • 结论： 问题不在央行不放水，而在实体无借款意愿；四季度政府应扮演最后借款人，央行需在量上配合，否则发债抽准备金会推高利率。
  • 前提事实： 二级银行体系：央行借给银行的是准备金，银行借给实体的是存款；商业银行买政府债消耗准备金转成政府存款；当前框架下企业居民借钱意愿弱。
  • 推导逻辑： 政府加杠杆借钱 → 需央行供给准备金对冲 → 资金流入实体留企业则促生产、流向非银则促交易、沉淀居民则循环不畅
  • 隐含假设： 政府支出能创造可借项目；准备金多寡仍是约束银行配置的关键。
  • 反例 / 证伪条件： 若四季度央行未放量而资金利率不升，或政府花钱后企业存款与交易量均无改善，则配合逻辑或传导假设失效。

观点 6：三季度外需撑GDP、外需与汇兑压力并存

  • 观点归属： 银波、夏雪
  • 结论： 三季度GDP预计4.4%-4.5%（二季度4.3%），靠中游生产（7-8月12%+）与出口（9月预计25%-30%）；但汇兑损失占非金融净利润5.7%创新高，同等升值幅度下冲击大于2017、2020年。
  • 前提事实： 全球PMI创3年新高，韩国半导体出口加速；A股非金融境外收入5.7万亿+21.7%占比17.6%；企业外汇套保率约34%，远期结汇比率下降，1年远期锁定亏损约2-3个点。
  • 推导逻辑： 全球总量+AI景气 → 出口中游生产强 → GDP回升 ↔ 海外敞口+套保不足 → 人民币升值3.7%带来更大报表拖累
  • 隐含假设： 9月工业偏强可持续；汇兑损益科目+投资收益+公允价值变动合并仍能反映真实敞口。
  • 反例 / 证伪条件： 若9月工业、出口低于预期，或三季度人民币升值放缓（0.7% vs 二季度1.8%）后汇兑拖累仍扩大，则需重估敞口与套保解释。

1. 核心结论

  • 结论1：AI竞争瓶颈正从算力/模型转向电力与能源基建。 适用条件/边界：仅在数据中心规模持续扩张、GPU电力占比高企的前提下成立；若模型效率出现数量级提升或电力投资大幅落地，瓶颈强度将减弱。
  • 结论2：AI替代不是岗位整体消失，而是任务重构；标准化、可流程化的脑力工作先被替代，具身不确定性高的体力工作更难替代。 适用条件/边界：仅在莫拉维克悖论持续成立、物理世界数据依然稀缺的前提下成立；不适用于已实现感知-决策-执行闭环的特定工业场景。
  • 结论3：具身智能商业化优先在工业脏活累活危险活落地，通用化ChatGPT时刻仍需2-3年或更长。 适用条件/边界：仅在焊接切割、船舶钢结构、高辐射等高危高稀缺工种成立；家庭保姆保洁等开放场景不在此列。
  • 结论4：开源生态削弱技术封锁有效性，中国AI优势在应用场景、数据积累、成本可控的快速产品化与电力系统完整性，而非前沿模型单点领先。 适用条件/边界：仅在开源持续流动、地缘未彻底断链、海外新兴市场需求为够用+低成本的前提下成立。
  • 结论5：人类尊严与价值锚点在于具身脆弱性、责任在场与批判性思维，需坚持关键领域有人复核、可申诉可撤回。 适用条件/边界：仅适用于司法医疗教育养老等高依赖、强问责场景；纯效率型工具场景不强制适用，转写稿中涉及具体产品名、时间点等疑似口误/转写错字已剔除，不作为结论依据。

2. 专家观点与逻辑链

观点 1：AI学习已摆脱人类知识归纳，走向端到端

  • 观点归属： 复旦大学计算与智能创新学院 张君平教授
  • 结论： 未来AI不需要显式人类领域知识也能做好任务，人类需为AI套可理解接口并转向AI解读
  • 前提事实： AlphaGo出现人类未见过棋路，AlphaZero从零学习摆脱人类棋谱思维；Transformer+数据+并行算力推动大模型快速演进
  • 推导逻辑： 数据上量+算力并行+算法适配 → 端到端隐式表达超越显式规则 → 人类按领域知识学习的方式相对失效
  • 隐含假设： 数据覆盖足够完备、任务目标可标准化定义、算力持续可得
  • 反例 / 证伪条件： 若在具身交互、摩擦力风力等不可见物理量建模上长期失败，或世界模型仅停留视觉简化，则该结论不成立

观点 2：替代顺序符合莫拉维克悖论

  • 观点归属： 张君平教授提出，胡豪杰、齐涛在圆桌中呼应
  • 结论： 学历高、白领、与学习强相关的标准化工作先被替代；人类觉得简单的保姆保洁等反而不易替代
  • 前提事实： 编程、课程报告、论文等率先被AI提效；工厂焊接切割等高危场景可用，千家万户非标场景数据稀缺
  • 推导逻辑： 可标准化程序化流程化 → AI可复制 → 人类觉得复杂的工作易被替代；自然进化41亿年的具身能力难模仿 → 人类觉得简单的工作难被替代
  • 隐含假设： 替代成本低于人力成本，物理世界数据获取难度不大幅下降
  • 反例 / 证伪条件： 若通用具身数据大规模采集成功且80%陌生场景通过语言指令完成80%任务，则蓝领难替代判断被证伪

观点 3：人的尊严不在能力优越性，而在具身脆弱性

  • 观点归属： 华东师范大学哲学系 张荣南教授
  • 结论： 无论AI多强，有些事不能完全交机器，需守住责任在场、人类主导、关怀底线
  • 前提事实： 招聘模型性别歧视、自动 perc权误解雇难申诉、经验被提炼为Skill、伴侣机器人迎合讨好、养老教育中真人被取消
  • 推导逻辑： 人有身体会受伤衰老依赖他人 → 产生不被随意伤害、要求回应、可问责的伦理要求 → AI不当使用剥夺主体性/提取经验/取代关系即侵害尊严
  • 隐含假设： 社会承认脆弱性需要人类回应，AI不能承担道德责任
  • 反例 / 证伪条件： 若社会共识接受AI可作为独立责任主体并有可执行问责赔偿机制，则该伦理框架需重构

观点 4：AI瓶颈不在算力而在电力

  • 观点归属： 第一财经总编辑 杨宇东
  • 结论： 能源基础设施将成AI链最具确定性机会，而非芯片设计或模型本身
  • 前提事实： 黄仁勋预计2030年AI基建投资7.9万亿美元，瓶颈是电力；IEA称GPU占数据中心约60%电力；美数据中心电力需求2035年达106GW约新增100座核电站
  • 推导逻辑： 模型参数竞赛持续 → 单机柜功率密度从5-8kW跃升至数十上百kW → 算力必须落在电网发电输电储能电力电子上
  • 隐含假设： 电力供给增速慢于算力需求增速，核电特高压等建设周期长
  • 反例 / 证伪条件： 若推理效率革命性提升使单位智能电耗数量级下降，或电力建设超预期，则瓶颈判断失效

观点 5：AI不偷走工作，但重新定义工作

  • 观点归属： 杨宇东，援引世界经济论坛与硅谷观察案例
  • 结论： 未来核心竞争力是比AI更有判断力创造力、更懂人性与协作，而非更快更准
  • 前提事实： WEF预测2030年9200万岗位被替代同时催生1.7亿新职业；海外银行2万员工案例中单任务30-60分钟压至8-16秒，200岗被替但新增AI训练师流程设计师等3类岗
  • 推导逻辑： AI取消讨厌的重复任务 → 岗位被拆为任务重组 → 新增理解AI思考与人机协作能力要求
  • 隐含假设： 企业愿意增设新岗承接被替代产能，而非单纯裁员兑现利润
  • 反例 / 证伪条件： 若2026年AI裁员潮后新增岗位长期显著少于替代量且无衔接机制，则重定义乐观判断不成立

观点 6：开源正在改写全球AI竞争格局

  • 观点归属： 杨宇东
  • 结论： 技术封锁有效性急剧下降，真正优势在应用场景、数据积累与商业模式
  • 前提事实： 2026年初白宫拟制裁中国开源模型遭硅谷企业反对；美巨头按任务价格路由自动选用包括DeepSeek等中国开源模型
  • 推导逻辑： 开源生态可复制可分发 → 地缘边界被技术流动性突破 → 垄断技术努力徒劳
  • 隐含假设： 开源许可与供应链不被彻底切断，开源模型能力保持够用
  • 反例 / 证伪条件： 若出现代际断层式闭源突破且严格管制算力与权重外流，则封锁重新有效

观点 7：中国最被低估资产是电力系统与最后一公里工程

  • 观点归属： 杨宇东，云之声黄伟、人心机器人胡豪杰提供产业佐证
  • 结论： 通用大模型进入寡头阶段，中国机会在离线场景知识密度、垂直模型盈利、超大市场从1到N再到N+1反向创新
  • 前提事实： 百模大战后分化；智能汽车机器人更看知识密度；云之声靠语音十年积累实现垂直盈利；焊接切割国产突围；云达便利店技术出海30多国靠够用+低成本+落地
  • 推导逻辑： 超大碎片化非标场景+完整电力设备制造+特高压新能源装机 → 模型能力兑现依赖最后一公里FDE对齐 → 混血型隐形冠军胜出
  • 隐含假设： 中国市场场景持续开放给企业试错，电力与产业链配套不出现硬缺口
  • 反例 / 证伪条件： 若垂直场景付费意愿长期不足或出海受本地数据算力合规 блокировка，则落地优势无法变现

观点 8：数字AI狂奔存在失控与高度集权风险，需刹车机制

  • 观点归属： 云之声创始人黄伟提出，杨宇东呼应治理议题
  • 结论： 1年内数字领域AI能力远超人，少数国家少数公司少数人掌握，临界点前需建立可踩刹车制度
  • 前提事实： coding率先被AI替代提效显著；OpenAI失控事件、递归自我进化讨论、碎片化国际治理被提及
  • 推导逻辑： 指数级摸高+高度集权掌握 → 接管组织即接管AI → 若无安全边界与数据隐私守护则失控
  • 隐含假设： 技术仍沿当前Transformer范式指数上升，治理速度慢于技术速度
  • 反例 / 证伪条件： 若物理AI与对齐技术证明可稳定约束目标漂移且实现可验证可断开，则失控论弱化

观点 9：AI时代需新的人文主义与自我认同重建

  • 观点归属： 复旦大学哲学学院 齐涛副教授，洪江资本宋俊从投资侧补充

  • 反例 / 证伪条件： 若就业市场长期只为单一效率指标付费且教育直接给答案导致思考过程消失，则人文主义主张落空
