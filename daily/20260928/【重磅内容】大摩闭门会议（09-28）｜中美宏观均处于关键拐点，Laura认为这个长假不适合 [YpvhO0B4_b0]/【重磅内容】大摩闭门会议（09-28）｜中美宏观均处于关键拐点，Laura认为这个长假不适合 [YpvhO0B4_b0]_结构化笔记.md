# 结构化笔记｜【重磅内容】大摩闭门会议（09-28）｜中美宏观均处于关键拐点，Laura认为这个长假不适合重仓过节

## 1. 核心结论

- **结论1：美国陷入财政踩油门、货币被动踩刹车的政策僵局，高利率维持时间或超预期。** 适用条件/边界：只要美国财政赤字率维持6%左右的高扩张惯性、且原油逼近百元叠加柴油裂解价差破纪录的能源冲击延续，该判断成立；若财政主动收缩或能源冲击快速缓解则失效。
- **结论2：中国处于信心主导型去杠杆陷阱，微观防风险举措叠加形成约GDP 1个百分点以上的合成紧缩，四季度至明年初仅能期待托底式微调而非强力反转。** 适用条件/边界：适用于名义GDP在4%出头徘徊、通缩循环未打破、中央财政未大规模加杠杆对冲的阶段；若中央主权资产负债表直接下场大规模修复居民资产负债表，则需上修。
- **结论3：人民币仅是有序补涨，不具备单边大幅升值基础，预计今年约6.65、明年底约6.6。** 适用条件/边界：适用于中美利差倒挂约300bp以上、内需偏弱仍处通缩边缘、金融账户对外配置需求对冲经常账户顺差的阶段；若内需修复+利差收窄+资本外流逆转，则升值空间打开。
- **结论4：短期交易环境边际恶化，这个超长国庆假期不适合重仓过节，建议谨慎、降低风险敞口，美股相对超配、中国市场盈利预期仍有下调压力。** 适用条件/边界：适用于美债收益率上行进入加息通道、MS中国2026年盈利预期6%远低于市场13-14%、且长假期间全球油价利率地缘不确定性高的窗口；若油价利率快速回落、盈利预期企稳，则谨慎观点解除。

## 2. 专家观点与逻辑链

### 观点 1：美国财政路径依赖下的防御性加息

- **观点归属：** 宏观主讲（Robin/邢自强）
- **结论：** 近期25bp加息不是新一轮主动紧缩周期，而是被市场逼到墙角的防御性动作，难以解决宏观失衡。
- **前提事实：** 美国名义GDP连续维持5%以上、近两季近6%，财政赤字率高达GDP的6%；美债收益率自3月以来已上行120-150bp；财政退税致税收返还同比增20%，二季度家庭净财富增加约13万亿美元，高收入消费堅挺。
- **推导逻辑：** `经济偏热本应财政收缩 → 两党对减税增支有刚性、地缘诉求致刚性支付，财政持续踩油门 → 通胀粘性+能源冲击致美债收益率飙升 → 美联储形势比人强被动加息`
- **隐含假设：** 财政刚性短期无法打破；通胀粘性主要来自能源和财政支持的需求韧性；加息无法替代财政收缩治理失衡。
- **反例 / 证伪条件：** 若美国达成财政整固共识大幅削减赤字，或通胀快速回落至目标、美债收益率自行回落，则“被动防御”判断被证伪。

### 观点 2：柴油短缺是比原油破百更致命的隐患

- **观点归属：** 宏观主讲（Robin/邢自强）
- **结论：** 能源冲击已从原油蔓延至下游炼化，柴油将支撑全球高利率环境维持更久。
- **前提事实：** WTI和布伦特逼近百元；柴油对原油裂解价差达破纪录的100美元/桶，柴油名义现货或突破200美元/桶；全球海运柴油市场每天缺失近150万桶，约占正常运量1/5；美国战略石油储备降至40多年最低，按消耗速度明年春天触及运营底线。
- **推导逻辑：** `霍尔木兹海峡+俄罗斯炼厂受损 → 炼化环节受损、柴油难被电气化替代 → 柴油缺口推高欧洲PPI和全球成本 → 通胀高压延长高利率持续时间`
- **隐含假设：** 地缘冲突相持不下；炼能缺口短期无法修复；SPR无法有效补充缓冲。
- **反例 / 证伪条件：** 若中东停火、俄罗斯炼能恢复或全球工业需求大幅走弱致柴油裂解价差大幅收窄，则该隐患判斷失效。

### 观点 3：中国信心主导型去杠杆陷阱与合成紧缩

- **观点归属：** 宏观主讲（Robin/邢自强，引述蔡志鹏及去杠杆陷阱报告）
- **结论：** 家庭去杠杆已从房价下跌冲击演变为削减消费、增持预防性储蓄的紧缩式修复，叠加微观防风险执行形成宏观收缩，亟需中央财政加杠杆对冲。
- **前提事实：** 过去三年低物价循环未破，名义GDP在4%出头徘徊；家庭债务占可支配收入比虽略降，但靠削减消费还本而非收入做大；社保按实际基数征缴、税收优惠核查倒查、现房销售致房企周转下降、高收入海外收入征税等加总影响超GDP的1个百分点。
- **推导逻辑：** `房价下跌初始冲击 → 信心转弱致预防性储蓄上升、消费削减还债 → 各执行主体各自防风险逻辑合理 → 加总形成顺周期紧缩合成谬误 → 内需就业体感偏弱`
- **隐含假设：** 居民收入预期不改善则储蓄倾向不降；各项征管新政同步执行不做宏观对冲；地方财政无力扩张。
- **反例 / 证伪条件：** 若社零、居民收入增速、消费信心同步显著回升，或广义财政赤字转为逆周期扩张，则陷阱缓解。

### 观点 4：人民币不存在单边大幅升值基础

- **观点归属：** 宏观主讲（Robin/邢自强）
- **结论：** 允许有序补涨消化出口商结汇，但央行会防止单边预期，年内约6.65、明年底约6.6。
- **前提事实：** 经常账户年顺差超7000亿美元；但中美利差倒挂明显，美国国债5%点几、中国1.7%；内需偏弱仍处通缩边缘；居民企业海外多元配置需求强。
- **推导逻辑：** `巨额贸易顺差带来结汇需求 → 金融账户对外配置需求对冲外汇结余+中美负利差+美元相对偏强 → 不能机械将顺差等同于低估 → 快速升值等同收紧金融条件挤压利润`
- **隐含假设：** 资本账户仍有流出压力；央行以防羊群效应为首要目标；再平衡靠改革和财政刺激消费而非汇率升值。
- **反例 / 证伪条件：** 若中美利差大幅收窄、国内通缩打破且结汇意愿持续单边强劲、央行容忍升值，则温和预期被证伪。

### 观点 5：短期谨慎，长假不宜重仓过节，美股韧性强于A股港股

- **观点归属：** 策略主讲（Laura）
- **结论：** 三周前已下调A股港股指数预期，维持短期谨慎，建议降低风险敞口、避免重仓过超长假期；全球范围内相对超配美股。
- **前提事实：** 美联储进入加息通道致全球流动性收紧；中美峰会仅将经贸协定顺延数月、符合信号式预期无正反馈；美国团队下调明年GDP、通胀、消费投资预期，测算10年利率上100bp两年拖累增长1.5-2个百分点；MS中国2026盈利预期6% vs 市场13-14%；美股每季盈利超预期且上调，A股科技与美股联动性极高。
- **推导逻辑：** `收益率上行+盈利预期下调 → 风险偏好和流动性边际恶化 → 长假7-8天无法交易叠加全球地缘政策变数 → 获利了结和降仓占优 → 美股靠强盈利预期韧性相对最强`
- **隐含假设：** 长假期间全球油价利率风险不落地；中国盈利预期仍有巨大下调空间未price-in；美股盈利上调趋势延续。
- **反例 / 证伪条件：** 若长假期间油价利率大幅回落、全球流动性改善，或中国企业盈利大幅上修弥合与市场预期缺口，则谨慎和美股超配判断失效。

### 观点 6：政策托底预期与杠铃配置

- **观点归属：** 宏观+策略共识（Robin提托底方向，Laura提配置执行）
- **结论：** 预期四季度至明年初出台托底微调：财政贴息支持房贷+加速风电等六张网基建；操作上长期超配新质生产力，短期用金融红利做杠铃另一端熨平波动。
- **前提事实：** 仅对新房贴息每年约300多亿即可释放信号意义，存量全贴效果更强；可再生能源基建兼顾托底投资与能源安全；上周已将中国银行加入港股配置、宁波银行加入A股配置。
- **推导逻辑：** `合成紧缩+能源安全压力 → 中央财政小额贴息表态修复资产负债表+风电投资托底 → 未破去杠杆陷阱力度有限 → 组合需成长端博长期+红利金融端收息降波`
- **隐含假设：** 贴息由中央和地方财政出资可落地；风电审批投资加速不受财政约束；银行保险股息可持续覆盖波动。
- **反例 / 证伪条件：** 若贴息政策未出台或规模远超预期转向全面刺激，或银行净息差大幅恶化致分红不可持续，则该指引失效。
