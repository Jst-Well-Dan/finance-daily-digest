# 结构化笔记｜【2026-10-26最新】华创张瑜旬度策略：张瑜——迷雾中的事实 五年消费下行周期到头

## 1. 核心结论
- **结论1：2021年以来持续5年的消费板块绝对收益下行周期基本结束，可开始自下而上挑选。** 适用条件/边界：仅在供需均衡度（需求增速-投资增速差值）回到2021年水平且供给出清快于需求走弱时成立；是供需双弱、供给更弱下的纯自下而上+龙头红利修复逻辑，无贝塔涨价行情。
- **结论2：居民部门再现保守化，若无财政及时对冲将压制远期盈利预期与当下市场活跃度。** 适用条件/边界：适用于收入增速~3%跟不上名义GDP~6%、房价未全面企稳、资本市场波动率偏高环境；将影响2027年Q2后PPI与上市公司利润预期，以及当期交易量与估值扩张。
- **结论3：金融市场流动性偏紧呈存量博弈，央行在不可能三角下仅能艰难平衡，降息与大幅投放均需观察。** 适用条件/边界：适用于非银存款连续5个月同比负增、5年定存利率~1.3%已接近核心CPI~1.0%、10年国债~1.6%与7天回购~1.4%曲线过平阶段；工业企业利润同比仍为正时降息概率低。
- **结论4：2026年全球温和修复共识高度依赖能源供应恢复与AI投资延续两条主线，前提脆弱需折价看待。** 适用条件/边界：仅在IMF假设（霍尔木兹海峡2026年3月起逐步恢复至10月复常、厄尔尼诺冲击未纳入）兑现且AI硬件基建开支不降温时成立；IMF对中美次年增速历史平均绝对偏差达1.4-2.3个百分点，具体数字不可直接采用。

## 2. 专家观点与逻辑链
### 观点 1：居民消费与消费板块不是一回事

- **观点归属：** 张瑜
- **结论：** 宏观消费需求偏弱，但消费板块供需均衡度自今年4-5月快速改善至2021年水平，绝对收益价值开始显现。
- **前提事实：** 居民消费贷、按揭贷、经营贷12个月加总年化增量持续下行，Q2以来居民部门绝对缩表；居民收入增速~3%与名义GDP~6%裂口扩大；上中下游供需均衡度5月以来上行很快。
- **推导逻辑：** `需求走弱但供给出清更快 → 需求增速-投资增速差值扩大 → 产能利用率/供需均衡改善 → 头部利润企稳`
- **隐含假设：** 行业并购重组、关店、亏损出清为真实供给收缩而非报表腾挪；需求增速不出现断崖式二次探底。
- **反例 / 证伪条件：** 若供给重新扩张或需求加速下滑导致均衡度掉头；若龙头现金流无法稳住则逻辑失效。

### 观点 2：居民风险偏好回落：又爱定存、又不爱消费

- **观点归属：** 张瑜
- **结论：** 居民预期波动再起，消费倾向低迷，若无财政对冲将传导至远期PPI、2027年Q2后利润及当下交易量估值。
- **前提事实：** 新增存款中居民定期比重自今年5月起连续4个月上升；9月消费倾向仅高于2020年同期，低于2019、2021-2024所有同期；股票波动率上行、房价未稳、收入增速下行。
- **推导逻辑：** `收入跟不上GDP+资产波动 → 风险偏好下降 → 多存少消费 → 经济循环走弱+市场新增资金减少 → 远期盈利预期不明朗+当期估值承压`
- **隐含假设：** 信贷与存款行为可作为风险偏好有效代理；收入增速锚定必选消费增速~3%上下。
- **反例 / 证伪条件：** 若财政大举对冲、房价全面企稳或收入增速回升，则保守化逆转；若9月消费倾向低迷仅为单月扰动则不成立。

### 观点 3：六张网是未来几年基建主要拉动

- **观点归属：** 银波（华创宏观）
- **结论：** 六张网整体落地概率高、资金不断加力、协调力度大，合计25-30万亿、年均5-6万亿、年均增速~10%，值得持续跟踪。
- **前提事实：** 全部来自十五五规划109项重大工程，参照十四五102项全部完成；资金从预算内投资→特别国债→金融工具→9月底PSL不断加力；7月会议部署后8月底至9月中旬发改委牵头连续4周协调；估算占基建总量40-45%。
- **推导逻辑：** `写入五年规划+中央加钱+专人推进 → 落地概率高于城中村改造等旧抓手 → 若整体实现10%以上增长 → 对基建拉动可观`
- **隐含假设：** 基建口径总量估算大致准确；不同年份间进度波动可用跨年平均熨平；物流网按航运+都市圈运窄口径约1-2万亿。
- **反例 / 证伪条件：** 若资金投放效果不佳后不再加钱、或水利、市政等今年负增长延续至明年，则增速不及预期；若物流网边界证伪则总量高估。

### 观点 4：9月消费超预期主因假期错位，10月需谨慎

- **观点归属：** 银波（华创宏观）
- **结论：** 9月社零、服务业生产、餐饮交运偏强不可外推，居民必选消费回升至3.6%为今年最高但无收入支撑，10月社零可能转弱。
- **前提事实：** 今年中秋在9月、去年在10月且紧邻国庆形成连休；农民工月均收入、居民人均可支配收入均未回升；三季度居民消费倾向、农民工就业收入仍微微走弱；10月高频汽车偏弱。
- **推导逻辑：** `收入未回升+消费回升 → 非趋势性因素 → 假期错位解释 → 10月基数反转走弱`
- **隐含假设：** 工资锚定必选消费的关系依然稳定；上市公司Q3人均薪酬数据将延续疲弱。
- **反例 / 证伪条件：** 若10月底三季报人均薪酬回升或10月社零、汽车高频走强，则错位解释被证伪。

### 观点 5：货币政策不可能三角与艰难平衡

- **观点归属：** 陆宇（华创宏观）
- **结论：** 流动性即非银存款已连续5个月同比负增，央行无法在不降息下同时实现流动性投放与维持向上收益率曲线，只能以缩短久期（7天逆回购缩至隔夜）微放短端流动性+预备流动性投放工具兜底。
- **前提事实：** 5月至9月每月非银存款同比负增，上次连续5个月以上为2022年4-10月；政策利率偏高时降息有效，但当下小幅降息难带动转型期+成本冲击下信贷；5年定存~1.3% vs 核心CPI~1.0%，再降息致存款实际回报转负；10年国债~1.6% vs 7天回购~1.4%曲线过平；工业企业利润同比仍为正。
- **推导逻辑：** `非银流出股市债市→存量博弈 → 盼央行放水 → 放水压低长端致曲线过平埋踩踏风险 → 只能短久期微调平衡预期`
- **隐含假设：** 二级市场股债互换不消灭非银存款，只有实体借款或居民赎回才抽离流动性；越短利率传导货币政策效果越好。
- **反例 / 证伪条件：** 若信贷大幅回升、非银存款同比转正，或工业利润转负触发降息周期，则三角约束解除；若经济预期骤然改善引发债市抛售，则兜底工具有效性被检验。

### 观点 6：IMF全球展望的框架与局限

- **观点归属：** 夏雪（华创宏观）
- **结论：** IMF预计2026全球实际GDP从3.1%回升至3.4%，但数字需水分看待；核心矛盾是供给端能源冲击缓冲收窄 vs 需求端AI投资能否延续，呈现高度分化与通胀粘性。
- **前提事实：** 基准假设霍尔木兹海峡2026年3月起恢复、10月复常，厄尔尼诺外生冲击未纳入；近5年IMF每年10月对次年中美增速预测平均绝对偏差1.4和2.3个百分点；今年韧性来自非冲突区增产+库存释放+能效提升；AI拉动主要来自硬件基建而非生产率兑现；全球总体通胀从4.7%回落至4.1%（较7月上调0.2pp），美欧核心通胀至2028年中才回2%；增速低于2%概率从4月20%降至10%，通胀超5%概率从30%升至35%。
- **推导逻辑：** `能源缓冲收窄+AI开支集中 → 台湾、韩国等深度参与AI且能源冲击小者有支撑，法国等进口依赖高且AI参与低者承压 → 全球总量小幅修复但结构分化+通胀制约货币政策`
- **隐含假设：** WTO货物贸易量2026年~3.1%微加速、IEA/EIA预计石油供需由缺转余可作为交叉验证；中东冲突缓和时间表外生给定。
- **反例 / 证伪条件：** 若霍尔木兹恢复不及预期、AI投资降温、贸易摩擦与债务压力发酵，则修复落空；若能源替代路线畅通、AI生产率超预期兑现，则上行超预期。
