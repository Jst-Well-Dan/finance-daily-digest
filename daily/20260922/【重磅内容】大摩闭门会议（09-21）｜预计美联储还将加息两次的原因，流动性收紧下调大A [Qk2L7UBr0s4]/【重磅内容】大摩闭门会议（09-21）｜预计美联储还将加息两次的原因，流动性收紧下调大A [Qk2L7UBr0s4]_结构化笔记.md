# 结构化笔记｜【重磅内容】大摩闭门会议（09-21）｜预计美联储还将加息两次的原因，流动性收紧下调大A和港股目标价

## 1. 核心结论

- **结论1：美联储已转向迷你加息周期，基准为9月已加后12月再加25bp、明年3月再加25bp。** 适用条件/边界：仅在核心PCE环比持续偏离0.17%路径、维持在0.25%左右且能源向核心传导未消退时成立；若未来2-3个月核心PCE回落至0.2%以下，加息周期可能更快结束。
- **结论2：中国居民去杠杆已从地产驱动转入信心驱动，存在去杠杆—通缩循环风险。** 适用条件/边界：仅在中央政府赤字扩张保持谨慎、多部门同时去杠杆、且经常账户顺差无法进一步扩大对冲时成立；若就业收入预期、房价预期实质性修复，或中央大幅加杠杆对冲，则循环假设失效。
- **结论3：下调中国市场目标价至明年6月仅剩中个位数上涨空间，港股压力大于A股。** 适用条件/边界：仅在美联储处于加息通道致全球流动性边际收紧、且境内资本流出管理阶段性偏严延续时成立；转写稿中绝对点位数字存在明显串入错字，已从结论剔除，仅保留方向与空间判断。
- **结论4：美股维持偏多不降仓，亚太内部分化为超配日、韩、台，低配澳大利亚；中国短期超配金融。** 适用条件/边界：仅在美国名义GDP加速、期限溢价与风险溢价未显著扩张、盈利预期未系统性下修时成立；若通胀迫使终点利率超预期上行或盈利下修，则偏多假设失效。

## 2. 专家观点与逻辑链

### 观点 1：美联储转向迷你加息周期的原因

- **观点归属：** 蔡世鹏转述美国经济团队
- **结论：** 9月并非孤立预防性加息，而是温和加息周期开始，基准为12月+25bp、明年3月+25bp，且终点利率判断仍低于市场预期
- **前提事实：** 6月核心PCE仍低，7月环比升至0.25%，8月预估亦在0.25%左右；9月FOMC前市场对9月加息定价已非常充分；7月FOMC未兑现紧缩预期后美债曲线变陡、通胀预期上升
- **推导逻辑：** `通胀回落慢于0.17%路径+美联储抗通胀决心诉求+市场倒逼公信力风险 → 全年不加息假设失效 → 转为迷你加息周期`
- **隐含假设：** 0.25%环比将持续并对应近3%年化；能源二阶传导与AI资本开支挤出效应短期偏通胀；按兵不动会损害公信力并推升长端风险溢价
- **反例 / 证伪条件：** 未来2-3个月核心PCE环比回落至0.2%以下；能源价格回落阻断向机票、交通服务等传导；长端通胀预期未因按兵不动而上升

### 观点 2：中国居民资产负债表修复的微观与宏观背离

- **观点归属：** 蔡世鹏
- **结论：** 微观三指标改善但靠分子端偿债压消费实现；宏观上多部门同去杠杆而中央对冲谨慎，只能靠外需或更低名义增长完成调整，易形成反馈循环
- **前提事实：** 债务/可支配收入从高点110%左右降至100%以下；偿债率从12.4%降至不足11%；负债资产比近期改善；社零总额趋近零增长；经常账户顺差从2019年0.6%升至2025年3.8%
- **推导逻辑：** `房价就业收入预期走弱 → 理想负债低于存量负债 → 主动偿债增储蓄压消费 → 总需求弱拖累企业居民收入 → 目标负债更快下移 → 继续去杠杆`
- **隐含假设：** 居民行为主因是意愿而非借不起；出口高科技化对就业收入传导弱于过去；中央赤字扩张将维持拖而不举；高顺差占比难以长期维持而不加剧摩擦
- **反例 / 证伪条件：** 收入房价金融资产上涨带来分母驱动修复且消费同步回升；中央大幅扩赤字或推出广谱房贷贴息、生育养育补贴、社保夯实并落地见效；外需持续扩大且有效传导至居民收入

### 观点 3：下调中国指数目标价与港股承压逻辑

- **观点归属：** Laura
- **结论：** 9月初全面下调中国市场目标价至明年6月，指数上行空间受限，恒生与MSCI中国下调幅度大于沪深300，短期降港股转回A股后维持谨慎
- **前提事实：** 美联储加息预期升温；港币盯住美元且港股对全球流动性收紧常呈提款机效应；3月以来红筹解绑、居民境外投资账户严控、境外金融资产红利征税、信托穿透征税、9月初境外个人在华分红征税等陆续收严；市场对MSCI中国2026年盈利预期12-13%，团队仅预期6%
- **推导逻辑：** `美联储加息通道打开+资本流动边际收严 → 港股流动性抽紧与外资增配放缓 → 估值支撑有限+盈利预期偏高难超预期 → 下调目标价`
- **隐含假设：** 流动性是短期主导估值的边际变量；资本管理收严被全球投资人一致解读为偏严方向；盈利 consensus 偏高不会被上修兑现
- **反例 / 证伪条件：** 美联储加息预期逆转或美元走弱带来回流；资本流动规则执行缓和或外资重回增配；盈利实际增速接近12%以上兑现 consensus

### 观点 4：美股维持Risk-on与板块轮动

- **观点归属：** Laura转述美股策略
- **结论：** 无需大幅降风险偏好或减仓，美股估值已部分计入紧流动性，应转向高质量、动量、周期风格精选个股
- **前提事实：** 美股估值已逐步调整反映更紧流动性；美国名义增长加速而非减速，5年平均名义GDP接近7%；长端期限溢价仍收敛，未要求更高风险补偿
- **推导逻辑：** `名义增长韧性+通胀预期上修 → 名义GDP支撑企业收入 → 盈利与估值可维持 → 维持偏多并做风格切换`
- **隐含假设：** 股票盈利更跟随名义而非实际GDP；历史加息前后Quality、Momentum、周期跑赢规律仍适用；AI长期反通胀但短期挤出效应不摧毁盈利
- **反例 / 证伪条件：** 盈利预期需根本性下修；期限溢价与股权风险溢价大幅扩张；核心通胀持续超预期迫使终点利率远超当前基准

### 观点 5：中美9月峰会与11月关键节点的休战延续

- **观点归属：** Laura
- **结论：** 9月24日访美峰会不会根本改变中美长期竞争对抗，基准是芯片换稀土相互制约下的休战延续，关键看11月10日三项到期是否延长
- **前提事实：** 双方各握前置制约：中国稀土、美国对华科技贸易限制；去年釜山会谈三大条款将于2026年11月10日到期：301关税178项排除清单、BIS相关规则暂停、中国第二波出口管制暂停；11月下旬还有亚太峰会
- **推导逻辑：** `势均力敌相互制约+都不愿升级为全面经济对抗 → 维持现状平衡最优 → 峰会目标为延长三项到期并推进农产品能源客机采购与部分限制暂缓`
- **隐含假设：** 双方以避免擦枪走火为首要动机；延长到期即算满意结果，市场可维持平稳交易；中国市场短期主导仍是国内宏观与流动性而非峰会
- **反例 / 证伪条件：** 峰会达成远超延长范畴的全面缓和或彻底破裂；11月10日任一到期未延长且加码；市场对峰会定价出现大幅扰动而非平稳
